# Models 폴더 구조

Blender로 제작한 3D 에셋을 임포트할 폴더. [[기획서/07 UI & 아트 방향]]의 톤 방향, 발광 오브젝트 디자인 원칙, 구조 제작 계획을 기준으로 분류했다.

## Environment/BuildingModules

건물을 벽, 지붕, 장식 부품으로 나눠 그리드와 소켓 규칙 기반으로 조립하는 핵심 모듈. 지붕이 난이도와 재사용도가 가장 높다.

- `Columns` — 기둥
- `Roofs` — 처마와 지붕
- `Windows` — 한지창과 문
- `Walls` — 벽체 패널
- `Foundations` — 기단

## Environment/Lanterns

발광 레이어. 한지 초롱, 처마 밑 등불처럼 구조 모듈과 분리된 별도 프리팹으로 만들어, 같은 건물 구조에 레이어 조합만 바꿔 변형을 만든다. 색-오브젝트 매칭은 아직 초안 단계라 색별 하위 폴더는 만들지 않았다. 최종 확정 전까지는 이 폴더에 평평하게 쌓는다.

## Environment/Props

간판, 전봇대 등 건물 모듈과 발광 레이어에 속하지 않는 기타 배경 소품.

## Characters/Enemies

먹괴음 5종. [[기획서/03 먹괴음 - 적 설계]] 기준 3D 형태 방향은 아직 미정이고, 검정과 먹물 텍스처만 확정된 상태다.

- `Pyeong` — 평, 기본형
- `Won` — 원, 원거리형
- `Heup` — 흡, 흡수형
- `Bun` — 분, 분열형
- `Gwang` — 광, 광역형

## Characters/Boss

보스 포. 3페이즈, 핑크 돌고래.

## 임포트 전 확인할 것

`07 UI & 아트 방향`의 "다음에 확정할 것" 목록 참고:

- 발광 오브젝트 구체적 형태 1~2개 확정
- 색-오브젝트 매칭 최종 확정
- 먹괴음 3D 형태 방향
- 환경 다양성. 골목과 거리 외 실내나 층별 테마 변화 여부
