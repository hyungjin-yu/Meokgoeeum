# 먹괴음 개발일지 - 어제 고친 것들, 진짜 괜찮은지 확인하는 날

어제 하루 종일 보스 밸런스랑 버그 5종을 고쳤다.
스테이지 스킵, 맵 밖으로 떨어지는 위치교란, 스킬 조준 안 맞는 문제, HP 리셋 안 되는 문제, 예외 던지던 스포너까지.

근데 전부 개별로만 검증했지, "새 게임 → 1층 튜토리얼 → 보스전 → 다음 층"까지 쭉 이어서 깨지는 거 없는지는 안 봤다.

그래서 오늘은 통합 회귀 테스트부터 시작.

결과는 대체로 통과. 근데 테스트 도중에 이상한 걸 하나 더 발견했다.

## 죽은 보스가 스킬을 쓴다

```
[BossHealth] BossPo 처치!
[RoomClearGate] RoomClearGate 클리어! 계단 활성화.
[BossPo] 왜곡(보라) 시전!  ← 어? 방금 죽었는데?
[PlayerController] 슬로우 적용! 배율 0.5, 3초간
```

보스가 죽은 다음에 스킬을 또 썼다.

킬샷이 공격 windup 도중에 들어가면, `BossHealth.Die()`는 죽었다는 플래그만 세우지 `BossPo` 쪽 공격 코루틴한테는 아무 말도 안 해줬던 거다. 이미 시전 대기 중이던 스킬이 죽은 채로 그대로 발동.

`OnDeath` 이벤트를 구독해서 사망 즉시 코루틴 전부 멈추는 걸로 수정했다.

## 흡한테 도망칠 자유를 뺏다

QA 리뷰에 오래전부터 남아있던 지적 하나 - "흡이 도망가서 회복하는 걸 막을 방법이 없다."

코드를 열어보니 `EnemyHeup`은 이미 `IKnockbackable`을 구현하고 있었다. 근데 그걸 트리거할 방법이 어디에도 없었다. 인터페이스만 만들어두고 아무도 안 쓴 상태.

구르는 동안 스치는 넉백 가능 대상은 밀어내도록 구르기에 넣었다. 테스트해보니 흡을 연속으로 굴러서 계속 밀어내며 회복 구역 접근을 저지하는 게 됐다. 정확히 원하던 그림.

## 1층을 통째로 다시 짰다

여기서부터가 오늘의 진짜 작업.

1층 몹 배치를 다시 보다가 깨달은 게 있었다. 튜토리얼에서 "구르기"랑 "색 스킬"을 가르치긴 하는데, 배운 직후에 그걸 써먹을 기회가 없었다. 구르기는 장애물 회피용으로만 쓰고 끝, 색 스킬은 팝업으로 강제 사용시키고 바로 계단으로 감.

그래서 1층 구성을 이렇게 바꿨다.

```
[복도] --이동+구르기--
[방A: 평×2] --콤보 공격 학습--
[색 구슬 획득 + 스킬 팝업]
[방B 신규: 흡×1] --방금 배운 색 스킬로 딜, 도망가면 구르기 넉백으로 저지--
[계단]
```

보스는 1층에서 완전히 뺐다. 나중에 다시 배치할 자리 고민.

그런데 이 작업을 하려고 오랫동안 꺼둔 채 방치돼 있던 스포너를 다시 켜니까, 이번엔 또 다른 버그가 튀어나왔다.

## 계단이 너무 일찍 열리는 버그, 두 번 고쳐야 했다

```
10:15:24 CubeMapManager 플레이어를 (13.50, 0.30, 0.47)로 이동.
10:15:24 [RoomClearGate] RoomClearGate 클리어! 계단 활성화.  ← 몹이 하나도 안 나온 시점
10:15:29 [EncounterSpawner] "1웨이브" 시작!  ← 5초 뒤에야 첫 웨이브 스폰
```

씬 로드 직후, 아직 적이 하나도 안 스폰된 시점에 계단이 먼저 열려버렸다. `RoomClearGate`는 "범위 안에 살아있는 적이 있는가"만 주기적으로 검사하는 방식이라, 스폰 자체가 지연되는 구간에서는 "적 0마리 = 클리어"로 오판한 거다.

1차로 "한 번이라도 적을 본 적 있어야 클리어 판정"으로 고쳤다. 그런데 다시 테스트해보니

```
10:18:37 [RoomClearGate] 클리어!  ← 1웨이브만 잡았는데?
10:18:39 [EncounterSpawner] "2웨이브" 시작!
```

웨이브 사이 인터벌 구간에서 똑같은 패턴이 또 터졌다. 1웨이브 죽이고 2웨이브 스폰까지 2초 기다리는 그 틈에 또 "0마리=클리어"로 오판. 같은 버그의 다른 타이밍이었던 것.

결국 "한 번이라도 봤는가"가 아니라 **적 0마리 상태가 일정 시간 연속으로 지속돼야 클리어**로 바꿔서야 제대로 잡혔다.

다른 층들도 이 버그에 노출돼있는지 전수 점검했는데, 다행히 지연 스폰 구조를 쓰는 건 1층뿐이라 나머지는 애초에 문제 상황 자체가 안 생기는 구조였다.

## 엔딩 대사 두 줄

QA 문서에 오래 남아있던 두 항목도 오늘 정리했다.

보스 쓰러진 직후 곧장 "고마워"로 넘어가던 엔딩에 반응 비트 하나 추가.

> "나를... 가둔 거야?"
> (침묵)
> "...그래도, 나 여기 있었잖아."

색 구슬 100% 수집해도 엔딩이 똑같았던 문제엔 조건부 대사 한 줄.

> "이제... 여기, 전부 다 우리 색이야."

이걸로 QA 리뷰 문서에 남아있던 지적사항이 전부 해결됐다. Critical, Major는 지난달에, Minor 4건은 오늘로 마무리.
