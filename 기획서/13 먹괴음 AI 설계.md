# 먹괴음 AI 설계

> 2026-03-23 초안 | 2026-05-29 Unity 6.3 LTS NavMesh + Unity Behavior 패키지로 전환

## 기본 AI 구조

Unity 6.3 **NavMeshAgent + Unity Behavior 패키지** 기반 실시간 AI.
공통 C# Blackboard에 각 타입별 Action/Condition 노드를 교체하는 방식으로 구성.

> Unity Behavior 패키지가 Preview 단계이므로, 불안정 시 **C# 상태머신(State Machine)** 으로 대체 가능하도록 인터페이스 분리 설계.

```csharp
// 공통 AI 구성 요소
NavMeshAgent          : NavMeshAgent 컴포넌트 (경로탐색)
EnemyBlackboard       : C# 클래스 (공유 데이터)
  - Transform player
  - float distanceToPlayer
  - bool canAttack
  - bool isLowHP
  - float attackCooldown
EnemyBrain            : MonoBehaviour (Behavior 그래프 또는 State Machine 연결)
EnemyPerception       : MonoBehaviour (Sight + Hearing — OverlapSphere 기반)
```

## EQS 대체 — 커스텀 색 복원 구역 쿼리

UE5 EQS 대신 C#으로 직접 구현.

```csharp
// ColorAreaQuery.cs
public static Vector3 FindNearestColorRestoredArea(Vector3 from)
{
    var restoredAreas = ColorSystemManager.Instance.GetRestoredAreaPositions();
    return restoredAreas
        .OrderBy(pos => Vector3.Distance(from, pos))
        .FirstOrDefault();
}
```

## NavMesh 설정

- **NavMesh Surface:** 각 큐브 면 씬(SC_Face_X)마다 NavMeshSurface 컴포넌트 포함
- **씬 로드 시:** `NavMeshSurface.BuildNavMesh()` 호출 (런타임 빌드)
- **복수 적 경로 충돌:** `NavMeshAgent.obstacleAvoidance = ObstacleAvoidanceType.HighQualityObstacleAvoidance` — 자동 처리

## AI 인지 (Perception)

UE5 AI Perception 대신 `Physics.OverlapSphere` 기반 커스텀 구현.

```csharp
// EnemyPerception.cs
void Update()
{
    var hits = Physics.OverlapSphere(transform.position, sightRadius, playerLayer);
    blackboard.player = hits.Length > 0 ? hits[0].transform : null;
    blackboard.distanceToPlayer = blackboard.player != null
        ? Vector3.Distance(transform.position, blackboard.player.position)
        : float.MaxValue;
}
```

## AI 확정 사항

- **Perception 감지 반경:** 기본 6f (타입별 조정 가능)
- **NavMesh 빌드:** 씬 로드 시 런타임 빌드 (NavMeshSurface.BuildNavMesh)
- **반복 층 "기억하는 것처럼" 연출:** 화면 상단 노이즈 텍스트 UI 3초 노출 (DOTween 글리치 애니메이션)
- **Unity Behavior 패키지 불안정 시:** EnemyBrain을 C# enum 상태머신으로 교체 — 인터페이스 동일하게 유지
