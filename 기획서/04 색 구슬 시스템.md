# 색 구슬 시스템

> 2026-05-29 재작성

## 드랍

- 먹괴음 처치 시 색 구슬 1개 드랍
- 드랍 색은 층별 가중치 테이블에서 랜덤 결정
- **최대 보유 개수:** 5개
- **드랍 확률 가중치:** 적외선/자외선에 가까운 색일수록 확률 낮음, 중간 색일수록 확률 높음
- **미획득 구슬:** 맵에 잔류 → 다회차 플레이 시 획득 가능 → 색 도감 시스템과 연동

## 두 개의 다른 숫자 — "보유 구슬"과 "누적 색 기록" (2026-08-16 확정, QA [[32 QA 리뷰 - 기획자 3인]] SYS-1 대응)

색 구슬과 관련된 숫자는 **완전히 별개인 두 값**이다. 이 둘을 섞어 쓰면 안 된다.

| 구분 | 보유 구슬 (Held Orbs) | 누적 색 기록 (Lifetime Collected) |
|------|------------------------|-------------------------------------|
| 정의 | 지금 당장 전투에서 쓸 수 있는 자원 | 이 회차에서 그 색을 총 몇 번 주웠는지 |
| 상한 | **5개** (전체 색 합산) | 상한 없음, 색상별 카운터 |
| 증가 시점 | 구슬 획득 시 +1 | 구슬 획득 시 +1 (보유량과 별개로 항상 증가) |
| 감소 시점 | 색 스킬 사용 시 -1 | **감소하지 않음** (평생 누적, 세이브에도 영구 기록) |
| 용도 | 전투 자원 (스킬 발동) | [[06 보스 설계]] 등장 조건, 색 도감 완성도 |
| 저장 위치 | `orbCounts[6]` (현재 상태) | `orbLifetimeCollected[6]` (누적치, → [[18 세이브 & 로드 기획]]) |

> **왜 나눴는가:** 보스 등장 조건("각 색 3개 이상 획득")을 보유 상한(5개)과 동시에 만족시키는 건 산술적으로 불가능하다(6색×3=18 > 5). 스킬을 쓰면 구슬을 소모하는 게 당연한데, 그럴 때마다 보스 조건 달성이 되돌아가면 안 되므로 "얼마나 모았는가(누적)"와 "지금 몇 개 들고 있는가(보유)"를 분리했다. 필러 1("색은 감정의 증거다") 관점에서도 이게 맞다 — 스킬로 써버렸다고 그 기억을 다시 잊는 건 아니다.

## 획득 시 연출 (핵심)

1. 획득 지점을 중심으로 **원형 파동**이 퍼져나감
2. 파동이 지나간 자리에 해당 색이 타일/오브젝트에 스며들듯 복원
3. 파동은 맵 전체로 확산, 벽과 바닥에 색이 돌아옴
4. 연출 종료 후 **맵 회전** 발동 → [[05 맵 시스템 - 큐브 구조]] 참조

### Unity 구현 방향

- URP Shader Graph: 원형 마스크 + 색 보간 (Lerp)
- C# 코루틴으로 `_WaveRadius` 파라미터 시간에 따라 증가
- VFX Graph으로 파동 경계 파티클 연출
- 상세 구현 → [[11 셰이더 설계 - 색 복원 파동]]

## 색 복원 상태

- 복원된 구역: 시각적으로 색 돌아옴 (Shader Graph 마스크 유지)
- 일부 타일은 색 복원 시 숨겨진 계단/오브젝트 등장
- 모든 색이 복원된 층 → 클리어 표시

## 색 종류 (6색)

| 색 | 스킬 연결 | 역할 |
|----|-----------|------|
| 빨강 | 강타 | 공격 강화 |
| 파랑 | 흐름 | 관통 공격 |
| 노랑 | 번쩍 | 광역 공격 |
| 초록 | 되살림 | 회복 |
| 보라 | 왜곡 | 디버프 |
| 검정 | 먹물 | 보스 특효 |

## 도감 시스템

- 미획득 구슬이 맵에 잔류하므로, 다회차 플레이를 통해 모든 색 수집 가능
- 색 도감 UI에서 획득 현황 및 스킬 설명 확인 가능
