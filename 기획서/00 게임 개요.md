# 먹괴음 (Meokgoeeum) — 게임 개요

> 2026-05-29 재작성

## 한 줄 요약

*색을 잃어버린 도시에서, 붓을 든 자가 먹괴음들을 쓰러뜨리며 세계의 색을 되찾는다. — 그리고 이 탑이 무엇인지 깨닫는다.*

## 장르 & 플랫폼

- **장르:** 3D 실시간 액션 RPG / 퍼즐 어드벤처
- **플랫폼:** PC (Steam)
- **엔진:** Unity 6.3 LTS (URP)

## 컨셉 키워드

- 색채 회복
- 반복과 기만
- 큐브 구조의 세계
- 붓 = 무기

## 핵심 게임 루프

```
탐색
  → 먹괴음 조우
    → 실시간 액션 전투
      → 색 구슬 드랍
        → 구슬 획득 (색 복원 파동 연출 + 맵 회전)
          → 새로운 구역 개방
            → 계단 → 다음 층
              → 반복되는 층에 의문
                → 진실 발각 → 최종 보스
```
