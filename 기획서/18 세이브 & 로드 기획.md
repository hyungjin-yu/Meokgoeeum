# 세이브 & 로드 기획

> 2026-05-29 재작성 (Unity 6.3 LTS 기준)

## 세이브 방식

**자동 저장** — 수동 저장 없음.

## 세이브 시점

- 층 입장 시 자동 저장
- 보스 처치 후 자동 저장

## 저장 데이터 항목

| 항목 | 설명 |
|------|------|
| 현재 층 번호 | int |
| 플레이어 HP | float |
| 보유 색 구슬 현황 | Dictionary<Color, int> |
| 각 면 색 복원 상태 | bool[6] |
| 큐브 현재 회전 상태 | int (currentFaceIndex) |
| 각 면 방문 여부 | bool[6] (반복 층 판정용) |
| 처치한 먹괴음 총 수 | int |
| 색 도감 수집 기록 | bool[6] (회차 간 유지) |
| 뉴게임+ 회차 | int |

## Unity 구현 방식

```csharp
// SaveData.cs (직렬화 가능한 데이터 클래스)
[Serializable]
public class SaveData
{
    public int currentFloor;
    public float playerHP;
    public int[] orbCounts;          // 색별 보유 개수 (index = 색 enum)
    public bool[] faceColorRestored; // 6개 면 복원 여부
    public int currentFaceIndex;
    public bool[] faceVisited;
    public int totalKills;
    public bool[] orbCollected;      // 도감용 (회차 간 유지)
    public int newGamePlusCount;
}

// SaveManager.cs
// 저장: JsonUtility.ToJson(saveData) → File.WriteAllText(persistentDataPath)
// 로드: File.ReadAllText → JsonUtility.FromJson<SaveData>()
```

## 세이브 슬롯

- **슬롯 수: 3개**
- 슬롯 정보 표시: 층 번호 + 색 구슬 현황 + 마지막 저장 시각

## Steam Cloud 저장

- 도입 예정 (Steam Cloud API 연동)
- 저장 파일 경로: `Application.persistentDataPath/save_slot_X.json`
