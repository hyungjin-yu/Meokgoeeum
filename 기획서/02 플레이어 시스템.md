# 플레이어 시스템

> 2026-05-29 재작성

## 기본 정보

- **외형:** 현대적 복장, 손에 거대한 붓 (먹물이 묻어 있으며, 끝은 날카로운 칼날)
- **시점:** 3인칭 숄더뷰
- **전투:** 실시간 액션

## 스탯

| 스탯 | 설명 |
|------|------|
| HP | 기본 체력 |
| 붓 공격력 | 물리 대미지 기반 |
| 색 충전량 | 보유 중인 색 구슬 수 (스킬 자원, 최대 5개) |
| 이동 속도 | 캐릭터 이동 속도 |
| 구르기 쿨타임 | 회피 구르기 재사용 대기시간 |

## 실시간 전투 구조

```
[기본 전투]
  마우스 좌클릭        → 붓 기본 공격 (3타 콤보)
  마우스 좌클릭 홀드   → 강공격 (차징)
  Space               → 구르기 회피 (무적 프레임)
  1~6                 → 색 스킬 슬롯 사용 (쿨타임 기반)
  Tab                 → Lock-On (적 잠금)

[콤보 구조]
  1타: 가로 베기
  2타: 세로 베기
  3타: 회전 베기 + 먹물 스플래시

[피격 시스템]
  히트스탑: 피격 시 0.05초 정지로 타격감 연출
  피격 후 0.5초간 무적 (i-frame)
```

## 붓 스킬 (색별)

색 구슬 획득 시 해당 색 스킬 활성화. 구슬 1개 소모로 사용. 각 스킬은 쿨타임 보유.

| 색 | 스킬명 | 효과 | 쿨타임 |
|----|--------|------|--------|
| 빨강 | 강타 | 전방 대시 후 강력한 일격 | 8초 |
| 파랑 | 흐름 | 전방 직선 관통 베기 (다수 적 히트) | 6초 |
| 노랑 | 번쩍 | 주변 범위 폭발 (넉백 포함) | 10초 |
| 초록 | 되살림 | 소량 HP 회복 | 15초 |
| 보라 | 왜곡 | 타겟 적 일시 행동 불능 (슬로우) | 12초 |
| 검정 | 먹물 | 먹괴음에게 2배 효과 (보스 핵심) | 20초 |

## 성장 시스템

### 레벨업

- 색 구슬 드랍 획득 시 기억이 되살아남 → 레벨업 → 점점 다양한 기술 사용 가능

### 붓 업그레이드

- 업그레이드 시 새로운 기법 사용 가능
- 강화 시 스킬 대미지 상승
- 업그레이드 시 붓 외형 변경

### 색 스킬 보유 상한선

- 드랍한 구슬 개수에 따라 색 스킬 보유 증가 (최대 5개)
- 다회차 플레이 시 색 스킬 보유 개수 초기화되지 않음 (원할 경우 초기화 선택지 제공)

## Unity 구현 참고

- 이동: `CharacterController` (WASD)
- 카메라: `Cinemachine FreeLook` (숄더뷰) + Lock-On 시 `CinemachineTargetGroup`
- 히트스탑: `Time.timeScale` 순간 조작 또는 DOTween 애니메이션 일시 정지
