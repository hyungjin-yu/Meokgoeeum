# 씬 구조 & 기술 스펙

> 2026-03-23 초안 | 2026-05-29 Unity 6.3 LTS URP로 전환

## Unity 씬 구성

```
Scenes/
  SC_Boot          ← 초기화, 저장 데이터 로드, Manager 초기화
  SC_MainMenu      ← 타이틀 화면
  SC_Game          ← 실제 플레이 (Persistent Scene + Addressables로 큐브 면 관리)
  SC_Face_0~5      ← 큐브 6면 (Additive 로드, 6면 순환 로직 안에 있음)
  SC_CubeReveal    ← 12층: 큐브 구조 노출 전용 룸 (면 순환 밖의 특수 씬)
  SC_Boss          ← 보스 전용 (Addressable로 동적 로드, 면 순환 밖)
  SC_Ending        ← 컷씬 (Timeline 기반)
```

> 면(Face) 전환은 씬 전환이 아닌 **Addressables LoadSceneAsync (Additive) + 페이드 트랜지션** 방식
> → 로딩 비용 최소화, 큐브 회전 연출과 연계 유리
> `SC_CubeReveal`과 `SC_Boss`는 6면 순환에 포함되지 않는 별도 씬이다 — "층(floorNumber)"이 12에 도달하면 6면 순환을 벗어나 이 특수 씬으로 전환한다 (→ [[05 맵 시스템 - 큐브 구조]], [[12 큐브 좌표계 설계]])

## 핵심 클래스 구조

| 클래스 | 역할 |
|--------|------|
| GameManager | Singleton — 게임 규칙, 층 진행, 게임오버 처리 |
| GameState | ScriptableObject — 전체 게임 상태 (층 번호, 색 복원 현황, 큐브 회전 상태) |
| PersistentData | ScriptableObject — 세션 전반 유지 데이터 (색 구슬 보유, 세이브 데이터) |
| PlayerInputHandler | New Input System 기반 입력 처리 |
| PlayerController | 캐릭터 이동, 전투, 스킬 (CharacterController 기반) |
| CubeMapManager | Singleton — 큐브 좌표계, 면 데이터, Addressables 로드/언로드 |
| ColorSystemManager | Singleton — 색 구슬 보유 현황, 색 복원 상태 |
| EnemySpawner | MonoBehaviour — 적 스폰, NavMesh Agent 활성화 관리 |
| HUDManager | MonoBehaviour — UI Canvas 관리 |
| AudioManager | Singleton — BGM/SFX, 오디오 믹서 제어 |

## Unity 주요 기능 활용

| 기능 | 용도 | UE5 대응 |
|------|------|----------|
| Addressables | 큐브 면별 씬 동적 로드/언로드 | Level Streaming |
| URP + APV | 글로벌 일루미네이션 (베이크드, 색 복원 조명 변화) | Lumen |
| URP Shader Graph | 색 복원 파동 셰이더 | UE5 Material Editor |
| VFX Graph | 색 복원 파동 파티클 이펙트 | Niagara |
| Unity Behavior | 먹괴음 AI 비헤이비어 트리 | Behavior Tree + EQS |
| NavMesh + NavMeshAgent | 적 경로탐색 | NavMesh |
| New Input System | 입력 매핑 (키보드/마우스/게임패드) | Enhanced Input |
| Timeline + Cinemachine | 컷씬, 큐브 회전 연출, 페이드 트랜지션 | UE5 Sequencer |
| Animation Rigging | 공격 시 캐릭터 위치 보정 | Motion Warping (근사치) |
| JsonUtility | 세이브 데이터 직렬화 | USaveGame |

## 3D 공간 시스템

- 큐브 면 1개 = 하나의 3D 구역 (Addressable Scene 단위)
- 플레이어 이동: `CharacterController` (WASD + 점프)
- 적 경로탐색: `NavMeshAgent` (각 면 씬마다 NavMesh Surface 빌드)
- 면 전환 시: 현재 면 UnloadScene → 다음 면 LoadScene Additive + 페이드 트랜지션

## 렌더 파이프라인

- **URP (Universal Render Pipeline)** 사용
- Forward+ 렌더링 모드 (Unity 6.3 기본값) — 동적 조명 다수 처리 유리
- **APV (Adaptive Probe Volumes)** — 구역별 베이크드 GI, 색 복원 후 Light Probe 갱신
- HDRP 미사용 (1인 개발 설정 복잡도 절감)

## 기술 확정

- **면 전환:** Addressables LoadSceneAsync (Additive) + 페이드 트랜지션
- **저장 데이터 구조:** JsonUtility 직렬화 → `Application.persistentDataPath` 저장
- **모바일 포팅:** 미고려 (PC Steam 전용)
- **구현 언어:** C# 전용 (Blueprint 없음)
- **타겟 프레임:** 60fps (PC)
