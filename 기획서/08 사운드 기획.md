# 사운드 기획

> 2026-05-29 재작성

## BGM 방향

| 구간 | 방향 |
|------|------|
| 기본 탐색 | 동심을 자극하는 노래. 따뜻하고 몽환적인 느낌 |
| 층이 올라갈수록 | 같은 테마의 변주. 점점 어른으로 성장해가는 느낌 |
| 반복 층 구간 | 기존 BGM이 뒤틀린 버전 (피치 시프트 + 에코 추가) |
| 전투 | 타격감 있는 비트. 빠른 템포. 2회차는 동심 자극 신나는 노래 |
| 보스 1~2페이즈 | 어른과 아이 사이에서 고뇌하는 느낌 |
| 보스 3페이즈 | 1~2페이즈 테마가 불협화음으로 붕괴 |
| 엔딩 | 밝고 따뜻한 풀 버전 |

## SFX

| 요소 | 방향 |
|------|------|
| 색 복원 파동 | 수채화 물감 번지는 듯한 소리. 색마다 음색 다름 |
| 먹괴음 이동 | 끈적하고 이상한 울음소리 |
| 먹괴음 피격 | 먹물 튀는 소리 |
| 붓 기본 공격 | 바람 가르는 소리 + 먹물 묻히는 소리 |
| 붓 콤보 3타 | 회전 베기 + 먹물 스플래시음 |
| 색 스킬 발동 | 각 색마다 고유한 음색 |
| 구르기 회피 | 빠른 바람 소리 |
| 맵 회전 | 묵직한 큐브 회전음 (돌덩이 구르는 느낌) |
| 구슬 획득 | 맑은 구슬 소리 |
| 층 이동 | 계단 발소리 + 장면 전환 효과음 |
| 피격 | 먹물 튀는 소리 + 히트스탑 효과 |

## Unity 구현 방향

- **BGM/SFX:** Asset Store 에셋 활용 (직접 제작 최소화)
- **Adaptive Audio:** AudioMixer + Snapshot 전환으로 BGM 상태 변경
  - 반복 층: Snapshot에 Pitch Shifter + Echo 이펙트 적용
  - 보스 3페이즈: Snapshot에 Distortion 추가
- **오디오 미들웨어:** Unity Audio Mixer만으로 처리 (Wwise/FMOD 미사용)
- **AudioManager:** Singleton + AudioSource 풀링으로 SFX 재생
