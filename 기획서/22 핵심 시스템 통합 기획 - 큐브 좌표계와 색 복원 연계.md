# 핵심 시스템 통합 기획 — 큐브 좌표계와 색 복원 메커니즘의 연계

> 2026-05-29 재작성 (Unity 6.3 LTS URP 기준)

## 개요

본 문서는 큐브 좌표계([[12 큐브 좌표계 설계]])와 셰이더 기반 색채 복원 시스템([[11 셰이더 설계 - 색 복원 파동]])이 어떻게 상호작용하는지 기술하며, '기억의 복원'과 '공간적 기만'이라는 내러티브 테마를 기술적으로 형상화하는 방식을 상세히 기술한다.

---

## 1. 시스템 설계의 전략적 배경

'먹괴음'의 세계는 단순한 3차원 공간이 아닌, 플레이어의 파편화된 기억이 투영된 폐쇄적 정육면체(Cube)다.

- **큐브의 이중적 의미:** 플레이어를 가두는 '기만의 감옥' + 잃어버린 자아를 찾는 '구조적 지도'
- **색채 회복:** 단순한 시각 피드백이 아닌 플레이어의 **인지적 확장**을 의미
- **반복과 기만:** 큐브 면의 물리적 회전 메커니즘으로 구현

---

## 2. 큐브 좌표계 — 심층 설계

### 2.1 고정 규격 & 가변 위상

| 항목 | 내용 |
|------|------|
| 면 수 | 6개 (Face Index 0~5) |
| 타일맵 크기 | **고정** (성능 안정성 확보) |
| 씬 관리 | Addressables로 6개 면 개별 관리 |

### 2.2 좌표 고정 아키텍처

회전 시 **플레이어를 해당 면의 SpawnPoint로 강제 이동**하고, 씬 자체를 교체한다.

- **기술적 이유:** 씬 전환 방식으로 물리 엔진 연산 오류 방지
- **내러티브적 의미:** 세계가 플레이어의 자아(Ego)를 중심으로 재구성된다는 암시

### 2.3 맵 회전과 심리적 기만

- **트리거:** 색 구슬 획득 시 X/Y/Z 축 중 1개 무작위 선택, 90도(CW/CCW) 회전
- **메모리 최적화:** 현재 면만 로드 (Addressables Additive, 나머지 Unload)
- **플레이어 심리:** 이미 지나온 층을 다른 각도에서 다시 마주함 → '탈출 불가능한 무한 루프' 압박감

## 3. 색 구슬 시스템 — 심층 설계

### 3.1 색상별 스킬 밸런스 데이터

| 색상 | 스킬명 | 효과 | 계수 |
|------|--------|------|------|
| 빨강 | 강타 | 전방 대시 후 강력한 일격 | 공격력 × 2.0 |
| 파랑 | 흐름 | 직선 관통 공격 | 공격력 × 1.5 |
| 노랑 | 번쩍 | 범위 내 적 전체 + 넉백 | 공격력 × 1.0 (광역) |
| 초록 | 되살림 | HP 즉시 회복 | 회복량 +20 |
| 보라 | 왜곡 | 적 슬로우 3초 | CC기 |
| 검정 | 먹물 | 먹괴음 본질 타격 | 공격력 × 1.5 (보스전 × 2.0) |

### 3.2 드랍 확률 가중치

- 가시광선 스펙트럼 양 끝단(빨강, 검정): 초기 층에서 낮은 드랍율 → 층수 증가에 따라 가중치 선형 증가
- 특정 색상 복원 효과: Shader Graph 마스크를 통해 숨겨진 오브젝트 렌더링 활성화

---

## 4. 색 복원 파동 셰이더 — 심층 설계

### 4.1 URP Shader Graph 기반 원형 마스크 및 보간 로직

```
// Shader Graph 파라미터
_WaveOrigin   : Vector3  ← 구슬 획득 월드 좌표
_WaveRadius   : Float    ← C# 코루틴으로 확장

// 노드 흐름
dist   = Distance( Position(World), _WaveOrigin )
mask   = Smoothstep( _WaveRadius, _WaveRadius - _EdgeSoftness, dist )
output = Lerp( Sample(GrayTex), Sample(ColorTex) * _TargetColor, mask )
```

### 4.2 마스크 누적 레이어 구조

- `Texture2D` 채널 활용 → 어떤 구역이 복원됐는지 영구 기록
- 여러 색상 파동이 겹쳐도 데이터 손실 없음
- 색 도감 시스템 연동 → 다회차 플레이 시 복원 기록 유지

---

## 5. 시스템 통합 — 기술적 시퀀스 타임라인

```
① OnEnemyDeath
   └─ 마지막 먹괴음 제거 판정 + OrbPickup 오브젝트 생성

② OnOrbCollect
   └─ ColorWaveEffect.PlayWave(origin, color) 호출
   └─ VFX Graph 파티클 재생 시작

③ ShaderMaskUpdate (C# 코루틴)
   └─ _WaveRadius 0 → MaxRadius 증가 (1.5초)
   └─ 구역 내 모든 Renderer 머티리얼 업데이트

④ MapRotationTrigger
   └─ 파동이 MaxRadius에 도달하는 순간
   └─ SFX: 묵직한 큐브 회전음
   └─ CubeMapManager.RotateRandomAxis() 호출

⑤ SceneTransition
   └─ FadeManager.FadeOut()
   └─ Addressables.UnloadSceneAsync(currentFace)
   └─ Addressables.LoadSceneAsync(nextFace, Additive)
   └─ PlayerController.TeleportToSpawnPoint()
   └─ FadeManager.FadeIn()
```

## 6. 반복 층 판정과 공간적 교란

회전 후 도달한 면이 이미 방문한 곳(`isRevisited == true`)일 경우:

### 노이즈 텍스트 (Glitch Text)
- 화면 상단에 내레이션 텍스트 출력
- DOTween으로 글리치 효과 (랜덤 문자 치환 → 올바른 텍스트 복원)
- 3초간 노출

### BGM 왜곡
- AudioMixer Snapshot 전환: Pitch Shifter + Echo 이펙트 적용
- 청각적으로 공간의 기만성 전달

## 7. 보스 '포(鯆)'와의 시스템적 대립

최종 보스 **포(핑크 돌고래)**는 플레이어의 복원 시스템을 역으로 이용한다.

### 데드 체이스 (Desaturation Wave) — 3페이즈

- 보스가 **핑크색 역방향 파동** 발산
- 플레이어 파동: `Grayscale → Color`
- 보스 파동: `Color → Grayscale` (동일 셰이더, `_WaveRadius` 역방향 적용)
- 플레이어에게 색(기억)을 지키기 위한 전략적 대응 요구

> 상세 설계 → [[06 보스 설계]]

## 8. 기술적 타당성 검토

| 항목 | 방침 |
|------|------|
| 씬 관리 | Addressables LoadSceneAsync (Additive) |
| 데이터 직렬화 | JsonUtility → persistentDataPath 저장 |
| 메모리 로딩 | 현재 면만 활성화 (나머지 Unload) |
| 셰이더 최적화 | Shader Graph — 분기문 최소화, Smoothstep 활용 |
| 비동기 처리 | UniTask 사용 (Addressables 연동) |

### 다회차 플레이 (New Game+) 가치

- 색 도감 누적 수치 보존
- 큐브 모든 면을 완벽한 색채로 채우는 수집 동기 제공
- 엔딩 시퀀스: 큐브가 완전히 펼쳐지는 강력한 시각적/서사적 보상
