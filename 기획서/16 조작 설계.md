# 조작 설계

> 2026-05-29 재작성 (Unity New Input System 기준)

## 지원 입력 장치

- [x] 키보드 + 마우스
- [ ] 게임패드 (추후 추가 고려)

## 키 바인딩 (키보드 + 마우스)

| 행동 | 키 |
|------|----|
| 이동 | W, A, S, D |
| 카메라 회전 | 마우스 이동 (우클릭 홀드) |
| 기본 공격 (콤보) | 마우스 좌클릭 |
| 강공격 (차징) | 마우스 좌클릭 홀드 |
| 구르기 회피 | Space |
| 색 스킬 1~6 | 1, 2, 3, 4, 5, 6 |
| Lock-On (적 잠금) | Tab |
| 구슬 슬롯 열기 | Q 또는 하단 구슬 슬롯 클릭 |
| 메뉴 열기 | ESC |

## 카메라 방식

- **기본:** 3인칭 숄더뷰 (캐릭터 뒤 + 약간 위)
- **Lock-On 시:** 적을 중심으로 카메라 고정, 측면 스트레이프 이동 가능
- **Unity 구현:** Cinemachine FreeLook Camera (기본) + CinemachineTargetGroup (Lock-On)

## 이동 특성

- 카메라 방향 기준 이동 (Camera-relative movement)
- 이동 중 공격 가능
- 구르기 중 무적 프레임 0.2초

## Unity New Input System 구성

```
Input Actions Asset: PlayerInputActions
  Player Action Map:
    Move          → WASD (Value, Vector2)
    Attack        → 마우스 좌클릭 (Button)
    ChargeAttack  → 마우스 좌클릭 홀드 (Hold interaction)
    Dodge         → Space (Button)
    Skill_1~6     → 1~6 (Button)
    LockOn        → Tab (Button)
    OpenSkillMenu → Q (Button)
    Menu          → ESC (Button)
```
