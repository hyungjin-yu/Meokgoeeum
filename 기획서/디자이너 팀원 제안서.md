## 2. 게임 컨셉

### 세계관

조선 풍 현대 도시. 세계는 색을 잃고 있다.
건물, 간판, 사람들의 얼굴 — 모든 것이 서서히 회색으로 바래간다.

플레이어는 한 손에 거대한 붓을 들고 이 낯선 세계에 서 있다.
붓 끝에는 먹물이 묻어 있고, 날카로운 칼날이 숨어 있다.

### 핵심 게임 루프

```
탐색
  → 먹괴음(먹물 괴물) 조우
    → 실시간 붓 전투
      → 색 구슬 드랍
        → 구슬 획득 → 색 복원 파동 연출 (핵심 비주얼)
          → 새로운 구역 개방
            → 다음 층으로
              → 반복되는 층에 의문
                → 진실 발각 → 최종 보스
```

### 핵심 반전

이 세계는 하나의 **정육면체(큐브)** 안에 갇혀 있다.
탑처럼 보이는 구조는 사실 큐브의 각 면을 순환하는 착각이다.
색 구슬을 얻을 때마다 큐브가 회전하며, 이미 지나온 면이 다시 나타난다.

### 보스 — 바다의 돼지 · 포 (鯆)

큐브 세계의 왕. 핑크 돌고래.
어린 시절 플레이어의 가장 친한 친구였지만,
플레이어가 자신을 잊어버리자 서운해져서 영원히 함께 놀기 위해 세계로 끌어들였다.

## 3. 아트 방향

### 스타일

**스타일라이즈드 3D** — 포토리얼이 아닌, 따뜻하고 아기자기한 감성.

| 요소 | 방향 |
|------|------|
| 전체 톤 | 어둡지 않음. 동화적이고 따뜻한 분위기 |
| 초반 (색 미복원) | 회색조 도시 — 모노크롬, 무채색 |
| 색 복원 후 | 선명하고 따뜻한 색감. 극명한 대비 |
| 캐릭터 스타일 | 아기자기하고 귀여운 느낌. 너무 사실적이지 않게 |
| 먹괴음 | 검정 + 먹물 텍스처. 이동 시 먹물 흔적 |

### 레퍼런스

- **색채 표현:** Gris (색이 돌아오는 감동)
- **3D 스타일:** Tunic (아이소메트릭 3D, 스타일라이즈드)
- **세계관 분위기:** 조선 풍 현대 도시 (한복 + 골목 + 간판)

### 컬러 팔레트

## 4. 디자이너 담당 역할

### 4-1. 컨셉아트 & 아트 방향 수립

- 게임 전체 비주얼 방향 결정 (디자이너 주도)
- 주요 장면 컨셉아트: 회색 도시 / 색 복원 후 도시 / 큐브 구조 / 보스 포(鯆)
- 색채 가이드라인 확정

### 4-2. 캐릭터 & 적 디자인

| 대상 | 내용 |
|------|------|
| 플레이어 | 현대적 복장 + 거대한 붓 (칼날 겸용). 먹물이 묻어 있는 디테일 |
| 먹괴음 - 평 | 기본형. 검정 먹물 형태의 기이한 생명체 |
| 먹괴음 - 원 | 원거리형. 먹물을 투척하는 팔 구조 |
| 먹괴음 - 흡 | 흡수형. 색 복원 구역을 탐지하는 감각 기관 표현 |
| 먹괴음 - 분 | 분열형. 처치 시 2마리로 분열하는 특성이 외형에 드러나도록 |
| 먹괴음 - 광 | 광역형. 덩치 크고 위협적 |
| 보스 포(鯆) | 핑크 돌고래. 귀엽지만 섬뜩한 이중성. 펄 + 그라데이션 핑크 |

### 4-3. 환경 & 타일셋

| 대상 | 내용 |
|------|------|
| 조선 풍 현대 도시 | 콘크리트 건물 + 한문 간판 + 전봇대 + 좁은 골목 |
| 회색 버전 | 무채색, 탈색된 질감 |
| 색 복원 버전 | 동일 구조, 색이 돌아온 버전 (셰이더로 전환) |
| 큐브 경계 구역 | 기하학적 패턴의 벽면 (큐브 구조 암시) |
| 보스 방 | 큐브 중심부. 화려하고 압도적인 공간 |

### 4-4. UI / HUD 디자인

| 대상 | 내용 |
|------|------|
| 메인 메뉴 | 타이틀 + 버튼 배치 (먹물 번짐 느낌) |
| 인게임 HUD | HP바, 층 표시, 색 구슬 슬롯, 스킬 쿨타임 아이콘 |
| 스킬 선택 팝업 | 구슬별 스킬 목록 UI |
| 맵 회전 오버레이 | 색 복원 텍스트 + 연출 UI |
| 게임오버 화면 | 통계 표시 + 재시도 버튼 |
| 색 도감 | 획득한 구슬 수집 UI |

#### UI 디자인 원칙

- **먹물 + 아기자기함** — 날카롭지 않고 부드러운 곡선
- **폰트:** 나눔스퀘어라운드 (메인), 온글잎 밀기름체 (연출용)
- **해상도:** 1920×1080 기준
- **색 미복원 시:** UI도 회색조 → **색 복원 후:** 해당 색 반영

## 8. 이 게임을 같이 만들어야 하는 이유

1. **비주얼이 핵심인 게임입니다.**
   색 복원 연출, 회색 → 컬러 대비, 보스 포(鯆)의 외형 —
   이 게임의 감동은 아트에서 옵니다. 디자이너의 기여가 게임 완성도를 결정합니다.

2. **기획이 완성되어 있습니다.**
   처음부터 기획을 같이 짜는 부담 없이,
   명확한 방향이 잡힌 상태에서 아트 작업에 집중할 수 있습니다.

3. **Steam 출시가 목표입니다.**
   포트폴리오로 남는 게임이 아니라,
   실제로 판매되는 게임을 함께 만드는 경험입니다.
