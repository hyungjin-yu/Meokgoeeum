# 2026-08-21 — 붓 공격이 자기 자신을 때리던 버그 (v0.1부터 존재했을 가능성)

## 발견 경위

4층 정상 클리어 테스트 중 사용자가 "Brush Weapon의 Attack Power를 10에서 1000으로 하니까 시작하자마자 플레이어가 죽어"라고 리포트. 무기 공격력이 플레이어 자신의 HP를 깎을 이유가 코드상 없어서 진단 로그를 추가해 확인한 결과, **`TakeDamage` 호출 시 amount가 600/700/1000 — 붓 3타 콤보의 배율(0.6/0.7/1.0) × Attack Power와 정확히 일치**했습니다. 즉 **붓 공격이 적이 아니라 플레이어 자기 자신한테도 맞고 있었던 것**.

Attack Power를 10으로 되돌려서 재확인해보니, 평소에도 매 타격마다 `amount=6/7/8/10` 같은 작은 자해 데미지가 계속 찍히는 걸 확인 — **이 버그는 지금 처음 생긴 게 아니라 원래부터 계속 있었고, 그동안 "피격 로그"를 꺼놔서(2026-08-19 로깅 원칙 변경) 안 보였던 것뿐**입니다.

## 원인

`BrushWeapon.PerformHit()`의 "자기 자신 무시" 판정:

```csharp
if (hit.attachedRigidbody != null && hit.attachedRigidbody.gameObject == gameObject)
    continue; // 자기 자신은 무시
```

이 체크는 **`Rigidbody` 기반 캐릭터를 전제로 짜여있는데, 플레이어는 `Rigidbody`가 아니라 `CharacterController`를 씁니다.** `CharacterController`는 `attachedRigidbody`가 항상 `null`이라서, 이 조건이 **한 번도 참이 되지 않았습니다** — 그 결과 `Physics.OverlapSphere()`가 판정 범위 안의 플레이어 자신의 콜라이더까지 그대로 잡아서 매번 데미지를 넣고 있었습니다.

## 수정

`hit.gameObject == gameObject` 직접 비교를 추가(기존 Rigidbody 체크는 자식 콜라이더 케이스 대비로 남겨둠):

```csharp
if (hit.gameObject == gameObject)
    continue;
if (hit.attachedRigidbody != null && hit.attachedRigidbody.gameObject == gameObject)
    continue;
```

## ⚠️ 중요 — 지금까지의 전투 난이도 체감은 이 버그가 섞여있었음

v0.1 붓 콤보 구현 시점부터 있었을 가능성이 높은 버그라서, **이날까지 진행한 모든 전투 관련 플레이테스트(밸런스 체감, "평 3클릭 처치" 검증 등)에 자해 데미지가 알게 모르게 섞여 있었을 수 있습니다.** 이 수정 이후로는 전투가 이전보다 더 안전하게/쉽게 느껴질 가능성이 큽니다 — 만약 밸런스가 너무 쉬워졌다고 느껴지면, 그동안 자해 데미지로 상쇄되던 부분이 없어진 것도 원인 중 하나로 고려할 것.
