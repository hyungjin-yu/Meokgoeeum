# 2026-08-16 — 적 피격 로그 추가 + 원칙화

## 배경

`PlayerHealth`는 맞을 때마다 콘솔에 로그가 찍히는데 `EnemyHealth`는 죽을 때(`정화 완료!`)만 찍혀서, 사용자가 "적도 플레이어처럼 맞을 때마다 콘솔에 보였으면 좋겠다"고 요청. 앞으로도 계속 적용되는 원칙으로 남겨달라는 요청도 포함.

## 한 일

- `EnemyHealth.TakeDamage()`에 `"{name} 피격! 남은 HP: {현재}/{최대}"` 로그 추가 (`PlayerHealth`와 같은 포맷)
- CLAUDE.md에 **"피격/상태 변화 로깅 원칙"** 신설 — 앞으로 만드는 모든 `IDamageable` 구현체(보스 포함)는 맞을 때마다 같은 형식으로 로그를 남기도록 명문화. HP바 UI가 나중에 생겨도 로그는 유지

## 다음 세션이 알아야 할 것

- 새 체력/피격 스크립트를 만들 때 이 로그 형식을 빼먹지 말 것 — 원칙 위치: CLAUDE.md "개발 원칙" 섹션
