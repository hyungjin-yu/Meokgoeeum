# 2026-08-19 — 인카운터 웨이브 스포너 + 1층 콘텐츠 착수

## 배경

v0.2/v0.3의 "시스템 코드"가 마무리되면서, 이제 그 시스템들을 실제로 쓰는 **레벨 콘텐츠**로 전환. [[28 레벨 디자인 - 인카운터 페이싱과 블록아웃]]을 보니 1층은 단순 배치가 아니라 **웨이브 기반 전투**(1웨이브: 평×1 HP 절반 고정 → 처치 후 2초 인터벌 → 2웨이브: 평×1 정상 HP → 클리어 시 계단)로 설계돼 있어서, 기존 `RoomClearGate`+`Stairs`만으로는 부족한 조각(웨이브 스포너)을 먼저 추가.

## 한 일

- **`EncounterSpawner.cs` 신규** — 웨이브 목록을 순서대로 진행하는 범용 스포너:
  - 각 웨이브는 적 프리팹 배열 + 스폰 위치 배열 + **체력 배율**(예: 0.5=절반)로 정의
  - 한 웨이브의 모든 적이 죽어야 다음 웨이브(대기시간 후) 시작
  - **`RoomClearGate`와 별도 이벤트 연동 없이 자연스럽게 맞물림** — RoomClearGate는 "지금 범위 안에 살아있는 적이 있는가"만 주기적으로 재검사하므로, 마지막 웨이브까지 다 죽어야 계단이 열림. 두 스크립트를 그냥 같이 두면 됨(설계 시너지)
  - 체력 배율은 이미 있던 `EnemyHealth.ConfigureMaxHP()`(EnemyBun 미니언용으로 먼저 만들어둔 것) 재사용

## Unity에서 해야 할 일 — 1층 콘텐츠 구성

1. **적을 프리팹으로 만들기**: `SC_Face_0`의 `EnemyPyeong`을 Hierarchy에서 Project 창(`Assets/Prefabs` 등)으로 드래그 → 프리팹 에셋 생성
2. **웨이브별 스폰 위치 2개** 만들기: 빈 오브젝트 2개(`Wave1SpawnPoint`, `Wave2SpawnPoint`) 배치
3. 빈 오브젝트에 **`EncounterSpawner.cs` 부착** → Inspector에서:
   - `Waves` 배열 크기 2
   - Element 0: `Wave Name`="1웨이브", `Enemy Prefabs`=[EnemyPyeong 프리팹], `Spawn Points`=[Wave1SpawnPoint], `Hp Multiplier`=0.5
   - Element 1: `Wave Name`="2웨이브", `Enemy Prefabs`=[EnemyPyeong 프리팹], `Spawn Points`=[Wave2SpawnPoint], `Hp Multiplier`=1
   - `Wave Interval`=2
4. **`RoomClearGate`**를 이 전투 공간을 덮도록 배치 (이미 [[logic/계단 & 방 클리어 게이트 씬 설정]] 절차대로 만들어뒀다면 위치/크기만 조정)
5. **`Stairs`**를 출구 쪽에 배치, `RoomClearGate`에 연결
6. 플레이테스트: 씬 시작 시 1웨이브(HP 절반 평) 자동 스폰 → 처치 → 2초 후 2웨이브(정상 HP 평) 스폰 → 처치 → 계단 활성화 → 밟으면 회전
