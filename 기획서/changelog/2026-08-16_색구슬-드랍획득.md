# 2026-08-16 — 색 구슬 드랍 & 획득 (v0.1 목표 ④)

## 배경

v0.1 목표 마지막에서 두 번째 단계. `EnemyHealth.OnDeath` 이벤트 훅을 미리 마련해뒀어서 바로 연결.

## 한 일

- **`OrbColor.cs` 신규** — 6색 enum (Red/Blue/Yellow/Green/Purple/Black)
- **`ColorSystemManager.cs` 신규** — [[04 색 구슬 시스템]] "두 개의 다른 숫자"(보유 vs 누적) 그대로 구현. 보유 상한(5) 초과 시 FIFO로 가장 오래된 색 자동 제거. [[10 씬 구조 & 기술 스펙]]에 명시된 이름 그대로 사용
- **`ColorOrbPool.cs` 신규** — 오브젝트 풀. 실제 구슬 아트가 없어서 런타임 Sphere 프리미티브로 임시 구현, 나중에 프리팹으로 교체해도 바깥 API(`Get`/`Release`)는 그대로 유지되도록 설계
- **`ColorOrbPickup.cs` 신규** — 월드에 놓인 구슬. 플레이어 접촉 시 자동 획득([[15 튜토리얼 설계]] 4단계 스펙), 풀로 반납
- **`EnemyHealth.cs` 수정** — `Die()`에서 `DropColorOrb()` 호출하도록 연결, 기존 TODO 제거

## 최적화 원칙 적용 (CLAUDE.md 원칙 실제 적용 사례)

- 구슬을 Instantiate/Destroy 대신 **오브젝트 풀**로 구현 — CLAUDE.md에 내가 직접 적어둔 "색 구슬... 처음부터 풀링 구조 고려" 원칙을 그대로 실천
- 머티리얼도 풀 크기만큼만 인스턴스가 생기도록(재사용 시 색만 덮어씀) 설계

## 설계 결정

- **드랍 색 확률은 지금 6색 균등 랜덤** — [[14 밸런스 수치 시트]]의 "층별 드랍 가중치" 테이블은 층/큐브 시스템이 아직 없어서 적용 불가. 나중에 층 시스템이 생기면 `DropColorOrb()`의 랜덤 선택 부분에 가중치 테이블만 끼워넣으면 됨
- 색 스킬로 구슬을 "소모"하는 API는 아직 안 만듦 — 스킬 시스템 자체가 없어서. 나중에 스킬 만들 때 `ColorSystemManager`에 소모 메서드 추가
