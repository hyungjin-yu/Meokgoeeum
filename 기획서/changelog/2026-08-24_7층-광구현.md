# 2026-08-24 — 7층(광) 구현: EnemyGwang.cs + 기획서 정리

## 배경

지난 세션(2026-08-21)에 7층 검토만 하고 구현을 미뤘던 작업. [[FaceBootstrapWindow]] 도구 실사용 테스트(`SC_Face_99` 더미 씬으로 검증, 정상 작동 확인 후 정리)를 먼저 마친 뒤 이어서 진행.

## 기획서 정리

`03 먹괴음 - 적 설계`의 "층별 등장 테이블"이 [[19 층별 상세 설계]]의 실제 층별 구성과 어긋나 있던 걸 정정:
- **분(分):** 03번엔 8~11층 첫 등장으로 되어있었는데, 19번 기준 실제로는 **6층**에서 첫 등장
- **광(光):** 03번엔 8~11층 첫 등장으로 되어있었는데, 19번 기준 실제로는 **7층**에서 첫 등장(단독 데뷔)

19번이 더 상세한 소스라 그쪽 기준으로 03번 테이블을 고쳤음(1~2/3~5/6/7/8~11/12+ 구간으로 세분화).

## EnemyGwang.cs 구현

`EnemyPyeong.cs` 구조를 그대로 재사용(윈드업/액티브/리커버리 상태머신, `IKnockbackable`, `NavMeshAgent` 기반). 차이점:

- **BT 트리거 조건이 다름** — [[13 먹괴음 AI 설계]]의 `BT_Enemy_Gwang`은 Pyeong처럼 "사거리 안"이 아니라 **쿨다운만으로** 공격을 트리거함(문서에 "평보다 단순한 BT"라고 명시). 그동안 추격이 거리를 좁혀왔을 거란 전제.
- **바닥 경고 인디케이터 추가** — [[27 전투 프레임 데이터]]에 명시된 "바닥에 원형 경고 범위 인디케이터"를 [[DamageZone]]과 같은 런타임 프리미티브(납작한 실린더) 패턴으로 구현. DamageZone과 달리 콜라이더는 즉시 제거(순수 시각 경고, 실제 피해는 Active 진입 시 `OverlapSphere`로 별도 계산 — 안 그러면 플레이어가 물리적으로 밀려나는 부작용 있음).
- **프레임 데이터**: 텔레그래프 25f/판정 8f/후딜 20f (5종 중 텔레그래프 최장)
- **⚠️ 밸런스 수치 정정**: 지난 세션 changelog엔 "광 전용 수치 없음"이라고 적었는데, 확인해보니 **`14 밸런스 수치 시트`의 "먹괴음 스탯" 표에 이미 있었음**(HP 60 / 공격력 15 / 이동속도 1.5f/s) — 지난 세션에서 놓친 것으로 보임. `EnemyHealth` 기본 HP(20)와 다르므로 `EnemyBun`의 분열 미니언 HP 조정과 같은 방식(`ConfigureMaxHP`)으로 `Awake()`에서 직접 60으로 맞춤(Inspector 수동 설정에 의존하지 않도록).

## Unity 검증 완료 (같은 세션에 이어서 진행)

`EnemyPyeong` 프리팹 복제(`Assets/Scenes/EnemyGwang.prefab`, 스크립트만 `EnemyGwang`으로 교체) → 컴파일 확인(에러 0) → `SC_Face_4`(NavMesh 베이크된 기존 씬)에 임시 배치해서 단독 테스트:

- 추격 → 쿨다운 만료 시 정지 + 바닥 빨간 경고 원(반경 3f) 표시 확인
- 경고 범위 밖으로 피하면 안 맞음, 안에 있으면 맞고 사망까지 확인(리스폰/1면 재시작/i-frame 전부 정상 작동)
- 처치까지 붓 공격으로 ~22초(3콤보 여러 번) 필요 — HP 60 스탯이 실제로 반영됨 확인
- `EnemyGwang 정화 완료!` → `RoomClearGate` 클리어 → `Stairs` 활성화까지 자동 연쇄 — 특별 코드 없이 기존 `EnemyHealth.OnDeath` 훅만으로 기존 시스템에 그대로 통합됨
