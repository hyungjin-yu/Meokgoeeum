# 2026-08-16 — 먹괴음-평 HP 30→20 조정 (3클릭 처치)

## 배경

첫 실전 테스트에서 붓 3타 콤보 한 번(23dmg)으로 평(HP 30)이 안 죽어서, 두 번째 콤보까지 필요해 "클릭을 엄청 많이 해야 한다"는 피드백. QA를 편하게 하려고 사용자가 직접 요청: "3번 클릭하면 죽을 정도로 바꿔줘".

## 한 일

- `EnemyHealth.cs`의 `EnemyPyeong` 기본 `maxHP` 30 → 20으로 변경 (코드 기본값)
- [[14 밸런스 수치 시트]] 평 HP 수치도 동일하게 갱신 + 조정 이유 각주 추가

## 왜 20인가

3타 콤보 총 대미지 = 6+7+10 = 23. 2타까지 누적(6+7=13)으로는 안 죽고, 정확히 3타째(23 ≥ 20)에 죽도록 20으로 설정 — "3번 클릭 = 처치"가 항상 성립하게 하는 값.

## Unity에서 해야 할 일 (중요 — 코드 기본값만으론 반영 안 됨)

**이미 씬에 배치된 `EnemyPyeong` 오브젝트의 `EnemyHealth` 컴포넌트는 이 변경으로 자동 갱신되지 않습니다.** Unity는 씬에 이미 놓인 컴포넌트의 필드 값을 스크립트 기본값 변경만으로 재적용하지 않기 때문입니다.

**사용자가 직접:** `EnemyPyeong` 선택 → Inspector에서 `Enemy Health`의 `Max HP`를 **20**으로 수동 변경 필요.

## 다음 세션이 알아야 할 것

- 이후 스크립트 기본값(`public float x = ...`)을 바꿀 때마다, **씬에 이미 배치된 오브젝트는 수동으로 값을 맞춰야 한다**는 걸 항상 안내할 것 — 이번처럼 빼먹으면 사용자가 "왜 안 바뀌지" 하고 헷갈림
