# 처마 지등 — Blender 첫 에셋 제작

## 배경

[[07 UI & 아트 방향]]의 "다음에 확정할 것" 1순위였던 발광 오브젝트 형태를 Blender MCP로 실제 제작. 처음엔 둥근 한지 초롱 형태로 시작했으나, 사용자가 레퍼런스 이미지를 제시하며 방향 전환 — 사각 창살 프레임에 지붕 갓을 얹고 고리로 매다는 목재 등 형태로 확정.

## 제작 과정

1. **1차 시도(둥근 초롱)** — bmesh로 배럴 형태 절차적 생성. 레퍼런스 이미지 확인 후 폐기
2. **2차 시도(사각 창살 등)** — 기둥 4개, 상단/하단 가로대, 4면 창살 패널 + 십자 문살, 사각뿔 지붕 갓, 걸이 고리와 막대로 구성. 총 28개 파츠
3. **버그 발견·수정 (사용자 리포트 "정면 뷰라 2D처럼 보임")** — 정면 직교 투영이라 입체감이 안 보였던 것으로, 3/4 퍼스펙티브로 전환해 3D임을 확인
4. **버그 발견·수정 (사용자 리포트 "초전도체처럼 중력 무시하고 떠있음")** — 하단 받침판 Z좌표 계산에서 간격을 이중으로 넣어 6mm 뜬 채로 생성되던 버그. 좌표식 정리해서 프레임에 완전히 붙임
5. **투박함 개선** — 프레임 두께 0.018→0.012m로 슬림화, 지붕 오버행·높이 축소, 전체 파츠에 Bevel 모디파이어(폭 0.0015, 세그먼트 2) 적용 후 `shade_smooth_by_angle`로 스무딩. Blender 5.x에서 `mesh.use_auto_smooth` API가 제거된 것도 확인·대응
6. **무채색 검증** — 재질 베이스 컬러를 Rec.709 휘도 공식으로 임시 그레이스케일 변환해 스크린샷 확인. 지붕/프레임/패널이 각각 어두움/중간/밝음 3단 명암으로 구분되어 [[07 UI & 아트 방향]] "발광 오브젝트 디자인 원칙"의 "채도 없어도 형태로 존재감 보완" 기준 충족 확인. 확인 후 원래 색상으로 복구
