# 건물 모듈 1차 제작 — 기둥/벽/창문/기단/지붕

## 배경

[[07 UI & 아트 방향]] "구조 제작 계획"의 5개 핵심 모듈(기둥, 처마와 지붕, 한지창과 문, 벽체 패널, 기단)을 실제로 Blender에서 제작. 그리드 2m 단위로 서로 소켓처럼 맞물리도록 설계했다.

## 제작 과정

1. **1차 조립** — 기단(3칸 통짜) + 기둥 4개(그리드 경계) + 벽체 패널 2칸 + 창문 패널 1칸(프레임+십자 문살+유리) + 경사 지붕(뒤가 두껍고 앞이 얇은 처마 형태)으로 3칸짜리 데모 건물 조립
2. **버그 발견·수정 (사용자 리포트 "벽 사이가 뚫려있는거 의도한거야?")** — 기둥을 건물 깊이 중앙(Y=0)에 배치하고 벽체는 앞면(Y≈0.71)에 배치해서, 옆에서 보면 기둥과 벽 사이에 뻥 뚫린 공간이 보이던 버그. 기둥을 벽과 같은 Y 위치로 옮겨서 해결
3. **착시 확인 (사용자 질문 "두께가 점점 두꺼워지는데 의도한거야?")** — 원근 시점 스크린샷에서 기둥이 위아래로 두께가 변하는 것처럼 보였는데, 실제 바운딩 박스를 측정해보니 0.28m로 완전히 균일했음. 직교 정측면 뷰로 다시 캡처해서 원근 착시였음을 확인(가까운 거리의 세로로 긴 물체를 비스듬히 볼 때 생기는 자연스러운 원근 왜곡)
4. **지붕 경사 설명 (사용자 질문 "왜 뒤가 두껍고 앞이 얇게 했어?")** — 의도된 디자인임을 설명: 처마가 완전 평판이면 배수 기능이 없어 보이고, 이미 만든 처마 지등이 이 처마 밑에 매달리는 걸 전제로 하고 있어서 실제 처마/차양 형태와 맞춰야 함. 경사 정도(뒤 3.2m/앞 2.9m)는 그대로 확정
5. **그리드 1칸 단위로 재정리** — 기단과 지붕을 3칸 통짜에서 1칸(2m)짜리로 다시 제작. 지붕 경사가 건물 길이(X) 방향이 아니라 깊이(Y) 방향으로만 기울어지는 구조라, 1칸으로 잘라도 단면이 동일해서 옆으로 이어붙일 때 단차가 생기지 않음을 확인

## 교훈

- 조립식 모듈에서 서로 다른 부품(기둥/벽)이 같은 면에 정렬되는지는 좌표를 직접 비교해서 확인해야 한다 — 이번엔 Y축 위치가 서로 달라서 생긴 실수였음
- 원근 투영 스크린샷만으로 형태를 판단하면 착시가 생길 수 있다. 치수 관련 의심이 들면 `matrix_world @ bound_box`로 실제 수치를 재고, 직교 뷰로 재확인하는 게 확실하다
- 경사/기울기가 있는 모듈을 그리드 단위로 쪼갤 땐, 경사 방향이 쪼개는 축과 겹치지 않는지 먼저 확인할 것 — 이번엔 운 좋게 경사 방향(깊이)과 분할 방향(길이)이 달라서 문제없이 쪼갤 수 있었음
