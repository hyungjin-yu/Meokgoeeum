# 2026-08-18 — 먹괴음 3종 추가 (원/분/흡)

## 배경

색 스킬 3종 완료 후, v0.2 나머지 항목 중 "먹괴음 3종 추가(원, 흡, 분)"를 다음 항목으로 선택 (큐브 좌표계보다 가볍고, 기존 `EnemyPyeong`/`EnemyHealth`/`IDamageable`/`IKnockbackable` 패턴을 그대로 재사용할 수 있어서).

## 한 일

### 공통 인프라
- **`EnemyHealth.cs`** — `Heal(float)`, `ConfigureMaxHP(float)` 추가 (흡의 회복, 분 미니언의 체력 재설정에 사용)
- **`RestoredAreaRegistry.cs` 신규** — `PaintableObject`가 칠해질 때마다 위치를 등록해두는 정적 유틸. [[13 먹괴음 AI 설계]] "ColorAreaQuery.FindNearestColorRestoredArea"(EQS 대체)를 그대로 구현
- **`PaintableObject.cs`** — `Paint()` 시 `RestoredAreaRegistry.Register()` 호출 추가

### 먹괴음 - 원 (원거리형)
- **`EnemyWon.cs` 신규** — [[13 먹괴음 AI 설계]] BT_Enemy_Won 그대로: 거리 2~5f면 투척, 1.5f 이하로 붙으면 후퇴(2f 확보), 아니면 추격. `EnemyPyeong`과 같은 상태머신 패턴, 텔레그래프는 [[27 전투 프레임 데이터]] 기준(Windup 20f, Recovery 16f)
- **`InkProjectile.cs` 신규** — 먹물 투사체. `ColorOrbPool`처럼 런타임 프리미티브로 생성(아트 에셋 없음). 지금은 풀링 안 함 — 원거리 몹 1종뿐이라 병목 아닐 걸로 판단, 나중에 몹 늘어나면 풀링할 것(주석에 명시)
- 스탯(14 밸런스 수치 시트): 공격력 10, 이동속도 2f/s. **HP 20은 `EnemyHealth.maxHP`에 수동 설정 필요**

### 먹괴음 - 분 (분열형)
- **`EnemyBun.cs` 신규** — 행동은 평과 완전히 동일(13 문서 "평과 동일 BT")이라 상속 대신 상태머신을 그대로 복제. 처치되면 `Instantiate(gameObject, ...)`로 자기 자신을 복제해서 체력 50%·크기 60%로 줄인 미니언 2마리 생성 (`isMinor` 플래그로 무한 분열 방지 — 별도 미니언 프리팹 없이 검증된 자기 자신을 복제하는 방식 채택, 아트 에셋이 없어서)
- 스탯: 공격력 7, 이동속도 3f/s (14 밸런스 수치 시트 "분(원본)" 기준). **HP 25는 `EnemyHealth.maxHP`에 수동 설정 필요** (미니언 HP는 런타임에 `ConfigureMaxHP()`로 자동 계산되므로 손댈 필요 없음)

### 먹괴음 - 흡 (흡수형)
- **`EnemyHeup.cs` 신규** — **비공격 유닛**([[27 전투 프레임 데이터]] "텔레그래프 불필요" 명시대로 플레이어를 절대 공격하지 않음). HP가 50% 밑으로 떨어지면 `RestoredAreaRegistry`에서 가장 가까운 색 복원 구역을 찾아가 흡수(초당 5 회복), 아니면 플레이어 쪽으로 다가만 옴(공격 없음)
- 스탯: 이동속도 2.5f/s. **HP 50은 `EnemyHealth.maxHP`에 수동 설정 필요**

## 의도적으로 단순화한 부분

- **흡의 색별 회복량 차등**: 원안은 "빨강(적외선 근접)일수록 크게, 보라(자외선 근접)일수록 작게" 회복하지만, 구역별 색 정보까지 `RestoredAreaRegistry`에 저장하는 건 범위를 넘어서서 **모든 구역 동일 회복량(초당 5)**으로 단순화. 나중에 레지스트리가 색까지 같이 저장하게 확장하면 됨
- **분 미니언 프리팹**: 별도 아트 에셋이 없어서 새 프리팹을 만드는 대신, 검증된 원본 GameObject를 통째로 복제하고 체력/크기만 줄이는 방식 채택
- **원거리 투사체 풀링**: 몹 1종뿐이라 지금은 생략, 주석에 나중에 풀링할 지점으로 명시해둠

## Unity에서 해야 할 일

1. 원/흡/분 각각 씬 오브젝트(또는 프리팹) 생성 → `NavMeshAgent` + `EnemyHealth` + 해당 스크립트(`EnemyWon`/`EnemyHeup`/`EnemyBun`) 부착. `EnemyPyeong`을 만들 때와 같은 절차([[logic/먹괴음 - 평 씬 설정]] 참고 — 스크립트 이름만 바꿔서 그대로 따라하면 됨)
2. `EnemyHealth.maxHP`를 타입별로 수동 설정: **원=20, 흡=50, 분(원본)=25**
3. 씬에 NavMesh가 이미 베이크돼 있어야 함 (평 때 이미 베이크했으면 추가 작업 불필요)
4. 플레이테스트:
   - **원**: 플레이어가 다가가면 후퇴하는지, 2~5f 거리에서 먹물을 던지는지, 맞으면 대미지가 들어가는지
   - **분**: 처치했을 때 미니언 2마리가 근처에 생성되는지, 미니언은 처치해도 또 안 갈라지는지
   - **흡**: 붓으로 때려서 HP를 절반 밑으로 내린 뒤, 근처에 색칠된(파동으로 원래 색 돌아온) 오브젝트가 있으면 그쪽으로 이동해서 회복하는지, 이동 중에도 플레이어를 공격하지 않는지
