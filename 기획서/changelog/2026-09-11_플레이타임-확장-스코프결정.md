# 플레이타임 확장 스코프 결정 + 1층 멀티룸 블루프린트

## 배경

환경 아트 6면 배치([[changelog/2026-09-11_6면환경아트-전체배치]]) 직후 사용자가 "맵 크기가 절대적으로 너무 작다, 면당 플레이타임이 10분은 넘겼으면 좋겠다"고 요청. 조사 결과 [[19 층별 상세 설계]]/[[28 레벨 디자인 - 인카운터 페이싱과 블록아웃]]은 애초에 각 층을 "방 하나, 몹 2~3마리, 1~2분"으로 설계해뒀던 것을 확인 — 이번 요청은 기존 페이싱 철학 자체를 바꾸는 결정이라 바로 만들지 않고 먼저 숫자를 맞췄다.

## 결정 — 총 플레이타임 목표

- [[31 엘리베이터 피치]]에 이미 "6~8시간(1회차)" 목표가, [[29 개발 리스크 진단 & 스코프 컷 계획]]에 이미 **"8개 층(6개 신규 면 + 반복 층 연출 1회분 2개 층) + 보스, 3~4시간"**이 축소 출시 기준(MVR)으로 문서화되어 있었음
- **사용자 확정: 새로 만드는 목표는 MVR 기준(3~4시간, 8층) — 12층 풀 비전(6~8시간)은 나중 확장으로 미룸**
- 역산: 3~4시간(210~240분) ÷ 8층 ≈ **층당 평균 26~30분**. 사용자가 처음 말한 "10분"보다 훨씬 긺 — 이 숫자로 재설계

## 구조 — 멀티룸 던전형

[[28 레벨 디자인]]의 기존 원칙("방 개수는 층당 3~5개 노드로 통일 — 제작 리듬 일정화")은 유지하되, 각 노드 자체를 훨씬 무겁게(방 하나에 1~2분이 아니라 6~8분) 만드는 방향으로 확정. 기존 시스템(`EncounterSpawner`, `HiddenOrbSpawner`, `PaintableObject`, `RoomClearGate`) 재사용을 최대한 우선시해서 "필러4(혼자 유지보수 가능한 복잡도)"를 지킨다.

## 1층(정육점 골목) 파일럿 블루프린트

```
[입장 복도] — 기존 유지·확장 (WASD/구르기 튜토리얼 + 장애물 구간) — 약 3분
  --문--
[방A: 정육점 광장 — 첫 전투 + 곁가지 탐색]
  평×2 전투(기존 튜토리얼 3단계 그대로) + 클리어 후 곁가지 통로로
  숨겨진 색 구슬 탐색 가능(HiddenOrbSpawner 패턴 재사용) + 색 스킬 1개 최초 언락
  — 약 8분
  --통로--
[방B: 뒷골목 — 색 복원 라이트 퍼즐]
  PaintableObject 벽화/간판 여러 개를 복원해야 문이 열리는 카운터 게이트
  (순서 무관, 전부 복원되면 오픈 — 신규 소형 스크립트 1개면 충분) +
  복원 도중 평×1~2 매복으로 순수 퍼즐이 되지 않게 함
  — 약 6분
  --통로--
[방C: 상점가 — 두 번째 전투]
  평×3, 움직이는 장애물(MovingObstacle 재사용) 활용한 회피 전투,
  방금 언락한 색 스킬 실전 사용 유도
  — 약 7분
  --좁은 통로--
[방D: 중앙 광장 — 클라이맥스]
  평×3~4 최종 웨이브 + 클리어 시 정육점 등불·간판 전체 색 복원 연출 + 계단
  — 약 6분
```

총 5개 노드(복도 포함), 약 30분. [[28 레벨 디자인]]의 "3~5개 노드" 기준 안에 들어옴.
