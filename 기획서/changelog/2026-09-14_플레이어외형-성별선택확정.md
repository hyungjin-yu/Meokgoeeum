# 플레이어 외형 스펙 확정 + 성별 선택 기능 신규 반영

## 배경

내일(9/15) 플레이어 캐릭터를 블렌더로 제작하기로 하면서, 기획서에 "현대적 복장"이라고만 되어있던 외형 스펙을 실제로 만들 수 있는 수준까지 구체화할 필요가 생김. 사용자와 직접 논의해서 확정.

## 결정 내용

- **색상 접근 — 거의 무채색 + 먹물 포인트만.** [[24 디자인 필러]] 필러 1("색은 감정의 증거다")을 캐릭터 외형에도 그대로 적용 — 캐릭터 자체는 흑백/회색 톤, 붓과 먹물만 진한 검정 포인트
- **의상 — 한복 실루엣 + 현대 소재 퓨전.** 배경(조선 풍 현대 도시)과 가장 직접적으로 어울리는 방향
- **성별 선택 기능 신규** — 플레이어가 게임 시작 시 남/녀 중 선택. **원래 기획서엔 전혀 없던 내용**, 이번에 처음 확정됨. 여성형을 먼저 제작하고 남성형은 나중에

`02 플레이어 시스템.md`의 "기본 정보"에 반영하고, "캐릭터 성별 선택" 소절 신규 추가 — 세이브 데이터/캐릭터 선택 UI/컷씬 대사 성별 중립 점검 등 후속 영향은 명시만 해두고 아직 착수 안 함.

## 한계

성별 선택에 따른 세이브 데이터 구조 변경, UI 설계, 컷씬 대사 검토는 전부 미착수 — 실제 구현 시점에 별도로 다뤄야 함.
