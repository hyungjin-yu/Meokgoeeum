# 먹괴음 광(범위형) 제작 완료 — 4종 변형 전체 완료

## 배경

[[07 UI & 아트 방향]] 계획대로 리깅된 `InkGolem_Pyeong_01`을 베이스로 한 마지막 변형종 "광"(범위형) 제작. 광은 "자기 주변 범위 전체 공격"하는 타입으로, 원/흡/분에 이어 이 변형종을 끝으로 먹괴음 5종(평/원/흡/분/광) 제작이 전부 완료됐다.

## 작업 전 예방 조치

원/흡/분에서 확립된 습관대로, 작업 시작 전 씬에서 분(Bun)을 먼저 제거했다(이미 export·커밋 완료 상태).

## 제작 내용

- Pyeong 베이스를 새로 import해 `InkGolem_Gwang_*`로 개명 (오브젝트/메쉬/머티리얼/Armature 데이터 블록 정리)
- **허리 에너지 고리:** 허리(Waist, Z≈0.70) 둘레에 토러스(major radius 0.38, minor radius 0.024)를 만들고 그 둘레에 바깥을 향하는 가시(콘) 8개를 균등 배치해 하나로 합침. 팔이 고리 안쪽 반지름(0.36) 안에 완전히 들어와서(팔 최대 반경 0.29) 클리핑 없이 통과하는 것을 바운딩 박스 실측으로 확인. 기존 `Waist` 본에 그대로 리지드 스키닝(새 본 불필요, 정렬 불일치 위험 자체가 없음)
- **머리 왕관 (사용자 추가 요청):** "머리에 뿔이든 뭐든 추가해서 차이점을 줘"라는 피드백으로 고리와 같은 콘 형태의 작은 가시 6개를 머리 위쪽에 왕관처럼 배치(반지름 0.115 머리 표면에서 바깥·위쪽으로 52도 각도, 길이 0.065). 고리와 같은 모티프를 반복해 "발산형" 테마의 통일감을 줌. 기존 `Head` 본에 리지드 스키닝
- 두 파츠 모두 기존 본(Waist/Head)에 부착했기 때문에 원/흡에서 겪은 "새 본을 메쉬와 같이 옮겨야 하는" 정렬 문제 자체가 발생하지 않음 — 분에서 Head2처럼 새 본이 필요한 경우와 달리, 이번엔 구조적으로 더 단순한 방식을 선택

## 교훈

- **새 파츠를 기존 본에 그대로 붙일 수 있으면(새 본이 필요 없으면) 정렬 불일치 버그 자체가 원천적으로 없다.** 분에서 겪은 "새 본을 메쉬와 같이 옮겨야 하는" 문제는 새 본을 만들 필요가 있는 경우에만 해당 — 가능하면 기존 본에 부착하는 설계가 더 안전하고 간단함
- **같은 모티프(가시 형태)를 반복 사용하면 새 파츠를 하나 더 추가할 때도 일관된 스타일을 유지하기 쉽다.** 고리에 쓴 콘 스파이크를 머리 왕관에도 그대로 재사용해 추가 제작 시간을 아끼면서 디자인 통일감도 얻음
- 사용자가 "부족하다"고 느낀 지점(머리가 밋밋함)을 구체적으로 짚어주면, 이미 확립된 기법(콘 스파이크 배치)을 재사용해 빠르게 대응할 수 있었음 — 새로운 기법을 고안하기보다 기존에 검증된 패턴을 재활용하는 것이 안전하고 빠름
