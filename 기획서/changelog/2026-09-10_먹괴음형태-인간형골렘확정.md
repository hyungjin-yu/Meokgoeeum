# 먹괴음 3D 형태 방향 확정 — 인간형 먹물 골렘

## 배경

[[07 UI & 아트 방향]] "다음에 확정할 것"의 마지막 두 항목 중 하나. [[03 먹괴음 - 적 설계]]의 부위별 색 변화 표(왼팔/오른팔/왼다리/오른다리/몸통/머리)가 이미 있어서, 형태는 이 6부위를 구분할 수 있는 구조여야 한다는 제약이 있었다.

## 방향 결정

인간형 먹물 골렘으로 확정 — 두 팔, 두 다리, 머리가 뚜렷한 인간형 실루엣에 끈적한 먹물이 뚝뚝 떨어지는 질감. 네발 짐승형이나 촉수형은 부위별 색 매핑과 어긋나서 제외.

## 제작 과정

1. **1차 형태** — 머리/몸통/팔/다리를 각각 하나의 타원체로만 표현한 단순 블롭형. 귀엽지만 사람보다는 스노우맨/로봇에 가깝다는 피드백("좀 더 사람 느낌이 나면 좋겠는데")
2. **2차 형태(현재)** — 몸통을 골반-허리-가슴 3단으로 잘록하게 잇고, 팔다리도 위팔-아래팔·허벅지-종아리로 관절을 나눠 인간 비율에 가깝게 재설계. 좌표를 손으로 하나씩 정하는 대신 `stack_vertical()` 헬퍼로 "이전 파츠 위에 일정 비율 겹쳐서 쌓기"를 코드가 직접 계산하게 만들어 처마 지등/좌판 유리등에서 반복됐던 "뜨는 파츠" 버그를 원천 차단
3. **재질** — 글로시한 완전 무채색(거의 검정) 재질 + 무표정한 창백한 눈동자 2개. 03번 문서의 "공통 특성: 색이 없는 회색/검정 외형"과 맞음

## 부위별 색 변화 구현 확인 (사용자 지적으로 발견)

처음엔 팔다리를 관절별로 여러 오브젝트(위팔/아래팔 등)로 나눠놓기만 하고 재질은 전부 `Mat_InkGolem_Body` 하나를 공유하고 있었음. 사용자가 "저 상태에서 어떻게 부위를 나눠서 색을 바꿔?"라고 지적 — 맞는 지적으로, 공유 재질을 바꾸면 몸 전체가 같이 바뀌는 구조였음.

**수정:** 머리/몸통/왼팔/오른팔/왼다리/오른다리 6개 독립 머티리얼로 분리하고, 관절별 오브젝트를 각자 속한 부위의 머티리얼에 재배정. 6색으로 임시 착색해 실제로 부위별 독립 변경이 되는지 검증. 이 과정에서 사용자가 "몸통도 색 바뀌나 봐야지 양팔·양다리·머리만 보면 어떡해"라고 추가 지적 — 몸통은 기본값이 이미 검정이라 테스트에서 빼먹고 넘어갔던 것을 발견, 몸통에도 눈에 띄는 테스트 색을 입혀 별도로 검증 완료.

## 부수 발견 버그

- 턱 밑 먹물 방울(`ChinDrip`) 오브젝트가 빌드 스크립트 실행 로그상으로는 생성된 것처럼 보였으나(`total parts: 22`) 실제 씬에는 존재하지 않았음(21개만 확인). 원인 불명 — Blender MCP 실행 중 마지막 오브젝트 생성이 유실된 것으로 추정. 재생성해서 해결, 원인 재현은 안 됨

## Unity 구현 시 주의 (다음 세션 필독)

이 골렘은 여러 마리가 동시에 존재하는 몹이다. 부위 머티리얼을 공유하는 구조라, `renderer.material`을 직접 수정하면 같은 색을 흡수한 다른 개체에도 전부 영향을 준다. 개체별로 독립된 색 상태를 가지려면 CLAUDE.md 코드 최적화 원칙대로 `MaterialPropertyBlock`으로 개체마다 따로 적용해야 함.
