# BrushWeapon 자체 소유 InputActions 누수 경고 수정

## 배경

[[changelog/2026-09-14_브러시웨폰-면검사]]에서 [[BrushWeapon]]이 `PlayerController`가 없을 때 자체 `PlayerInputActions`를 새로 만들어 쓰도록 바꿨는데, 큐브 프로토타입을 플레이해보니 콘솔에 "This will cause a leak and performance issues, PlayerInputActions.Player.Disable() has not been called" 경고가 떴음(스크린샷으로 확인, "이거 뜨는데").

## 원인

`OnDestroy()`에서 자체 소유 인스턴스를 정리할 때 `Dispose()`만 호출하고 `Disable()`은 안 부르고 있었음:

```csharp
private void OnDestroy()
{
    if (ownsInputActions) inputActions?.Dispose();
}
```

기존 [[PlayerController]]의 `OnDestroy()`를 보면 "Enable()과 반드시 짝을 맞춰 Disable()을 호출해야 한다"는 주석과 함께 `inputActions?.Disable()`을 명시적으로 호출하고 있었음 — `BrushWeapon`이 자체 인스턴스를 만드는 새 코드 경로에서 이 짝을 안 맞춘 게 실제 원인이었음(에디터 리플렉션 테스트 잔재가 아니라 진짜 코드 버그였음).

## 수정

`OnDestroy()`에서 `Dispose()` 전에 `Disable()`을 먼저 호출하도록 고침:

```csharp
private void OnDestroy()
{
    if (ownsInputActions)
    {
        inputActions?.Disable();
        inputActions?.Dispose();
    }
}
```

## 검증

수정 후 재컴파일 성공(`recompile_status` → `completed`, 에러 없음). 큐브 프로토타입을 다시 플레이해서 경고 재발 여부는 사용자 쪽에서 확인 필요.
