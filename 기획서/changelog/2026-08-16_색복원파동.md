# 2026-08-16 — 색 복원 파동 (v0.1 목표 ⑤, 마지막 단계)

## 배경

v0.1의 마지막 단계. [[11 셰이더 설계 - 색 복원 파동]] 원안은 Shader Graph + VFX Graph 기반.

## 중요한 설계 결정: Shader Graph 대신 C#

Shader Graph/VFX Graph 에셋은 직렬화 포맷이 복잡해서 텍스트로 직접 만들면 Unity가 못 여는 파일을 만들 위험이 큼 (지금까지 겪은 Cinemachine 씬 문제보다 훨씬 위험도 높음). 그래서 **같은 시각적 목표(파동이 퍼지며 색이 돌아옴)를 C# 코루틴 기반 오브젝트별 색 Lerp로 대체 구현**했음. 나중에 진짜 Shader Graph로 업그레이드하는 경로는 [[refactor/색 복원 파동 - Shader Graph 업그레이드]]에 별도로 정리해둠 (우선순위 낮음, 아트 방향 확정 후 착수 권장).

## 한 일

- **`PaintableObject.cs` 신규** — 회색 → 원래 색(`trueColor`) 코루틴 페이드. `Paint()` 호출 시 1회만 동작(중복 파동 안전)
- **`ColorWaveEffect.cs` 신규** — 파동 발생 지점에서 `OverlapSphere`로 주변 `PaintableObject`를 1번만 수집 → 거리순 정렬 → 파동 반경이 커짐에 따라 순서대로 `Paint()` 호출. 매 프레임 재조회 안 함(최적화 원칙)
- **`ColorOrbPickup.cs` 수정** — 구슬 획득 시 `ColorWaveEffect.PlayWave(위치)` 자동 호출
- **[[refactor/색 복원 파동 - Shader Graph 업그레이드]] 신규** — 나중에 실제 업그레이드할 때 참고할 방향/범위/우선순위 기록

## Unity에서 해야 할 일
