# 플레이어 이동에 가속/감속 추가

## 배경

회전 관련 버그 3건([[changelog/2026-09-10_플레이어-대시중회전스냅-수정]])과 카메라 순간이동 추적 버그([[changelog/2026-09-10_카메라-순간이동추적버그-수정]])를 고친 뒤에도 사용자가 "A, D를 누르거나 Tab으로 락온을 하면 순간 대시를 하는 느낌으로 이동이 된다"고 재차 리포트.

## 조사 과정

이번엔 카메라(Cinemachine) 쪽 원인을 의심해서 깊게 조사했다:

- `CinemachineOrbitalFollow.TrackerSettings.BindingMode` = `WorldSpace`(오프셋이 타겟 회전을 안 따라감), `HorizontalAxis.Recentering.Enabled` = `false` — 플레이어 회전이 카메라 오빗 각도나 숄더 오프셋을 흔드는 경로가 없음을 소스 코드 레벨(`CinemachineOrbitalFollow.cs`)로 확인
- Cinemachine의 실시간 프레임 단위 동작을 이 자동화 환경에서 직접 재현하려 했으나, `Time.frameCount`가 별도 `eval` 호출 사이에 전혀 진행되지 않는다는 걸 발견 — `CinemachineBrain.ManualUpdate()`는 내부적으로 이 프레임 번호로 "이미 갱신된 프레임"을 판단해서 건너뛰므로, 리플렉션으로 카메라 갱신을 강제할 방법이 없음(도구 한계로 인정하고 다음 단서로 이동)
- 대신 `PlayerController.Move()`가 입력이 들어오는 즉시 `moveSpeed`로 순간 가속하고, 입력이 없어지는 즉시 순간 정지한다는 걸(가속 곡선이 전혀 없음) 코드로 재확인 — 이게 A/D·락온 직후 "순간 대시" 감각의 유력한 원인으로 판단

## 수정

`PlayerController`에 `Vector3.SmoothDamp` 기반 속도 보간을 추가:

```csharp
Vector3 targetVelocity = hasInput
    ? (camForward * inputDir.z + camRight * inputDir.x).normalized * moveSpeed * speedMultiplier
    : Vector3.zero;
currentVelocity = Vector3.SmoothDamp(currentVelocity, targetVelocity, ref velocitySmoothRef, accelerationTime);
cc.Move(currentVelocity * Time.deltaTime);
```

`accelerationTime`(기본 0.1초) 인스펙터 노출 — 목표 속도까지 부드럽게 도달, 입력이 사라져도 즉시 멈추지 않고 서서히 감속.

## 검증

`Update()`를 리플렉션으로 15회 반복 호출하며 `currentVelocity.magnitude`를 매 스텝 기록:

```
step0:  speed=0.308
step4:  speed=2.970
step9:  speed=4.542
step14: speed=4.913 (moveSpeed=5에 근접)
```

입력 해제 후 10회 반복:
```
정지0: speed=4.631
정지4: speed=2.015
정지9: speed=0.455
```

즉시 5→0으로 뚝 끊기던 게, 이제 완만한 곡선으로 오르내림을 수치로 확인.

## 교훈

- **"카메라가 이상하다"는 리포트가 실제로는 카메라가 아니라 캐릭터 컨트롤러의 즉시-가속/즉시-정지 때문일 수 있다** — 자동화 환경에서 Cinemachine 내부 동작을 직접 검증하지 못하는 한계에 부딪혔을 때, 코드로 확실히 증명 가능한 다른 후보(가속 곡선 부재)로 관점을 옮긴 게 실제 개선으로 이어짐
- 이 자동화 환경은 `Time.frameCount`가 개별 `eval` 호출 사이에 멈춰있어서 Cinemachine처럼 프레임 번호 기반 중복 방지 로직이 있는 시스템은 리플렉션으로 강제 갱신이 안 된다 — 반면 `MonoBehaviour.Update()`처럼 프레임 번호에 의존하지 않는 일반 메서드는 리플렉션 반복 호출로 결정적 검증이 잘 됨(이번에도 `currentVelocity` 곡선을 그대로 실측)
