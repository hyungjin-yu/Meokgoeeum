# 먹괴음 골렘 — 뼈대(Armature) 추가

## 배경

먹괴음 기본형(평) 3D 형태를 확정한 직후, 사용자가 "먹괴음 골렘은 팔 다리가 따로따로 움직일 수 있어? 플레이어를 공격하는데 가만히 서서 공격하는건 이상하잖아"라고 지적. 당시 모델은 관절별로 오브젝트만 나눠뒀을 뿐 뼈대가 전혀 없어서, Unity로 가져가도 팔다리를 따로 움직이는 애니메이션이 불가능한 정적 상태였음 — 맞는 지적이었음.

## 작업 내용

- 척추(골반-허리-가슴-목-머리) + 팔다리 관절(위팔-아래팔-손, 허벅지-종아리-발)마다 총 17개 본으로 구성된 Armature 생성
- 본의 위치는 손으로 좌표를 다시 잡지 않고, 각 오브젝트의 실제 월드 바운딩 박스(상단/하단 Z)를 코드로 직접 읽어서 계산 — 지금까지 반복된 "뜨는 파츠" 버그의 원인이 전부 손으로 좌표를 맞추다 생긴 오차였던 것을 감안한 조치
- 각 블롭 오브젝트를 해당 본 하나에만 가중치 1.0으로 묶는 리지드 스키닝 적용 — 부위가 이미 개별 오브젝트로 나뉘어 있어 버텍스 웨이트 페인팅 없이도 정확히 맞물림
- 오른팔을 앞으로 굽히고 왼쪽 허벅지를 들어올리는 테스트 포즈를 적용해 실제로 팔다리가 몸통과 독립적으로 움직이는지 스크린샷으로 확인. 이후 포즈를 0으로 되돌려 원래 자세로 뒤틀림 없이 복귀하는지도 확인

## 한계 (정직하게 기록)

리지드 스키닝이라 부드럽게 이어지는 스킨 메쉬가 아니다. 팔꿈치·무릎처럼 크게 꺾이는 관절에서는 블롭 두 개가 서로 다른 각도로 회전하면서 이음매에 틈이 보일 수 있음. 지금은 이 모델 자체가 블롭을 겹쳐 만든 스타일이라 크게 위화감은 없지만, 실제 공격 애니메이션에서 팔꿈치를 크게 굽혔을 때 틈이 눈에 띄면 메쉬를 하나로 합치고 버텍스 웨이트를 손으로 칠하는 추가 작업이 필요하다.
