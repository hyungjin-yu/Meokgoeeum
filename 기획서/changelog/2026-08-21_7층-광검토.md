# 2026-08-21 — 7층 검토 (광 첫 등장, 구현은 다음 세션)

## 배경

6층 완료로 큐브 6면이 처음으로 전부 완성된 뒤, 7층("고요한 광장")을 검토. 구현은 하지 않고 검토만 하고 오늘 세션 종료.

## 검토 결과

**7층은 지금까지와 다르게 새 적 타입(먹괴음 - 광, 광역형) 코드 자체가 없어서 새로 만들어야 함** — 지금까지(평/원/흡/분)는 다 구현돼 있었지만 광만 없음.

- **AI ([[13 먹괴음 AI 설계]])**: `BT_Enemy_Gwang` — Selector(쿨다운 다 찼으면 AOE 공격(반경 3f `Physics.OverlapSphere`), 아니면 `MoveToPlayer`). 평보다도 단순한 BT
- **프레임 데이터 ([[27 전투 프레임 데이터]])**: 텔레그래프 25f(가장 김 — "가장 위협적"), 판정 8f, 후딜 20f. **바닥에 원형 경고 범위 인디케이터**가 특징 — 기존 `DamageZone`/`InkProjectile` 같은 런타임 프리미티브 생성 패턴으로 구현 가능해 보임
- **밸런스 ([[14 밸런스 수치 시트]])**: 광 전용 수치 없음 — `EnemyPyeong`(공격력 8)/`EnemyWon`(10) 참고해서 비슷한 수준으로 잡을 예정
- **계단 조건**: "광 처치" — 기존 `RoomClearGate`+`Stairs` 그대로 재사용 가능(새 로직 불필요)

## ⚠️ 기획서 불일치 발견

`03 먹괴음 - 적 설계`의 "층별 등장 테이블"엔 광이 **8~11층**부터 등장한다고 되어있는데, `19 층별 상세 설계`엔 **7층**에 광이 등장한다고 명시돼 있음 — 서로 어긋남. 지금까지 관행대로 더 상세한 19번 문서를 기준으로 진행 예정. 나중에 기획서 정리할 때 이 불일치를 조정할 것.
