## 발견한 버그 — 환경 아트 FBX 전체의 축 보정 미적용

`Building_StreetUnit_Demo.fbx`(3칸 조립 참고용 건물)를 방A 서쪽 벽(문 없는 통짜 벽, X=-5)에 붙이려고 `Transform.SetPositionAndRotation()`으로 Y축 90도 회전을 절대값으로 지정했더니, 건물이 옆으로 완전히 넘어진 것처럼 배치됨(실측: 기둥의 월드 Y 범위가 0.28m로 나옴 — 원래 세로로 2.6m여야 할 기둥이 가로로 누움).

원인 조사:
- 원본 FBX 에셋을 직접 로드해서 확인한 결과, 프리팹 루트의 기본 로컬 회전이 `(270, 0, 0)`(Blender Z-up → Unity Y-up 변환용 보정 회전)으로, **임포트 시 이 보정이 메쉬 데이터에 구워지지 않고 루트 Transform 값으로만 남아있었음**
- `SetPositionAndRotation()`으로 회전을 절대값 지정하면 이 보정 회전을 통째로 덮어써버려서, 실제로는 "Y축 90도 회전"이 아니라 "보정 회전을 지우고 그 자리에 엉뚱한 회전을 넣은" 상태가 됨
- `RedLantern_01.fbx`에도 동일하게 `(270,0,0)` 잔여 회전이 있어서 같은 문제가 재현됨
- Environment 폴더 전체(BuildingModules/Lanterns/Props, 18개 FBX)의 Model Importer를 조회한 결과 **전부 `bakeAxisConversion=false`** — 이번에 배치를 시도한 2개만의 문제가 아니라 이 세션에서 만든 환경 아트 FBX 전체에 해당하는 구조적 버그였음

## 수정

18개 FBX 전부 `ModelImporter.bakeAxisConversion = true`로 설정 후 `SaveAndReimport()` 일괄 실행. 재임포트 후에도 루트에 `(90,0,0)` 근처의 잔여 회전이 남지만(완전한 identity는 아님), 실측 결과 자식 메쉬가 이미 그에 맞게 구워져 있어 최종 형태는 올바르게 똑바로 섬을 확인(바운딩 박스 실측: 재임포트 전후로 크기 `(6.30, 3.20, 2.25)` 동일, Y가 여전히 3.20으로 세로축 유지).

**교훈 — 이 잔여 회전 때문에 배치 코드는 반드시 다음 패턴을 따라야 함:**

```csharp
// ❌ 위험 — prefab 기본 보정 회전을 통째로 덮어씀
obj.transform.SetPositionAndRotation(pos, Quaternion.Euler(0, yaw, 0));

// ✅ 안전 — 기본 회전 위에 원하는 추가 회전만 곱해서 적용
obj.transform.position = pos;
obj.transform.rotation = Quaternion.Euler(0, yaw, 0) * obj.transform.rotation;
```

## Face0ArtDressingBuilder.cs 신규 (에디터 전용)

[[Floor1CorridorBuilder]]와 같은 패턴(재실행 안전, 이전 생성물 삭제 후 재생성)의 배치 스크립트. `SC_Face_0`의 방A(10x10, 서쪽 벽 통짜)에:

- `Building_StreetUnit_Demo` — 서쪽 벽에 뒷면을 붙이고 정면이 방 안쪽(+X)을 보도록 배치. 좌표는 손으로 어림하지 않고, "원점 + 회전만 적용한 상태"로 임시 인스턴스를 만들어 실제 바운드를 먼저 측정한 뒤 역산(뒷면 X=-0.95 → 벽 X=-5에 맞춰 평행이동, 길이 중심 Z=-3.0 → 방 중심 Z=0으로 이동)
- `RedLantern_01` — 건물 정면 처마 밑(재확인된 건물 정면 위치 X≈-2.75 근처)에 배치. 정육점 골목=빨강([[changelog/2026-09-10_색오브젝트매칭-확정]])

색/발광 배선(`PaintableObject` 연동, `MaterialPropertyBlock` 기반 부분 색칠)은 의도적으로 이번 범위에서 제외 — "다음 작업" 목록에 이미 별도 항목으로 있음(11번 셰이더 확장, 부위별 MaterialPropertyBlock).

## 검증

Scene View 카메라를 방A 내부로 이동시켜 스크린샷 2장 촬영(`capture_scene_view`). 결과: 건물이 벽에 정확히 맞물려 똑바로 서있고, 기둥·벽 패널·창문(프레임+유리)·처마 지붕이 전부 비율에 맞게 보임. 등불은 처마 밑, 창문 위쪽에 정확히 걸려있는 것을 확인. 기존 블록아웃(회색 구체/큐브 장애물, 벽)과 자연스럽게 겹쳐 보임 — 첫 "전체 그림" 목표 달성.
