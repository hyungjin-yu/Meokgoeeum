# 2026-08-18 — 색 복원 파동 타이밍 조정 검증 완료, v0.1 프로토타입 전체 완성

## 배경

`2026-08-16_색복원파동-타이밍조정.md`에서 원인 분석 후 `PaintableObject.fadeDuration`을 0.5→0.2초로 조정. 씬에 이미 배치된 테스트 Cube 4개는 스크립트 기본값이 자동 반영 안 되므로 Inspector에서 수동으로 Fade Duration=0.2 변경 필요하다고 안내했었음.

## 한 일

- 사용자가 Inspector 반영 후 재테스트 → 파동이 거리순으로 순서대로 퍼지는 게 눈에 보이는 것 확인 ("얼추 확인되었네")
- **v0.1 목표 ①~⑤(이동/카메라, 붓 3타 콤보, 먹괴음-평 AI, 색 구슬 드랍/획득, 색 복원 파동) 전부 코드 + 실제 Unity 테스트까지 완료.** CLAUDE.md 체크리스트 갱신
- 재발 방지용으로 CLAUDE.md에 **"순차 효과 '타이밍이 안 보임' 버그 진단 원칙"** 신설 — 여러 대상에 시간차를 두고 순차 효과를 주는 시스템에서 "동시에 일어나는 것처럼 보인다"는 리포트가 오면, 로직 버그로 단정하기 전에 `개별 전환 소요 시간 vs 대상 간 트리거 시간차` 비율부터 확인하라는 내용 (2026-08-16 조사 사례를 실제 예시로 링크)
