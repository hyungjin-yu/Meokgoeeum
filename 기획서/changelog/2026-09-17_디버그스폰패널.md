# 디버그 스폰 패널 — 원하는 몹 소환 + 색 구슬 종류/개수 지급

## 배경

사용자 요청: "유니티 내부 시스템으로 내가 원하는 몹 소환, 색 구슬 종류 및 개수 설정가능하게 만들어줘." 기존 [[DebugOrbCheat]]는 F1~F3로 빨강/파랑/노랑 구슬을 1개씩만 지급할 수 있었고, 몹을 원하는 대로 소환하는 기능은 아예 없었음.

## 작업

- **`CubeEnemyConverter.cs` 신규** — [[EncounterSpawner]].SpawnWave()에만 있던 "평지 프리팹 → CubeEnemy* 즉석 변환" 로직(flat 종 스크립트/EnemyHealth/NavMeshAgent 제거 → 대응하는 CubeEnemy* 부착 → cubeCenter/faceNormal/cubeHalfExtent/target 설정)을 공용 정적 메서드로 분리. `EncounterSpawner`는 이 메서드를 호출하도록 리팩터(동작 100% 동일, 코드 51줄 → 4줄). 덤으로 변환 후 위치를 faceNormal 기준 수학적 표면에 정확히 재보정하는 단계 추가 — 호출하는 쪽이 정확한 면 좌표를 몰라도 안전하게 면 위에 붙음.
- **`DebugSpawnPanel.cs` 신규** — F5로 여닫는 IMGUI 패널. `CubeSurfaceWalker`(플레이어)만 있으면 cubeCenter/cubeHalfExtent/현재 면 법선을 전부 거기서 가져와서 따로 설정할 필요 없음.
  - 몹 소환: 5종(평/원/흡/분/광) 버튼 — 플레이어 정면 4유닛 위치에 평지용 프리팹을 그대로 소환하면 `CubeEnemyConverter`가 자동으로 큐브 면 버전으로 변환.
  - 색 구슬 지급: 6색(빨/파/노/초/보/검) 각각 개수 입력창 + 지급 버튼 — 원하는 개수만큼 `ColorSystemManager.AddOrb()` 반복 호출(기존 5슬롯 FIFO 상한은 그대로 존중).
  - `DebugOrbCheat`와 동일하게 `UNITY_EDITOR || DEVELOPMENT_BUILD`로 감싸서 릴리즈 빌드엔 안 들어감.

## 검증

리플렉션으로 직접 호출해 확인:
- `SpawnMob(wonPrefab)` → `EnemyWon(Clone)`이 정확히 플레이어와 같은 면(z=18, faceNormal=(0,0,1))의 수학적 표면 좌표(0, 4, 18)에 소환됨, `cubeCenter`/`cubeHalfExtent`(17)/`target` 전부 정확히 설정됨 확인.
- `GiveOrbs(Green, "3")` → `ColorSystemManager.GetHeld(Green)`이 정확히 3으로 반영됨.
- ⚠️ 소환 직후 `GetComponents()`로 보면 옛 flat 컴포넌트(NavMeshAgent/EnemyHealth/EnemyWon)가 아직 안 지워진 것처럼 보였는데, 이건 `Destroy()`가 프레임 끝에 지연 처리되는 것과 이 자동화 환경의 기존에 알려진 "Time이 멈춰있을 수 있음" 문제(2026-09-11 발견)가 겹친 테스트 환경 특유의 현상 — `EncounterSpawner`가 이미 검증된 것과 완전히 동일한 코드라 실제 플레이(시간이 정상적으로 흐름)에서는 문제없이 지워질 것으로 판단. 사용자가 실제 플레이로 F5 패널을 열어 소환해보고 몹이 정상적으로 동작하는지(NavMesh 경고 뜨는지, 실제 추적/전투가 되는지) 최종 확인 필요.
