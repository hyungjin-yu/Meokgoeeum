# 2026-08-25 — 1층 "입장 복도" & "방B" 콘텐츠 착수

## 배경

`CLAUDE.md`에 오래 남아있던 "1층의 '방B(색 구슬 파동 트리거)'·'입장 복도(튜토리얼 유도)'도
아직 별도 콘텐츠 작업 필요" 항목 진행. [[28 레벨 디자인 - 인카운터 페이싱과 블록아웃]] 1층
블록아웃(`[입장] → [방A] → [방B] → [출구]`) 중 방A(전투)/계단은 이미 완료돼있고, 입장/방B만
비어있던 상태.

## 스코프 컷

[[15 튜토리얼 설계]]는 6단계 전체(팝업 힌트 6종, 발자국 이펙트, ESC 스킵 확인창, Tab Lock-On
연동)를 정의하지만, 프로젝트에 팝업 UI 시스템이 아예 없어서 오늘은 **공간/메커니즘**만
만들고 **연출 폴리시(팝업, 이펙트, 스킵창)는 다음으로 미룸**. `CLAUDE.md`에 별도 항목으로
다시 남김.

## 한 일

- **`MovingObstacle.cs` 신규** — [[15 튜토리얼 설계]] 2단계("느리게 움직이는 장애물, 피해야
  통과 가능 → 구르기 자연스럽게 학습") 구현. 대미지/넉백 없음(튜토리얼 초입에 패널티는
  "환경으로 자연스럽게 유도" 원칙과 인카운터 체크리스트 5번 "실수를 용서하는 여유"에 안 맞음)
  — 그냥 단단한 Collider가 통로를 왕복하며 막을 뿐, CharacterController가 물리적으로 못
  지나가고 밀려나는 것만으로 "피해야 한다"는 감각을 줌
- **`TutorialCheckpoint.cs` 신규** — 팝업 UI가 없어서 대신 Console 로그로 "이 구간을 실제로
  지나갔는지"만 검증하는 최소 버전. 나중에 팝업을 붙일 때 이 스크립트에 훅을 걸면 됨
- **`logic/1층 콘텐츠 - 입장 복도 & 방B 씬 설정.md` 신규** — Unity 수동 배치 가이드.
  방B는 새 스크립트 없이 기존 [[PaintableObject]]/[[ColorWaveEffect]]를 그대로 재사용
  (간판 하나 배치만 하면 자동으로 동작 — 4층/2층에서도 같은 패턴)
