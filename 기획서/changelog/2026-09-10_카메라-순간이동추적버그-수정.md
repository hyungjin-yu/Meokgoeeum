# 플레이어 순간이동 시 카메라 추적 실종 버그 수정

## 배경

플레이어 회전 버그 3건([[changelog/2026-09-10_플레이어-대시중회전스냅-수정]]) 수정 후 재테스트를 요청했는데, 사용자가 같은 영상 파일 경로에 새로 녹화한 영상을 보내며 "새 버그로 덮어씌웠다"고 알려줌. ffmpeg로 프레임을 뽑아 확인.

## 증상 (영상 분석)

1. 여러 먹괴음(5~6마리)이 플레이어를 완전히 둘러싸고 근접
2. 몇 프레임 뒤 카메라가 급격히 멀어지기 시작 — 지면이 화면에서 사라질 정도로 계속 줌아웃
3. 이후 ~10프레임(약 1.2초) 동안 플레이어가 허허벌판에 뜬 아주 작은 점으로 보이는 채 완전히 고정 — 회복 안 되고 그대로 얼어붙음

## 원인

몹떼에 둘러싸여 플레이어가 사망 → `GameOverManager` → `CubeMapManager.ReloadCurrentFace()` → `TeleportPlayerToSpawnPoint()`가 실행되는 흐름은 기존에 확인된 대로였는데, 이 마지막 메서드가:

```csharp
player.transform.SetPositionAndRotation(spawnPoint.transform.position, spawnPoint.transform.rotation);
```

로 플레이어를 **직접 순간이동**시키면서, Cinemachine(3.1.6)에 "이건 순간이동이다"라고 알려주는 `CinemachineCore.OnTargetObjectWarped()` 호출이 빠져있었다. Cinemachine의 팔로우 카메라는 이 호출이 없으면 위치 변화를 "그냥 엄청 빠르게 이동한 것"으로 해석해서 평소의 감쇠(damping) 속도로 새 위치를 부드럽게 뒤쫓아가려고 시도한다 — 순간이동 거리가 충분히 크면(면이 통째로 바뀌는 경우) 이 추격이 정상적으로 수렴하지 못하고 계속 멀어지다가 길을 잃는 것으로 보임.

같은 패턴(`player.transform.position = ...` 직접 대입, 워프 알림 없음)이 `TutorialSkipManager.cs`(튜토리얼 스킵 이동)에도 있어서 동일하게 수정.

## 수정

`CinemachineCore.OnTargetObjectWarped(player.transform, positionDelta)`를 두 위치 모두에 추가:

- `CubeMapManager.TeleportPlayerToSpawnPoint()` — 면 재진입/재시작 시 플레이어 이동
- `TutorialSkipManager`의 스킵 이동 코루틴 — 튜토리얼 스킵 시 플레이어 이동

## 검증

- 수정 후 재컴파일 성공, 콘솔 에러 없음
- (실제 사망→리스폰 재현 테스트는 사용자의 다음 플레이 확인 필요 — 이번엔 코드 근거가 명확해서(Cinemachine 문서화된 표준 패턴 누락) 곧바로 수정)

## 다른 곳도 점검

`FindGameObjectWithTag("Player")`/`GameObject.Find("Player")`와 `transform.position` 직접 대입이 같이 쓰이는 곳을 전체 검색해서 위 2곳이 전부임을 확인 — 다른 순간이동 경로는 없음.

## 교훈

- **Cinemachine으로 추적되는 오브젝트를 `transform.position`으로 직접 순간이동시킬 땐 항상 `CinemachineCore.OnTargetObjectWarped()`를 같이 호출해야 한다.** 짧은 거리 이동은 감쇠가 알아서 따라잡아서 티가 잘 안 나지만, 면 전환처럼 먼 거리를 한 번에 이동하면 카메라가 실종되는 형태로 드러난다 — "플레이어 위치를 직접 바꾸는 코드"를 새로 짤 때마다 체크리스트에 넣을 것
- 사용자가 같은 파일 경로에 영상을 다시 녹화해서 보내는 패턴("아까 그 경로로 다시 봐봐")을 쓴다 — 매번 다시 읽어야 함(캐시된 이전 프레임을 재사용하면 안 됨)
