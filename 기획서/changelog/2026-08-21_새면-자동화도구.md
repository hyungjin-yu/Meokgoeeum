# 2026-08-21 — 새 면 만들기 자동화 도구

## 배경

사용자가 "새로운 면(Scene)을 할 때마다 RoomClearGate+Stairs며, 기본 세팅 과정이 너무 귀찮은데 자동화할 순 없어?"라고 요청. 1~6층 만들면서 매번 반복했던 절차(씬 생성, Addressable 등록, CubeFaceData 생성, GameState 연결, RoomClearGate+Stairs 배치)를 살펴보고 자동화 범위를 제안 → "둘 다"(프리팹 + 전체 자동화 스크립트) 선택.

## 한 일

- **`Assets/Scripts/Editor/FaceBootstrapWindow.cs` 신규** — `MG > 새 면 만들기 (Face Bootstrap)` 메뉴로 여는 에디터 창. 씬 파일 번호 + Face Index(0~5) 입력하고 버튼 누르면:
  1. 새 씬 생성 (`SC_Face_N`)
  2. `Ground`+`SpawnPoint` 배치
  3. `Stairs`(트리거 콜라이더, **Start Active 기본 꺼짐** — 6층에서 겪은 실수를 코드로 원천 차단)
  4. `RoomClearGate`(`Stairs` 자동 연결)
  5. 씬 저장
  6. Addressable 등록
  7. `CubeFaceData` 에셋 생성
  8. `GameState.faceData` 배열에 자동 연결

  까지 전부 자동 처리. 그 이후(적/장식 배치, Bounds Size 조정)만 손으로 하면 됨.
- **[[logic/새 면 자동화 도구]] 신규** — 사용법, 확인할 것, 알려진 한계 정리
- **프리팹은 만들지 않음** — 손으로 하면 30초짜리 간단한 작업(오브젝트 2개 선택해서 Project 창에 드래그)이라, `.prefab` 파일을 텍스트로 직접 만드는 것보다(GUID/직렬화 형식을 손으로 맞춰야 해서 오히려 위험) 사용자가 직접 만드는 게 더 안전하다고 판단 — 대신 훨씬 강력한 전체 자동화 스크립트에 집중함

## ⚠️ 아직 실제로 테스트 안 됨

에디터 자동화 스크립트라 Claude가 직접 Unity를 실행해서 테스트할 방법이 없습니다. Addressables 에디터 API(`AddressableAssetSettingsDefaultObject`, `CreateOrMoveEntry` 등)는 버전별로 시그니처가 조금씩 다를 수 있어서, **처음 실행했을 때 컴파일 에러나 실행 중 에러가 날 가능성이 있음** — 그러면 바로 에러 메시지 캡처해서 알려주면 고칠 것.
