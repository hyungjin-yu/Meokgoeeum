# 2026-08-25 — 보스 DPS "실효 교전 비율 40%" 가정 실측용 계측 추가

## 배경

[[14 밸런스 수치 시트]] "보스 DPS 역산 검증"은 "보스 공격 회피/포지셔닝으로 실제 교전 가능 시간은
전체의 약 40%"라는 **감으로 잡은 가정**을 근거로 1페이즈 처치 시간(≈66초)을 역산해뒀고, 문서 자체가
"v0.1 이후 가장 먼저 재보정해야 할 값"이라고 명시함. v0.1이 완성된 지금, 실제로 재보정하려면 먼저
실측 데이터가 있어야 함.

## 확인한 것

계측을 추가하기 전에, 문서의 이론 계산이 실제 코드와 아직도 일치하는지 먼저 확인:
- `BrushWeapon.cs`의 `attackPower`(10) × `DamageMultiplier`(0.6/0.7/1.0) = 6+7+10 = 23댐 — 문서와 일치
- 프레임 합산(Startup+Active+Recovery, 73f/60=1.22초) — 문서와 일치
- → 순수 콤보 DPS 18.9/초 상수는 **아직 유효**, 그대로 실측 비교 기준으로 씀

## 한 일

`BossHealth.cs`에 최소 계측 추가 — 별도 로깅 시스템(`PlaytestLogger`, [[30 플레이테스트 & 밸런싱 검증 계획]]에
개념만 있고 아직 미구현) 없이, Console 로그만으로 바로 확인 가능하게 함:

- 첫 `TakeDamage()` 호출 시각을 "전투 시작"으로 기록
- `Die()` 시점에 경과 시간 계산 → `실측 실효 DPS = maxHP(500) ÷ 경과시간`
- `역산된 실효 교전 비율 = 실측 실효 DPS ÷ 18.9(순수 콤보 DPS)` — 문서의 40% 가정과 직접 비교되는 형태로 로그 출력

## 검증

**[2026-08-25]** Unity 컴파일 에러 없음 확인 완료.

## 아직 안 한 것

**실제 플레이가 있어야 값이 나옴** — 다음에 보스전을 처치까지 한 번 플레이하면 Console에
`=== 보스 DPS 실측 결과 ===` 로그가 뜨고, 거기 나온 교전 비율을 40%와 비교해서 [[14 밸런스 수치 시트]]의
가정을 실측치로 교체하면 됨. 플레이 실측은 다음 세션(또는 사용자가 원할 때) 진행.
