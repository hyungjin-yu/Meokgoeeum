# 큐브 던전 방A~D — 웨이브 스포너 + 장식 요소 추가

## 배경

[[changelog/2026-09-15_실제던전-큐브면포팅-1차]]에서 방마다 적을 처음부터 전부 동시 배치하는 단순화를 스코프 밖으로 뺐었는데, 사용자가 이어서 착수 요청. [[EncounterSpawner]](웨이브 시간차 등장)와 [[MultiRoomFloor1Builder]] 원본의 장식 요소(벽화/장애물/숨겨진 구슬)를 큐브 면 버전에 실제로 반영.

## 결과물

- **`EncounterSpawner.cs` 수정** — 큐브 면 모드 필드(`cubeCenter`/`cubeFaceNormal`/`cubeHalfExtent`/`cubeTarget`) 추가. `cubeCenter`가 설정돼 있으면 `enemyPrefabs`에 평소처럼 평지용 `EnemyPyeong.prefab`을 그대로 넣어도, 스폰 시점에 [[CubeEnemyPyeongTestBuilder]]와 동일한 패턴(NavMeshAgent/EnemyPyeong/EnemyHealth 제거 → CubeEnemyPyeong 부착)으로 즉석 교체합니다. 웨이브 생존 판정용 리스트를 `List<EnemyHealth>`에서 `List<GameObject>`로 일반화(`Destroy()`되면 `null`이라는 성질은 평지/큐브 몹 둘 다 동일하게 성립).
- **`CubeFaceRoomBuilder.cs`**:
  - `BuildWaveSpawner()` 신규 — 방 중앙에 큐브 면 모드 `EncounterSpawner`를 세우고, `enemiesPerWave = {1,1}` 같은 배열로 웨이브별 마리 수·스폰 위치(원형 배치)를 구성. 원본 `MultiRoomFloor1Builder.BuildWaveSpawner()`와 같은 패턴을 면 법선 기준으로 일반화.
  - `BuildMural()` 신규 — 장식용 [[PaintableObject]]를 면 위에 얇게 눕혀서 배치(원본은 세워진 그림이지만 "바닥 문양"으로 단순화).
  - `BuildRoomObstacle()` 신규 — [[MovingObstacle]]을 면 위에 배치. `MovingObstacle`이 `transform.right` 기준으로 왕복하는 구조라, 벽 빌더와 같은 회전 관례(`LookRotation(v, normal)`, 로컬 X=u축)를 그대로 쓰면 자동으로 방의 u축(가로) 방향으로 왕복함 — 코드 수정 없이 그대로 재사용됨.
  - 방A: 튜토리얼 전투를 1+1 2웨이브로 전환 + 벽화/숨겨진 구슬 곁가지(원본 `BuildRoomASidePath`) 추가, 좌클릭 공격 힌트(`showFirstAttackHint`)도 원본처럼 1웨이브에 연결.
  - 방B: 1+1 2웨이브 + 장식 벽화 3개(게이트 아님, 순수 장식 — 원본처럼 `ColorWaveEffect` 반경 문제로 진짜 퍼즐 게이트로는 안 씀).
  - 방C: 2+1 2웨이브 + 왕복 장애물 2개.
  - 방D: 2+2 2웨이브 + 클라이맥스 벽화 2개.

## 검증

- 재컴파일 에러 없음, `BuildFromCLI()` 재실행 성공.
- 4개 스포너 전부 `waves=2`, `cubeCenter` 설정됨, 올바른 면 법선 확인. 벽화 6개(A:1, B:3, D:2), 장애물 2개(C), 구슬 스포너 1개(A) 생성 확인.
- **Play 모드 진입 후 실제 웨이브 1이 스폰한 적을 직접 검사** — `CubeEnemyPyeong` 컴포넌트로 정상 교체됨(잔존 `EnemyPyeong`/`NavMeshAgent` 0개), `faceNormal`/`cubeCenter`/`target` 전부 올바르게 설정, `CurrentHP=100` 정상. `EncounterSpawner`의 큐브 면 즉석 교체 로직이 실제로 작동함을 확인.
- Scene View 스크린샷으로 방B 상단면에 배치된 벽화(붉은 사각형) 육안 확인.

## 알려진 소음 (버그 아님)

- `EncounterSpawner.Start()`의 "씬에 스포너가 2개 이상 있으면 경고" 진단이 이 씬에서는 항상 뜸(4개 방이 전부 같은 씬에 동시 존재하는 게 큐브 구조의 정상 상태라서) — 원래 이 경고는 평지 던전에서 씬이 중복 로드됐을 때를 잡기 위한 것이라 큐브 프로토타입에서는 거짓 양성. 당장은 안 건드림(경고일 뿐 동작에 영향 없음).
- `HintPopupManager.Instance가 없어서 힌트를 못 띄움` 경고도 뜸 — 이 프로토타입 씬엔 `GameSystems`(전역 매니저 모음)가 없어서 원래 예상된 동작.

## 한계

- 웨이브 2까지 실제로 시간차를 두고 스폰되는지, 웨이브 다 죽인 뒤 게이트가 실제로 열리는지는 실시간 대기가 필요해서 이 자동화 환경에선 재검증 못 함 — 사용자가 직접 Play로 확인 필요.
- `HiddenOrbSpawner`의 구슬 스폰 높이 오프셋(`Vector3.up * spawnHeightOffset`)이 월드 Y축 고정이라, 옆면(+Z 등)에서는 "면 바깥쪽"이 아니라 세계 기준 위쪽으로 살짝 치우쳐 스폰됨 — 오프셋이 작아서(0.3) 육안상 크게 티는 안 나지만 완전히 정확하진 않음. 필요하면 나중에 면 법선 기준으로 고칠 것.
