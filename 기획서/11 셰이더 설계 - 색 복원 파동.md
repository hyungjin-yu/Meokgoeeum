# 셰이더 설계 — 색 복원 파동

> 2026-03-23 초안 | 2026-05-29 Unity 6.3 LTS URP Shader Graph + VFX Graph로 전환

## 개요

색 구슬 획득 시, 획득 지점에서 구형으로 퍼져나가며 해당 색이 복원되는 연출.
Unity 6.3 URP **Shader Graph** + **VFX Graph** 기반 구현.

## 동작 원리

```
1. 구슬 획득 지점의 World Position을 머티리얼 파라미터로 전달
2. Shader Graph에서 각 픽셀의 World Position과의 3D 거리 계산
3. C# 코루틴으로 _WaveRadius 값을 시간에 따라 증가
4. 거리 < _WaveRadius 인 픽셀 → 색 복원 상태(컬러 텍스처)로 전환
5. 경계 부분에 Smoothstep 처리 (번짐 효과)
6. VFX Graph로 파동 경계에 파티클 이펙트 추가
```

## Shader Graph 파라미터 구조

```
// Material 프로퍼티
_WaveOrigin   : Vector3    ← 구슬 획득 월드 좌표
_WaveRadius   : Float      ← C# 코루틴으로 증가 (0 → MaxRadius)
_TargetColor  : Color      ← 복원할 색
_EdgeSoftness : Float      ← 경계 부드러움 (0.05 ~ 0.3 권장)
_GrayTex      : Texture2D  ← 회색 텍스처
_ColorTex     : Texture2D  ← 컬러 텍스처

// Shader Graph 노드 흐름
dist   = Distance( Position(World), _WaveOrigin )
mask   = Smoothstep( _WaveRadius, _WaveRadius - _EdgeSoftness, dist )
output = Lerp( Sample(_GrayTex), Sample(_ColorTex) * _TargetColor, mask )
```

## C# 제어 코드

```csharp
// ColorWaveEffect.cs
public class ColorWaveEffect : MonoBehaviour
{
    [SerializeField] float waveDuration = 1.5f;
    [SerializeField] float maxRadius = 30f;
    [SerializeField] VisualEffect vfxPrefab;

    public void PlayWave(Vector3 origin, Color targetColor)
    {
        foreach (var renderer in GetComponentsInChildren<Renderer>())
        {
            var mat = renderer.material;  // Dynamic Material Instance
            mat.SetVector("_WaveOrigin", origin);
            mat.SetColor("_TargetColor", targetColor);
            StartCoroutine(AnimateWave(mat));
        }

        var vfx = Instantiate(vfxPrefab, origin, Quaternion.identity);
        vfx.SetVector3("Origin", origin);
        vfx.SetVector4("Color", targetColor);
    }

    IEnumerator AnimateWave(Material mat)
    {
        float elapsed = 0f;
        while (elapsed < waveDuration)
        {
            float radius = Mathf.Lerp(0f, maxRadius, elapsed / waveDuration);
            mat.SetFloat("_WaveRadius", radius);
            elapsed += Time.deltaTime;
            yield return null;
        }
        mat.SetFloat("_WaveRadius", maxRadius);
        // 색 복원 완료 이벤트 발행
        ColorSystemManager.Instance.OnWaveComplete();
    }
}
```

## VFX Graph 파동 이펙트

```
에셋 이름: VFX_ColorWave
- Output: GPU Particle (Sphere Surface 스폰)
- 스폰 반경: C#에서 _WaveRadius와 동기화 (SetFloat)
- 파티클 색: TargetColor
- Lifetime: 0.3 ~ 0.8초 (랜덤)
- 크기: 작게 시작 → Fade Out
```

## APV 연동 (조명 변화)

```
색 복원 완료 시:
  1. 해당 구역의 Light Probe Group 색 온도 변경
  2. APV Bake 데이터는 미리 복수 상태로 준비
  3. ColorSystemManager에서 ProbeVolume 파라미터 전환
     → 완전 실시간은 아니지만, 준비된 상태 전환으로 분위기 변화 연출
```

## 유의사항

- 구역 내 모든 Renderer에 `renderer.material` (인스턴스) 사용 필요 — `sharedMaterial` 수정 금지
- 여러 색 파동이 겹칠 경우 마스크를 Texture2D에 누적 기록 (마스크 레이어 구조)
- VFX Graph는 Unity 6.3 URP에서 지원됨 — HDRP 전용 노드 사용 주의

## 셰이더 확정 사항

- **색 마스크 레이어:** Texture2D 채널 활용 → 색 누적 기록 영구 유지
- **파동 후 색 유지:** 영구 유지 (_WaveRadius = maxRadius 고정 상태)
- **복수 파동 동시 재생:** 가능 (각각 독립적인 Material 인스턴스)
