# 맵 시스템 — 큐브 구조

> 2026-05-29 재작성

## 큐브 맵 개념

- 전체 맵은 **하나의 정육면체(큐브)**로 구성
- 6개의 면 = 6개의 독립적인 3D 구역
- 플레이어가 탐색하는 것은 큐브의 전개도를 걷는 것처럼 느껴짐
- 실제로는 큐브를 돌아가며 보는 착각 구조

```
     [면 2]
[면 3][면 1][면 4][면 6]
     [면 5]
```

## 맵 회전 (색 구슬 획득 시 발동)

- 큐브의 **랜덤한 축**으로 **90도 회전** (CW/CCW 랜덤)
- 회전 후 플레이어가 보는 층/구역이 달라질 수 있음
- 이미 방문한 층이 다시 나타나는 효과 → 반복 착각 연출의 핵심

### Unity 구현 방향

- Addressables: 6개 면을 개별 씬으로 관리
- 회전 시 현재 면 UnloadScene → 다음 면 LoadSceneAsync(Additive)
- 상세 구현 → [[12 큐브 좌표계 설계]]

## "층(Floor)"과 "면(Face)"의 관계 (2026-08-16 확정 — QA [[32 QA 리뷰 - 기획자 3인]] LVL-1 대응)

기존 설계는 "면은 6개인데 층은 12개"라는 산술적 모순이 있었다. 아래처럼 둘을 **다른 개념**으로 분리해 해결한다.

| 개념 | 정의 | 개수 |
|------|------|------|
| **면 (Face)** | 물리적으로 고정된 3D 공간. Addressable Scene 1개 = 면 1개 | **정확히 6개** (변하지 않음) |
| **층 (Floor)** | 화면에 표시되는 진행 카운터. 회전(=색 구슬 획득)할 때마다 +1 | 제한 없음 (플레이 중 계속 증가) |

- 면은 6개뿐이지만, **면마다 "방문 횟수별 콘텐츠 레이어"**를 갖는다 — 1번째 방문 레이어(신규 오브젝트, 적 배치)와 2번째 이후 방문 레이어(반복 연출용으로 미세하게 바뀐 배치, [[24 디자인 필러]] 필러 2에 따라 완전 동일 금지)가 각각 존재
- "몇 층인가"는 단순 카운터일 뿐, 특정 물리 공간과 고정 대응되지 않는다 — 같은 면이라도 언제 몇 번째로 다시 방문하느냐는 실제 플레이(랜덤 회전 결과)에 따라 달라진다
- **방문 순서 보장 규칙:** 완전 무작위면 초반부터 반복이 나올 수도, 끝까지 안 나올 수도 있어 페이싱이 무너진다. 이를 막기 위해 회전 대상 선정 시 **미방문 면을 우선 후보로 가중** — 6개 면을 모두 최소 1번씩 방문하기 전까지는 재방문이 발생하지 않는다. 즉 **1~6층은 항상 신규 콘텐츠**, **7층부터 재방문이 시작될 수 있음**이 시스템적으로 보장된다 (7층 이후는 다시 완전 랜덤 — 몇 층에 정확히 어떤 면이 재방문되는지는 매 플레이마다 달라짐, 리플레이성 확보)
- **12층과 최종층은 면이 아니다** — 각각 큐브 구조 노출 전용 특수 룸(`SC_CubeReveal`), 보스 전용 씬(`SC_Boss`)으로 6면 순환 로직 바깥에 별도 존재

### 이 결정이 [[19 층별 상세 설계]]에 미치는 영향

19번 문서의 "1층~12층" 표는 **고정 스케줄이 아니라 대표 플레이 예시**로 읽어야 한다. 실제 게임에서 "8층에서 정확히 1층이 재등장한다"처럼 층 번호로 못박힌 서술은, 실제로는 "**어떤 면이든 그 면의 두 번째 방문에서**" 발생하는 사건으로 재해석한다. 서사 트리거(내레이션 강도)는 층 번호가 아니라 **재방문 누적 횟수**를 기준으로 건다 — 이 세계에서 처음 재방문이 발생하면 약한 데자뷰 내레이션(기존 "5층" 텍스트급), 그 이후 재방문들에서는 강한 확신 내레이션(기존 "8층" 텍스트급)이 나온다. 구현 시 각 면의 `visitCount`를 기준으로 판정 (→ [[12 큐브 좌표계 설계]]).

## 층 구조

| 층 범위 | 특징 |
|---------|------|
| 1~3층 | 튜토리얼. 색 거의 없음. 먹괴음 약함 (항상 신규 면 — 위 방문 순서 보장 규칙에 따라) |
| 4~6층 | 색 복원 시작 (역시 항상 신규 면, 6층까지는 재방문 없음) |
| 7층~ | 재방문이 시작될 수 있는 구간. 첫 재방문 시 반복 층 힌트, 이후 재방문에서 "여기 왔던 것 같은데" 확신 내레이션 |
| 12층+ | 큐브 구조 노출 (면이 아닌 특수 공간) |
| 최종층 | 큐브 중심 — 보스 방 (면이 아닌 특수 공간) |

## 반복 층 연출

- 특정 층 도달 시 BGM 미묘하게 변형 (AudioMixer 피치/에코)
- 플레이어 내레이션(혼잣말) 화면 상단 글리치 텍스트로 등장
- 전에 없던 오브젝트 위치 변화로 혼란 유도
- 일부 먹괴음이 "기억하는 것처럼" 행동 (같은 위치에 같은 패턴으로)

## 계단 & 층 전환

- 계단은 색 복원 완료 시 또는 숨겨진 타일 활성화 후 등장
- 층 전환 시 페이드 트랜지션 + 맵 회전 연출 연계

## 맵 생성 방식

- 층당 타일맵 크기: **고정** (성능 안정성 확보)
- 생성 방식: **프로시저럴 생성** 또는 미리 제작된 씬 풀에서 선택
- 큐브 회전 시 플레이어 위치: 해당 면의 지정 SpawnPoint로 강제 이동
