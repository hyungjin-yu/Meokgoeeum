## HUD 구성 (1920×1080)

```
┌─────────────────────────────────────────────────────────┐
│ [HP바 + 캐릭터 아이콘]           [층 표시: B3F]          │  ← 상단 (높이 60px)
│                                                         │
│                   ( 3D 게임 화면 )                       │
│                                                         │
│ [색 구슬 슬롯 × 5]          [스킬 쿨타임 아이콘 × 6]    │  ← 하단 (높이 60px)
│  ● ● ● ○ ○                  [1][2][3][4][5][6]          │
└─────────────────────────────────────────────────────────┘
```

- 상단 좌: HP 바 220px와 캐릭터 아이콘
- 상단 우: 층 표시. B3F 형식, Warm Yellow #FFE082
- 하단 좌: 색 구슬 슬롯 5개, 40×40px 원형
- 하단 우: 색 스킬 쿨타임 아이콘. 각 스킬 단축키 1~6 표시, 쿨타임 시 회색 오버레이

## 아트 방향

### 톤 방향

세계관 문서의 "조선 풍 현대 도시"를 어떤 톤으로 구현할지 확정했다.

처음에는 한국과 사이버펑크를 결합하는 방향으로 접근했지만 두 가지 이유로 순화했다. 이 문서가 이미 정한 레퍼런스인 Tunic과 Gris는 둘 다 차갑고 날카로운 디스토피아와는 결이 다르고, 이 게임은 힐링게임을 지향하므로 시안과 마젠타 네온, 각진 홀로그램 같은 사이버펑크 요소는 그 방향과 부딪힌다.

그래서 "조선 풍 도시 + 색을 되찾는 등불과 초롱" 톤으로 확정했다. 기존 UI 팔레트의 Warm Yellow #FFE082와도 자연스럽게 이어진다.

| 배제 | 채택 |
|------|------|
| 차갑고 날카로운 디스토피아 사이버펑크, 시안·마젠타 네온, 각진 홀로그램 | 한지 초롱, 처마 밑 등불, 창호지 안쪽에서 새어나오는 부드러운 빛 |

### 색채 설계

- **기본 상태:** 회색조 도시. 채도를 0으로 클램프하며 발광 오브젝트도 예외 없이 적용한다.
- **색 복원 후:** 선명하고 따뜻한 색감
- **번지는 질감:** 색이 각지게 켜지는 대신 칠해지듯 번지는 질감으로 표현한다. Gris를 참고해 파동 경계가 날카롭지 않고 부드럽게 스며드는 느낌을 낸다.
- **먹괴음:** 검정과 먹물 텍스처, 이동 시 먹물 흔적 파티클

### 발광 오브젝트 디자인 원칙

- 각진 네온튜브나 홀로그램 광고판은 쓰지 않는다.
- 한지 초롱, 처마 밑 등불, 창호지 안쪽에서 새어나오는 부드러운 빛을 기본형으로 삼는다.
- 무채색 상태에서도 발광체의 형태와 명암 대비는 뚜렷하게 유지한다. 채도가 없는 대신 형태로 존재감을 보완한다.

### 색-오브젝트 매칭 (초안, 확정 필요)

[[04 색 구슬 시스템]]의 6색-스킬 매칭에 오브젝트를 붙인 초안이다. 아래 표는 아직 확정이 아니며, 특히 검정은 무채색 배경에 묻히지 않도록 별도 처리가 필요하다.

| 색 | 스킬 | 오브젝트 매칭 초안 |
|----|------|---------------------|
| 빨강 | 강타 | 정육점, 포장마차 등불 |
| 파랑 | 흐름 | 저녁 하늘 같은 부드러운 인디고 계열 발광 |
| 노랑 | 번쩍 | 가로등. 기준 팔레트 Warm Yellow #FFE082와 직결 |
| 초록 | 되살림 | 약국이나 회복과 관련된 등불 |
| 보라 | 왜곡 | 뒷골목 초롱 |
| 검정 | 먹물, 보스 특효 | 빛을 빨아들이는 네거티브 이펙트. 무채색 배경에 묻히지 않도록 별도 처리 필요 |

### 색감 기술 구현 방향

[[11 셰이더 설계 - 색 복원 파동]]의 `_WaveRadius` 기반 원형 파동 Lerp 셰이더를 그대로 확장한다. 네온 전용 셰이더를 새로 만들지 않고 Emission과 채도 채널만 추가한다.

- 기본 상태는 완전 무채색으로 클램프한다. 네온 계열 머티리얼도 예외를 두지 않는다.
- 파동의 Lerp 곡선은 선형 대신 ease-out으로 바꿔 색이 확 터지는 손맛을 낸다.

### 캐릭터

- 붓의 먹물이 전투 시 튀는 이펙트 (VFX Graph)
- 피격 시 회색 먹물이 묻는 시각 효과

### 환경

- 조선 풍 현대 도시: 콘크리트, 간판, 전봇대, 골목
- 회색 상태와 색 복원 상태 두 버전의 머티리얼이 필요하다. Shader Graph로 전환한다.
- 큐브 경계 구역: 기하학적 패턴의 벽면
- 환경 다양성은 아직 미정이다. 골목과 거리 외에 실내나 층별 테마 변화를 둘지는 "다음에 확정할 것" 참고

## 구조 제작 계획

건물을 벽, 지붕, 장식 부품으로 나누고 그리드와 소켓 규칙 기반 조립 방식으로 제작하고 맵을 구성한다.

- **핵심 모듈:** 기둥, 처마와 지붕, 한지창과 문, 벽체 패널, 기단. 이 중 지붕이 난이도와 재사용도가 가장 높다.
- **발광 레이어:** 초롱과 등불은 구조 모듈과 분리된 별도 프리팹으로 만든다. 같은 구조에 레이어 조합만 바꿔 변형을 만든다.

이 구조 제작 계획은 [[05 맵 시스템 - 큐브 구조]]의 맵 생성 방식과 이어진다.

## 제작 도구

작업용 PC에서 Blender 5.2.1과 Blender MCP, Claude Code를 Orca 터미널에서 함께 사용한다.

## 맵 회전 연출 UI

- 회전 전: 화면 테두리 해당 구슬 색 파동 효과 (글로우)
- 중앙: 색 복원 텍스트 페이드인 ("붉은 기억이 되살아났다")
- 회전 중: 화면 0.3초 암전 + 큐브 아이콘 (로딩 표시 대체)
- 회전 후: 새 맵으로 페이드인

## 폰트 & 언어

- 기본 언어: 한국어 (영어 추후 추가)
- **메인 UI:** 나눔스퀘어라운드 — 둥글고 아기자기, 가독성 높음
- **연출용 텍스트:** 온글잎 밀기름체 — 손그림 느낌 (내레이션, 보스 대사)

## 스킬 UI

- 인벤토리 없음
- 하단 구슬 슬롯 클릭 → 사용 가능한 스킬 목록 팝업
- 단축키(1~6)로도 즉시 발동 가능
- 구슬 슬롯 길게 누르면 **잠금(Lock)** 토글 — 잠긴 슬롯은 작은 자물쇠 아이콘 오버레이, 최대 2개까지 동시 잠금 가능 (→ [[02 플레이어 시스템]] "5슬롯 vs 6색" 절)

## Unity & Blender 구현 참고

- UI 시스템: **Unity UI Toolkit** 또는 **uGUI (Canvas)**
- 쿨타임 표시: Image Fill Amount 애니메이션
- 글리치 텍스트 내레이션: DOTween으로 텍스트 노이즈 효과
- 발광 오브젝트와 건물 모듈은 Blender에서 제작한 뒤 Unity로 임포트한다.
