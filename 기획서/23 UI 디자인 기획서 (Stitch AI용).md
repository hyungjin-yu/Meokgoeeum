## 디자인 원칙

### 1. 색 = 이야기 (Color as Narrative)
- UI 자체도 게임 세계의 일부: **초반(색 미복원 시) → 회색조 UI**, **색 복원 후 → 해당 색 반영**
- 먹물 테마: 획, 번짐, 스며드는 느낌을 UI 요소에 적용
- "화려하지 않되, 색이 살아있는" 디자인

### 2. 읽기 편함 > 미적 화려함
- 실시간 액션 게임 특성상 정보 전달이 최우선
- 핵심 정보(HP, 구슬, 층, 쿨타임)는 **항상 시야 내 고정 위치**
- 팝업/오버레이는 게임 화면을 50% 이상 가리지 않음

### 3. 아기자기한 감성
- 어린아이 마음 세계 → 딱딱하지 않고 부드러운 곡선, 손그림 느낌 테두리
- 폰트: 둥글둥글하고 따뜻한 한글 폰트
- 버튼 모서리: 완전한 원형 or 큰 radius의 둥근 사각형

### 4. 스타일라이즈드 3D 일관성
- 그림자 최소화 (필요 시 flat drop shadow만)
- 아이콘: 선 두께 일정한 라인 아이콘 or 단순 실루엣
- 해상도 기준: 1920×1080

## 타이포그래피 시스템

### 폰트 선택 가이드

- **메인 UI:** 나눔스퀘어라운드 (네이버) — 둥글고 아기자기, 가독성 높음
- **연출용 텍스트:** 온글잎 밀기름체 — 손그림 느낌 (내레이션, 보스 대사, 게임오버)
- **영문 서브:** Nunito (Google Fonts) — 영어 지원 시

### 텍스트 스케일

| 용도 | 크기 | 굵기 | 색상 |
|------|------|------|------|
| 타이틀 (메인 메뉴) | 72px | Bold | `#EFEFEF` |
| 층 표시 (B3F) | 32px | Bold | `#FFE082` |
| HP / 수치 | 22px | Bold | 상태 컬러 따름 |
| 일반 설명 텍스트 | 18px | Regular | `#EFEFEF` |
| 보조 정보 (소) | 14px | Regular | `#AAAAAA` |
| 내레이션 텍스트 | 24px | Regular | `#EFEFEF` (글리치 시 `#FF5252` 혼합) |

## 공통 컴포넌트

### HP 바 (Health Bar)

```
[ 구조 ]
- 바 배경: #333333, border-radius 6px, 높이 14px
- 바 채움: 왼쪽→오른쪽
  - 70% 이상: #66BB6A (초록)
  - 30~70%:  #FFA726 (주황)
  - 30% 미만: #FF5252 (빨강) + 깜빡임 애니메이션

[ 레이아웃 ]
- 플레이어 HP: 화면 좌상단, 너비 220px
- 적 HP: 적 머리 위 World Space Canvas, 너비 80px
```

### 색 구슬 슬롯 (Orb Slot)

```
[ 구조 ]
- 슬롯 크기: 40×40px 원형
- 보유 구슬: 해당 색 + 내부 광택 하이라이트
- 빈 슬롯: #555555, 점선 테두리
- 최대 5개 가로 배열, 간격 8px

[ 상태 ]
- 기본: 정적
- 선택됨: 외곽 2px 흰색 글로우
- 소모됨: 회색 fade → 빈 슬롯 (0.3s)
```

### 스킬 쿨타임 아이콘

```
[ 구조 ]
- 크기: 36×36px
- 아이콘 위에 쿨타임 오버레이 (Image Fill Amount, 시계 반대 방향)
- 쿨타임 중: 회색 오버레이 + 남은 시간 숫자 (14px)
- 쿨타임 완료: 구슬 색 글로우 효과 + 펄스 애니메이션
```

### 맵 회전 연출 오버레이

**단계별 UI**

```
[1단계 - 파동 시작]
- 화면 테두리: 해당 구슬 색 글로우 파동
- 중앙 텍스트 페이드인 (온글잎 밀기름체, 48px)
  빨강: "붉은 기억이 되살아났다"
  파랑: "흐르는 것들이 돌아왔다"
  노랑: "빛이 다시 깜빡였다"
  초록: "숨결이 느껴진다"
  보라: "뒤틀린 것들이 바로잡혔다"
  검정: "먹이 다시 흘렀다"

[2단계 - 맵 회전 중]
- 화면 전체 0.3s 암전
- 중앙: 작은 큐브 회전 아이콘

[3단계 - 회전 완료]
- 새 맵으로 페이드인
```

## 상태별 UI 변화 규칙

| 상황 | UI 변화 |
|------|---------|
| 색 미복원 (초기) | HUD 전부 회색조 (#2B2B2B 기반) |
| 색 구슬 보유 중 | 해당 색이 구슬 슬롯에 반영 |
| 색 복원 후 | HUD 테두리에 해당 색 미세 글로우 추가 |
| HP 30% 미만 | HP바 빨강 깜빡임, 화면 테두리 빨간 펄스 |
| 스킬 쿨타임 중 | 해당 아이콘 회색 오버레이 + 남은 시간 수치 |
| 스킬 사용 가능 | 아이콘 펄스 애니메이션 |

## Stitch AI 프롬프트 가이드

### 공통 지시문 (모든 화면에 붙이기)

```
3D 실시간 액션 RPG 게임 "먹괴음"의 UI를 디자인해줘.
- 해상도: 1920×1080
- 스타일: 스타일라이즈드 3D 게임 HUD, 아기자기하고 따뜻한 감성
- 폰트: 나눔스퀘어라운드 계열, 둥글고 부드러운 한글 폰트
- 테마: 색을 잃어버린 회색조 도시 + 먹물 텍스처
- 버튼 모서리: border-radius 12px
- 주요 색상: 배경 #2B2B2B, 패널 #1A1A1A, 텍스트 #EFEFEF, 강조 #FFE082
- 구슬 색: 빨강 #E53935, 파랑 #1E88E5, 노랑 #FDD835, 초록 #43A047, 보라 #8E24AA, 검정 #212121
```

### 화면별 추가 프롬프트

**메인 메뉴:**
```
게임 메인 메뉴 화면을 디자인해줘.
회색조 도시 배경 이미지 위에 타이틀 "먹괴음" (72px Bold),
아래에 버튼 5개 세로 나열: 게임 시작 / 계속하기 / 색 도감 / 설정 / 종료
버튼 너비 280px, 간격 12px. 먹물 번짐 텍스처 배경 오버레이 포함.
```

**인게임 HUD:**
```
실시간 액션 RPG 인게임 HUD를 디자인해줘.
상단 바 (60px): 좌측 HP 바 (캐릭터 아이콘 + 220px 바 + 수치), 우측 층 표시 "B3F" (32px, #FFE082)
하단 바 (60px): 좌측 색 구슬 슬롯 5개 (40×40px 원형), 우측 스킬 쿨타임 아이콘 6개 (각 36×36px, 단축키 1~6)
구슬 슬롯: 빨강, 파랑, 초록은 채워진 상태 / 나머지 2개는 빈 슬롯.
```

**스킬 선택 패널:**
```
실시간 액션 게임의 스킬 선택 팝업을 디자인해줘.
크기 560×300px, 화면 중하단 위치.
각 행: 구슬 아이콘(32px) + 스킬명(Bold) + 효과 설명 + [사용] 버튼
빨강/파랑/초록은 활성, 보라/검정은 미보유로 흐린 상태.
```
