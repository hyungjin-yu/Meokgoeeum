# 새 면(Face) 만들기 자동화 도구

> 1~6층 만들 때마다 매번 반복했던 절차([[logic/큐브 좌표계 씬 설정]] 4~7단계 + [[logic/계단 & 방 클리어 게이트 씬 설정]] 전체)가 귀찮다는 피드백으로 만든 **에디터 전용 도구**입니다. `Assets/Scripts/Editor/FaceBootstrapWindow.cs` — 빌드에는 포함 안 되는 에디터 전용 코드(Unity 관례상 `Editor` 폴더 안 스크립트는 자동으로 그렇게 처리됨).

## 무엇을 자동으로 해주는지

버튼 한 번으로:
1. 새 씬 생성 (`SC_Face_N`)
2. `Ground`(Plane) + `SpawnPoint` 배치
3. `Stairs`(Cube, Box Collider Is Trigger 켜짐, Start Active **꺼짐** — 6층에서 겪은 그 실수 원천 차단)
4. `RoomClearGate`(Bounds Size 20×5×20 기본값, `Stairs`까지 미리 연결됨)
5. 씬 저장
6. Addressable 등록 (`Default Local Group`에 주소를 씬 이름으로)
7. `CubeFaceData` 에셋 생성 (`Face Index` + `Scene Reference` 채움)
8. `GameState.faceData` 배열에 자동 연결

**자동화 안 하는 것(그대로 손으로 해야 함):** 적/장식 배치, `RoomClearGate`의 `Bounds Size`를 실제 배치에 맞게 조정 — 이건 층마다 내용이 완전히 다르니까 자동화 대상이 아닙니다.

## 사용법

1. 상단 메뉴 `MG` → `새 면 만들기 (Face Bootstrap)` 클릭 → 창이 뜸
2. `씬 파일 번호`: 아직 안 쓴 아무 숫자(예: 다음 번호). `SC_Face_N`으로 저장됨 — 이 번호가 `Face Index`랑 같을 필요는 없음
3. `Face Index (0~5)`: **여기가 중요** — `GameState`의 `Face Data` 배열에서 실제로 들어갈 자리 번호입니다. 회전 테이블(`CubeMapManager.RotationTableCW`) 계산 결과와 일치해야 실제로 그 면으로 갈 수 있어요. **헷갈리면 숫자 넣기 전에 먼저 물어보세요** — 지금까지처럼 "지금 채워진 면에서 다음 회전하면 어디로 가는지" 계산해서 알려줄게요
4. `만들기` 클릭 → 완료 팝업이 뜨면 끝
5. Project 창에서 `SC_Face_N`을 더블클릭해서 열고, 적/장식 배치 시작

## 확인해야 할 것

- 완료 팝업에 "GameState 연결: 완료"라고 떴는지 확인. 만약 "수동으로 해야 함"이라고 뜨면, 콘솔 경고를 보고 원인(대부분 `SC_Game`이 안 열려있었거나 `Addressables`가 아직 초기화 안 됨) 확인 후 기존 절차대로 수동 연결
- `RoomClearGate`의 `Bounds Size`(기본 20×5×20)가 실제로 배치할 적들을 다 덮는지, 배치 끝난 뒤 Scene 뷰에서 하늘색 박스로 확인

## 알려진 한계

- 아직 아무도 실제로 눌러본 적 없는 스크립트라(에디터 자동화라 Claude가 직접 테스트할 방법이 없음), 처음 써볼 때 뭔가 안 맞으면 바로 알려주세요 — 콘솔 에러 메시지 캡처해서 보여주면 바로 고칠 수 있음
- `SC_Game`이 안 열려있으면 `GameState` 연결 단계만 건너뛰고 나머지는 정상 진행됨(수동 연결 필요)
- Addressables가 프로젝트에서 한 번도 초기화 안 된 상태(`Window > Asset Management > Addressables > Groups`를 한 번도 안 연 상태)면 6~9단계를 건너뜀 — 이미 1층 만들 때 초기화했으니 지금은 해당 없음
