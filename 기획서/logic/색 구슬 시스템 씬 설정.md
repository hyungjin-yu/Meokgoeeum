## 설정 순서

### 1. 매니저 오브젝트 만들기

1. Hierarchy 빈 곳 클릭 → 선택 해제
2. Hierarchy 우클릭 → `Create Empty`
3. 이름을 `GameSystems`로 변경 (→ [[10 씬 구조 & 기술 스펙]] 명명 그대로)
4. `Add Component → Color System Manager` 추가
5. 같은 오브젝트에 `Add Component → Color Orb Pool` 추가

> 두 매니저 다 씬에 정확히 1개씩만 있어야 합니다 (싱글톤). 중복 생성해도 자동으로 나중 것이 파괴되긴 하지만, 애초에 하나만 만드는 게 깔끔합니다.

### 2. 확인

1. Play 버튼
2. `EnemyPyeong`을 붓으로 처치
3. 처치한 자리에 색이 칠해진 구슬(작은 Sphere)이 나타나는지 확인
4. 그 구슬 쪽으로 걸어가면 자동으로 사라지고, Console에 `"색 구슬 획득: {색} | 보유 현황: ... | 누적 획득: ...회"` 로그가 뜨는지 확인

## 트러블슈팅

| 증상 | 원인 | 해결 |
|------|------|------|
| 적을 죽여도 구슬이 안 나타남 | `ColorOrbPool`이 씬에 없음 | 위 1번 단계 진행. Console에 경고 로그(`ColorOrbPool이 씬에 없어서...`)가 뜨는지 확인 |
| 구슬 위로 걸어가도 안 없어짐 | Player 태그가 `Player`가 아님, 또는 `ColorSystemManager`가 씬에 없음 | Player 태그 확인 (예전에 이미 고쳐뒀어야 함), `ColorSystemManager` 부착 확인 |
| 구슬이 항상 같은 색만 나옴 | 정상일 수 있음 — 지금은 6색 균등 랜덤이라 우연히 겹칠 수 있음 | 여러 번 처치해서 다른 색도 나오는지 확인 |
