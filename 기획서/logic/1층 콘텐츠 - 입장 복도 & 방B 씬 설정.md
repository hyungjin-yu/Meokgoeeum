# 1층 콘텐츠 — 입장 복도 & 방B 씬 설정

> [[28 레벨 디자인 - 인카운터 페이싱과 블록아웃]] 1층 블록아웃: `[입장] → [방A: 평×2 전투] →
> [방B: 색 구슬 파동 트리거 지점] → [출구/계단]`. **방A(1층 전투)와 계단은 이미 구현·검증
> 완료**([[changelog/2026-08-19_인카운터스포너-1층콘텐츠]]) — 이 문서는 아직 안 만든
> **[입장]**([[15 튜토리얼 설계]] 1~2단계: 이동/구르기 유도)과 **[방B]**(색 복원 연출, 4단계)만 다룹니다.

## 스코프 컷 — 오늘 안 만드는 것

[[15 튜토리얼 설계]]는 이것보다 범위가 넓습니다(6단계, 키 안내 팝업 6종, ESC 스킵 팝업, Tab
Lock-On 연동). 프로젝트에 팝업 UI 시스템 자체가 없어서, 오늘은 **공간/메커니즘**만 만들고
**연출(팝업 힌트, 발자국 이펙트, 스킵 확인창)은 다음으로 미룹니다** — `CLAUDE.md`에 별도
항목으로 다시 남겨둘 것. 대신 [[TutorialCheckpoint]]로 Console 로그만 남겨서 "공간이 의도대로
배치됐는지"는 지금 바로 검증할 수 있게 했습니다.

## 무엇을 만드는지 (미리 보기)

- **입장 복도(1단계)** — 긴 복도, 끝에 [[TutorialCheckpoint]] 트리거
- **장애물 구간(2단계)** — 좁은 통로 + [[MovingObstacle]](느리게 좌우로 오가는 단단한 장애물), 통과 지점에 [[TutorialCheckpoint]]
- **방B** — [[PaintableObject]]를 부착한 "간판" 오브젝트 하나. 방A 클리어 후 구슬을 먹으면 이미 있는 [[ColorWaveEffect]](최대 반경 30m)가 자동으로 칠해줍니다 — **새 스크립트 필요 없음**, 배치만 하면 됨

---

## 1단계 — 입장 복도 만들기

1. `SC_Face_0`을 엽니다
2. 기존 `SpawnPoint`(방A 앞)보다 앞쪽에, 길게 뻗은 복도 지오메트리를 만듭니다 (`Cube`를 늘려서 바닥+양옆 벽 3개, 또는 있는 에셋 재사용 — 그레이박스면 충분)
3. 플레이어 시작 위치(`SpawnPoint` 또는 별도 `PlayerStart`)를 복도 입구 쪽으로 옮깁니다
4. 복도 끝(방A 진입 직전)에 `Create Empty` → 이름 `Checkpoint_CorridorEnd` → `Box Collider` 추가(`Is Trigger` 체크, 복도 폭만큼 크기 조절) → `Add Component` → `Tutorial Checkpoint` 부착 → `Checkpoint Name`에 `"1단계 - 복도 끝"` 입력

## 2단계 — 장애물 구간 만들기

1. 복도 중간에 폭이 좁아지는 구간을 하나 만듭니다 (양옆 벽을 좁혀서 장애물이 아니면 못 지나가게)
2. 그 구간 한가운데에 `3D Object` → `Cube` → 이름 `Obstacle_Slow` → 통로 폭을 다 막을 만한 크기로 스케일 조정 (`Is Trigger`는 **끄기** — 물리적으로 막아야 함)
3. `Add Component` → `Moving Obstacle` 부착
   - `Travel Distance`: 통로 폭보다 살짝 작게 (예: 3)
   - `Period`: 기본 4(초) — "느리게"라는 기획 의도, 필요하면 테스트하면서 조절
4. 장애물 구간을 통과한 직후(방A 진입 직전)에 `Checkpoint_ObstaclePassed` 오브젝트를 1단계와 같은 방식으로 만들고 `Checkpoint Name`엔 `"2단계 - 장애물 통과"` 입력

> ⚠️ 장애물이 플레이어를 완전히 가둬서 못 지나가게(타이밍 창이 아예 없게) 만들지 않도록 `Travel Distance`/`Period`, 통로 폭을 같이 보면서 조절하세요 — 막힌 것처럼 느껴지면 안 됩니다.

## 3단계 — 방B (간판) 만들기

1. 방A 안쪽, 구슬이 드랍되는 위치 근처(대략 몇 미터 이내 — `ColorWaveEffect`의 `Max Radius` 30m면 방 안 어디든 충분)에 `3D Object` → `Cube` 또는 `Quad` → 이름 `Signboard_Floor1`
2. `Add Component` → `Paintable Object` 부착
   - `True Color`: 원하는 간판 색 (예: 노란빛 도는 색)
   - `Start Gray`: 켠 채로 유지

끝입니다 — 새 스크립트 연결 없음. 방A 클리어 → 구슬 획득 → 기존 `ColorWaveEffect`가 자동으로 이 간판을 찾아서 칠합니다.

## 4단계 — 저장 + 테스트

1. `Ctrl+S`로 `SC_Face_0` 저장
2. Play, 복도를 걸어서 끝까지 이동 → Console에 `[TutorialCheckpoint] 1단계 - 복도 끝 도달!` 확인
3. 장애물 구간 통과 → `[TutorialCheckpoint] 2단계 - 장애물 통과 도달!` 확인 (장애물에 부딪히면 캐릭터가 물리적으로 밀려나기만 하고 대미지는 없는지도 확인 — 의도된 동작)
4. 방A(평×2) 클리어 → 구슬 획득 → `Signboard_Floor1`이 회색에서 원래 색으로 칠해지는지 확인
