# 마우스 감도 설정 (Mouse Sensitivity)

> 2026-08-16 작성

## 배경

Cinemachine 카메라 튜닝 중 `Input Axis Controller`의 `Gain`을 20으로 맞춰야 정상적인 감도가 나왔다 (→ [[logic/Cinemachine 3인칭 카메라 설정]]). 이 값을 나중에 플레이어가 설정 메뉴([[07 UI & 아트 방향]], [[23 UI 디자인 기획서 (Stitch AI용)]]에 이미 "설정" 버튼은 그려져 있었지만 실제 설정 시스템은 아직 설계된 적 없음)에서 바꿀 수 있게 해달라는 요청으로 추가함.

## 설계

두 값을 분리했다:

| 값 | 위치 | 성격 | 누가 바꾸나 |
|----|------|------|-------------|
| `Gain = 20` | Cinemachine `Input Axis Controller` | 디자이너가 튜닝한 "기본 감도" (고정값) | 디자이너만 (Inspector에서) |
| 감도 배율 (0.1~3.0) | `PlayerInputActions`의 `Look` 액션 `ScaleVector2` 프로세서 | 플레이어 취향 배율 | 플레이어 (설정 UI) |

최종 감도 = Cinemachine Gain(20, 고정) × 플레이어 배율(0.1~3.0, 가변)

이렇게 나눈 이유: Cinemachine 컴포넌트 내부 값을 코드에서 직접 건드리는 건 Cinemachine 버전 API에 의존적이라 위험하다. 대신 Input System의 표준 기능(`ScaleVector2` 프로세서 + `ApplyParameterOverride`)만 사용하면 Cinemachine을 전혀 건드리지 않고도 감도를 실시간으로 바꿀 수 있다.

## 구현

- `Assets/Input/PlayerInputActions.inputactions`의 `Look` 바인딩에 `scaleVector2(x=1,y=1)` 프로세서 추가 (기본값 1 = 배율 없음)
- `Assets/Scripts/MouseSensitivitySetting.cs`
  - `Awake()`에서 `PlayerPrefs`에 저장된 감도 불러와 적용 (없으면 기본값 1.0)
  - `SetSensitivity(float)` — 나중에 설정 UI 슬라이더의 `OnValueChanged`에 그대로 연결하면 됨
  - `PlayerPrefs`로 영구 저장 (다음 실행에도 유지)

## 씬 설정 (Unity 에디터에서)

- `MouseSensitivitySetting` 컴포넌트를 씬의 아무 오브젝트에나 붙이면 됨 (Player에 붙여도 무방, 별도 GameObject를 만들어도 됨)
- 별도 설정 없이 바로 동작 (기본 배율 1.0)

## 아직 없는 것 (다음 세션 참고)

- 실제 설정 UI(슬라이더)는 아직 없음 — [[07 UI & 아트 방향]]의 "설정" 버튼을 실제 화면으로 만들 때 `MouseSensitivitySetting.SetSensitivity()`를 슬라이더에 연결하면 됨
- 마우스 감도 외 다른 설정(볼륨, 해상도 등)이 늘어나면 이 스크립트를 확장하기보다 별도 `SettingsManager` Singleton으로 승격하는 걸 고려할 것 — 지금은 항목이 1개뿐이라 과설계 방지 차원에서 최소 구조로 둠
