# 플레이어 캐릭터 디자인 프롬프트

> 2026-09-15 작성. [[02 플레이어 시스템]]에서 확정한 외형 스펙(한복 실루엣+현대 퓨전, 거의 무채색+먹물 포인트, 여성형 먼저)을 실제 이미지/3D 생성에 쓸 수 있는 프롬프트로 옮긴 것. Hyper3D Rodin 무료 크레딧 소진으로 지금 당장 3D 생성은 막혀서, 이미지 생성(Midjourney, SDXL 등)으로 먼저 컨셉 아트를 뽑거나 크레딧 충전 후 재시도할 때 쓸 것.

## 스타일 앵커

[[26 경쟁작 비교 & 포지셔닝]]에서 이미 "귀여운 스타일라이즈드 비주얼"로 비교 대상에 오른 **Kena: Bridge of Spirits**를 톤 기준으로 삼는다 — 완전 리얼리스틱도 아니고 로우폴리 블록아웃도 아닌, 부드러운 스타일라이즈드 3D.

패션 아이템 개념으로 분리 제작할 예정이라, 각 파츠만 따로 컨셉을 뽑고 싶을 때 쓸 것.

details, rounded crown, charcoal black color, minimal stylized design, clean
white background, orthographic side view
```

**상의 (Top)**
```
isolated game asset concept, Korean jeogori-inspired jacket top with modern

(goreum) in deep black as accent color, mid-gray fabric, minimal stylized design,
clean white background, front and back view

**하의 (Bottom)**
```
isolated game asset concept, Korean chima-inspired flared skirt-pants (culottes),
modern fusion cut ending just above ankle, mid-dark gray fabric, minimal

```

## 사용 메모

- 이미지 생성 결과를 그대로 3D로 못 쓰는 도구(Midjourney 등)라면, 나온 이미지를 Hyper3D Rodin의 `input_image_url` 조건으로 넣어 3D화하는 경로도 있음(Hunyuan3D의 `generate_hunyuan3d_model`도 이미지 입력 지원 — 단, 로컬 API 서버 필요)
- Hyper3D Rodin 크레딧을 충전하면 위 "전체 캐릭터 프롬프트"를 `text_prompt`로 그대로 넣고 `bbox_condition=[0.3, 0.22, 1]`(폭:깊이:높이 비율) 정도로 시도해볼 것 — 단, 옷 입은 채로 한 번에 생성하면 모자/상의/하의를 나중에 떼어낼 수 없으므로, **패션 아이템 분리가 필요하면 반드시 파츠별 프롬프트로 따로 생성**해야 함
