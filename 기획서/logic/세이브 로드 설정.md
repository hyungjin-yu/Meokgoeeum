# 세이브 & 로드 설정

> [[18 세이브 & 로드 기획]] 최소 버전 구현. `SaveManager.cs` + `SaveData.cs`가 완성돼 있고,
> [[CubeMapManager]](층 입장 시)와 [[BossHealth]](보스 처치 시)가 이미 자동으로 `Save()`를
> 호출하도록 연결돼 있습니다. Unity에서 할 일은 딱 하나 — **컴포넌트 부착**뿐입니다.

## 무엇을 저장/복원하는지

- 현재 층 번호, 현재 면(큐브 회전 상태), 플레이어 HP
- 보유 색 구슬 + 누적 획득 색 구슬 (색별)
- 각 면 방문 여부 (반복 층 판정에 씀)
- 처치한 먹괴음 총 수

**저장 안 하는 것** (스코프 컷, [[SaveManager]] 코드 주석에 이유 있음):
- 슬롯 여러 개 (지금은 1개 고정 — 슬롯 고르는 메뉴 화면 자체가 없음)
- 개별 오브젝트 색칠 상태(어떤 벽/간판이 칠해졌는지) — `RestoredAreaRegistry`가 아직 면별로 안 묶여 있어서
- Steam Cloud

## 설정 — 딱 한 단계

1. `SC_Game`을 열고 `GameSystems` 오브젝트 선택
2. `Add Component` → `Save Manager` 부착 (별도 설정 필요 없음)
3. `Ctrl+S`로 저장

## 테스트

1. Play → 1층 시작 → 콘솔에 `[SaveManager] 저장 완료!` 로그가 뜨는지 확인
2. 계단 밟아서 2층으로 넘어가기 → 또 `저장 완료!` 로그
3. **Play 멈추고 다시 Play** → 이번엔 1층이 아니라 **저장됐던 층/면에서 바로 시작**하는지 확인 (콘솔에 `[SaveManager] 로드 완료!` 로그)
4. 구슬을 몇 개 주운 상태로 저장된 거라면, 다시 시작했을 때 `보유 현황`이 이어지는지도 확인

## 세이브 파일 지우고 처음부터 테스트하고 싶을 때

지금은 삭제 UI가 없어서, 직접 파일을 지워야 합니다:
- Windows: `%userprofile%\AppData\LocalLow\[회사명]\[프로젝트명]\save_slot_0.json` (정확한 경로는 콘솔의 `[SaveManager] 저장 완료!` 로그 뒤에 전체 경로가 같이 찍힘 — 그걸 보고 찾는 게 제일 확실함)
- 또는 나중에 디버그용 버튼/치트키로 `SaveManager.Instance.DeleteSave()`를 연결해도 됨 (아직 안 만듦)
