# 계단 & 방 클리어 게이트 씬 설정

> [[Stairs]] + [[RoomClearGate]] 코드는 완성되어 있습니다. 이 문서는 면 씬(`SC_Face_N`) 하나에
> 실제로 계단을 배치하는 절차입니다. 면 씬마다(방마다) 반복하면 됩니다 — 지금은 테스트를 위해
> `SC_Face_0` 하나에만 먼저 해보는 걸 추천합니다.

## 무엇을 만드는지 (미리 보기)

- **계단 오브젝트** (`Stairs.cs` 부착) — 평소엔 안 보이다가, 방을 클리어하면 나타나서, 밟으면 다음 면으로 회전시킵니다
- **방 클리어 게이트** (`RoomClearGate.cs` 부착, 눈에 안 보이는 빈 오브젝트) — "이 방 안의 적을 다 잡았다"를 감지해서 계단을 켜는 역할

둘 다 아직 아트 에셋이 없어서, 계단은 그냥 `Cube` 도형 하나로 임시로 만듭니다 (나중에 실제 모델로 바꿔도 스크립트는 그대로 씀).

---

## 1단계 — 계단 오브젝트 만들기

1. Project 창에서 **`SC_Face_0`를 더블클릭**해서 엽니다 (SC_Game이 아니라 SC_Face_0을 여는 것에 주의)
2. Hierarchy 빈 곳에서 우클릭 → `3D Object` → `Cube` → 씬에 흰색 정육면체가 하나 생깁니다
3. 이 오브젝트 이름을 **`Stairs`**로 변경 (Hierarchy에서 더블클릭하거나 F2)
4. Inspector에서 `Transform` → `Position`을 방에서 적당한 자리(예: 적들이 없는 구석, "출구"처럼 느껴지는 위치)로 옮기기. `Scale`도 원하는 크기로 조절 (예: 계단처럼 보이게 Y는 낮고 넓게)
5. Inspector 맨 아래 `Add Component` 클릭 → 검색창에 `Stairs` 입력 → `Stairs (Script)` 선택해서 부착
6. 같은 오브젝트에 이미 있는 **`Box Collider`** 컴포넌트를 찾아서(Cube를 만들면 자동으로 붙어있음) **`Is Trigger` 체크박스를 켜기** — 이게 안 켜져 있으면 플레이어가 계단에 부딪혀서 못 지나가거나, `OnTriggerEnter`가 아예 발동을 안 합니다

> `Stairs` 컴포넌트의 `Start Active` 체크박스는 **꺼둔 채로 두세요** — 방 클리어 전까지는 안 보이고 안 밟히는 게 정상입니다. (게이트가 나중에 자동으로 켜줌)

## 2단계 — 방 클리어 게이트 만들기

1. 같은 `SC_Face_0` 씬 Hierarchy 빈 곳에서 우클릭 → `Create Empty` → 이름을 `RoomClearGate`로 변경
2. `Transform` → `Position`을 방의 대략 중앙으로 옮기기 (범위 판정의 기준점이 됨)
3. `Add Component` → `Room Clear Gate` 검색해서 부착
4. Inspector에서:
   - `Bounds Size`: 이 방 전체를 덮을 만한 크기로 입력 (예: `20, 5, 20`처럼 X/Z는 방 크기에 맞게, Y는 적 키 정도면 충분)
   - `Stairs`: **1단계에서 만든 `Stairs` 오브젝트를 이 필드로 드래그**해서 연결
5. `RoomClearGate` 오브젝트를 클릭한 상태로 **Scene 뷰를 보면 하늘색 박스 테두리(기즈모)** 가 보일 겁니다 — 이게 "이 안의 적을 다 잡아야 계단이 열림" 범위입니다. 이 박스가 방의 적들을 전부 감싸도록 `Bounds Size`나 `Position`을 조절하세요 (너무 좁으면 방 밖 다른 면의 적까지 포함하거나 반대로 놓치는 적이 생길 수 있음)

## 3단계 — 저장 + 테스트

1. `Ctrl+S`로 `SC_Face_0` 저장
2. `SC_Game`을 열고 Play
3. 방 안의 적을 전부 처치 → 콘솔에 `[RoomClearGate] RoomClearGate 클리어! 계단 활성화.` 로그가 뜨는지, 씬에서 `Stairs` 큐브가 갑자기 나타나는지 확인
4. 계단(큐브) 쪽으로 걸어가서 밟기 → 콘솔에 `[Stairs] 계단 사용! 다음 층으로 이동합니다.` → 뒤이어 기존 회전 로그들(`회전 시작!` → 페이드 → `플레이어를 ...로 이동.` → `n층 도착`)이 이어지는지 확인

## 자주 나올 수 있는 문제

| 증상 | 원인 |
|------|------|
| 적을 다 잡아도 계단이 안 나타남 | `RoomClearGate`의 `Bounds Size`/`Position`이 방을 제대로 안 덮고 있어서, 이미 죽은 적이 아니라 **다른 곳의 살아있는 적**이 범위 안에 잡히고 있을 수 있음. Scene 뷰에서 파란 박스 범위를 확인 |
| 계단을 밟아도 반응 없음 | `Box Collider`의 `Is Trigger`가 안 켜져 있을 가능성. 또는 `Stairs`의 `Start Active`가 켜진 채로 있었는데 `RoomClearGate` 연결이 안 되어 있어서 애초에 로직이 이상하게 꼬였을 수도 있음 — 둘 다 확인 |
| 계단이 처음부터 보임(안 숨겨짐) | `Stairs` 컴포넌트의 `Start Active` 체크박스가 켜져 있음 → 끄기 |
| `RoomClearGate`에 Stairs가 없다는 경고 | 2단계 4번에서 `Stairs` 필드 드래그 연결을 빼먹었을 가능성 |
