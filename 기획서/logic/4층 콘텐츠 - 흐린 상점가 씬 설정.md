# 4층 콘텐츠 — 흐린 상점가 씬 설정

> [[19 층별 상세 설계]] 4층 스펙: "평×2, 흡×1, 첫 흡수형 등장, 색 복원 시 상점 간판 색 복원 +
> 숨겨진 통로 개방, 계단 조건 = 흡이 색 복원 구역에 접근하기 전에 처치".
>
> [[EnemyHeup]]는 이미 "HP 50% 밑으로 떨어지면 가장 가까운 색 복원 구역을 찾아가 흡수 회복"하는
> AI가 완성돼 있고, [[PaintableObject]]는 `Paint()`될 때마다 자동으로 [[RestoredAreaRegistry]]에
> 자기 위치를 등록합니다 — 색칠 가능한 오브젝트 하나만 놓으면 흡이 찾아갈 대상이 저절로 생깁니다.

## 설계 메모 — "흡이 접근하기 전에 처치"를 진짜 페널티로 구현

처음엔 이 조건을 "도전 과제" 정도로만 해석해서 하드 게이트 없이 넘어가려 했는데, 사용자 요청으로 **진짜 페널티(벽 폭발 → 플레이어 즉사)**를 넣기로 했습니다. 문제는 "플레이어 사망" 자체가 그동안 구현이 안 되어 있었다는 것 — 그래서 이번에 **[[GameOverManager]] 최소 버전을 같이 만들었습니다**:

- **[[PlayerHealth]]**: HP 0 도달 시 `OnDeath` 이벤트 발동 (`ResetHealth()`로 리스폰 시 다시 최대 HP로)
- **[[GameOverManager]]**: `OnDeath` 구독 → "게임 오버" 문구(기존 [[NarrationManager]] 재사용) → **현재 층을 다시 로드** → 체력 회복
  - ⚠️ [[17 게임오버 & 리트라이]] 원 기획은 "처음부터(1층부터) 재시작"이지만, **지금은 사용자 요청으로 "죽은 층에서 다시 시작"**으로 구현했습니다. 레벨 콘텐츠를 계속 만들어가는 지금 단계에서 매번 1층부터 다시 하면 테스트가 너무 오래 걸리기 때문. 나중에 진짜 "처음부터"로 바꾸려면 `GameOverManager.HandlePlayerDeath()`의 재시작 로직만 바꾸면 됩니다.
- **[[CubeMapManager]].ReloadCurrentFace()** 신규 — 지금 있는 면을 회전 없이 그대로 다시 로드(적 전부 리스폰). 회전 로직과 페이드/텔레포트 코드를 그대로 재사용
- **[[WallExplosionHazard]]** 신규 (4층 전용) — `EnemyHeup.OnAbsorbStart`(회복 구역 도달 순간)를 구독해서, 짧은 경고 유예 시간(기본 1.5초) 뒤에도 그 흡이 살아있으면 벽이 터져서 플레이어 즉사. 유예 시간을 준 건 기획서에 없는 추가 설계입니다 — [[27 전투 프레임 데이터]]의 텔레그래프(공정한 예고) 원칙에 맞춰, 도달하자마자 즉발이면 너무 억울할 수 있어서 반응할 틈을 준 것

## 0단계 — EnemyHeup 프리팹 만들기 (아직 없음)

`EnemyWon` 때와 동일한 절차:

1. `SC_Face_0`(또는 `SC_Face_1`)을 열고 Hierarchy에서 `EnemyHeup` 찾기
2. **Project 창으로 드래그**해서 프리팹 생성 (⚠️ Hierarchy가 아니라 Project 창에 놓을 것 — [[changelog/2026-08-19_인카운터스포너-1층콘텐츠]] 버그 반복 방지)
3. 저장(`Ctrl+S`)

## 1단계 — GameOverManager 부착 (한 번만, 전체 게임에 공용)

1. `SC_Game`을 열고 `GameSystems` 오브젝트 선택
2. `Add Component` → `Game Over Manager` 부착 (별도 설정 없이 바로 동작)
3. `Ctrl+S`로 저장

> 이건 4층 전용이 아니라 게임 전체 공용 시스템입니다 — 한 번만 붙이면 이후 어떤 층에서 플레이어가 죽어도 동작합니다.

## 2단계 — SC_Face_3 새 씬 만들기

[[logic/3층 콘텐츠 - 전봇대 거리 씬 설정]] 1단계와 동일: `Assets/Scenes`에 `SC_Face_3` 씬 생성 → `Ground`(Plane) + `SpawnPoint` 배치 → 저장

## 3단계 — Addressable 등록 + CubeFaceData 생성

[[logic/큐브 좌표계 씬 설정]] 5~6단계 반복:

1. `Groups` 창에서 `SC_Face_3`를 `Default Local Group`으로 드래그, 주소 정리
2. `Assets/Data`에 `CubeFaceData_3` 생성 → `Face Index`=`3`, `Scene Reference`=`SC_Face_3`
3. `SC_Game`의 `GameSystems` → `GameState` → `Face Data` 배열의 **어느 Element**에 넣을지는 회전 테이블을 참고해야 합니다 — 지금 채워진 면(0=1층, 4=2층, 2=3층)에서 한 번 더 회전했을 때 도달하는 면 번호를 코드(`CubeMapManager.RotationTableCW`)에서 확인하거나, 테스트하면서 뜨는 "몇 면 → 몇 면" 로그를 보고 그 번호에 맞는 Element에 `CubeFaceData_3`을 넣으면 됩니다 (꼭 Element 3일 필요 없음 — `Face Index` 값만 씬 파일과 일치하면 어디 넣어도 상관없음)

## 4단계 — 적 배치 (평×2, 흡×1) + 상점 간판(PaintableObject)

1. `EnemyPyeong` 프리팹 2번, 0단계에서 만든 `EnemyHeup` 프리팹 1번 드래그해서 배치
2. Hierarchy 빈 곳에서 `3D Object` → `Cube`(간판 역할) → 이름 `ShopSign` → 적당한 위치·크기로 배치 (예: 벽에 붙은 얇은 판)
3. `Add Component` → `Paintable Object` 부착, `True Color` 원하는 색 지정, `Start Gray` 켜기

> 이 `ShopSign`이 색 복원 파동에 닿아 칠해지는 순간, `RestoredAreaRegistry`에 자동 등록되고, `EnemyHeup`이 HP가 낮아지면 이 위치로 찾아갑니다 — 별도 연결 작업 필요 없음.

## 5단계 — 벽 폭발 페널티 (WallExplosionHazard)

1. Hierarchy 빈 곳에서 `3D Object` → `Cube` → 이름 `Wall` → 방 한쪽 벽처럼 보이게 배치·크기 조절 (선택 사항 — 시각적 표시용, 없어도 페널티는 작동함)
2. 빈 오브젝트(`Create Empty`) 하나 만들어 이름을 `WallExplosionHazard`로 (또는 위 `Wall` 오브젝트에 바로 부착해도 무방)
3. `Add Component` → `Wall Explosion Hazard` 부착
4. Inspector에서:
   - `Heup`: 4단계에서 배치한 `EnemyHeup` 인스턴스를 드래그해서 연결 (⚠️ 반드시 이 씬 안의 인스턴스를 연결 — Project 프리팹이 아님, Hierarchy에서 드래그하는 게 맞는 경우입니다)
   - `Warning Delay`: 기본 1.5초로 두거나 원하는 값으로
   - `Wall Visual`: 1번에서 만든 `Wall` 오브젝트를 연결(선택) — 폭발 시 이 오브젝트가 사라짐

## 6단계 — 계단 & 방 클리어 게이트

[[logic/계단 & 방 클리어 게이트 씬 설정]] 1~2단계 그대로: `Stairs` + `RoomClearGate`(적 3마리 다 덮도록 `Bounds Size` 조정, `Stairs` 연결).

## 7단계 — 저장 + 테스트

1. `Ctrl+S`로 `SC_Face_3` 저장
2. `SC_Game`에서 Play → 1~3층 거쳐 4층까지 도달
3. 평 2마리 처치로 색 복원 파동이 발생해서 `ShopSign`이 칠해지는지 확인
4. `EnemyHeup`을 공격해서 HP를 절반 밑으로 깎기 → `ShopSign` 쪽으로 도망가는지 확인
5. **일부러 늦게 반응해서** 흡이 `ShopSign`에 도달하게 두기 → 콘솔에 `[WallExplosionHazard] 흡이 색 복원 구역에 도달했다!` 경고 → 1.5초 안에 못 끊으면 `벽 폭발!` → 플레이어 사망 → `게임 오버... 다시 도전!` 문구 → 4층이 다시 로드되고 플레이어 체력이 회복되는지 확인
6. **반대로 유예 시간 안에 흡을 처치**하면 `유예 시간 안에 흡이 처치됨 — 폭발 취소.` 로그가 뜨고 아무 일도 없는지 확인
7. 평×2+흡×1 전부 처치 → `RoomClearGate` 클리어 → 계단 → 회전 확인
