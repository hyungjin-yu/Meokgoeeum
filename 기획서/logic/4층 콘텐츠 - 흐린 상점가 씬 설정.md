# 4층 콘텐츠 — 흐린 상점가 씬 설정

> [[19 층별 상세 설계]] 4층 스펙: "평×2, 흡×1, 첫 흡수형 등장, 색 복원 시 상점 간판 색 복원 +
> 숨겨진 통로 개방, 계단 조건 = 흡이 색 복원 구역에 접근하기 전에 처치".
>
> **코드 변경 없음** — [[EnemyHeup]]는 이미 "HP 50% 밑으로 떨어지면 가장 가까운 색 복원 구역을
> 찾아가 흡수 회복"하는 AI가 완성돼 있고([[13 먹괴음 AI 설계]] 그대로), [[PaintableObject]]는
> `Paint()`될 때마다 자동으로 [[RestoredAreaRegistry]]에 자기 위치를 등록합니다. 즉 **"색이 복원된
> 오브젝트가 씬에 하나라도 있으면" 흡이 찾아갈 대상이 자동으로 생깁니다** — 새로 만들 시스템이 없습니다.

## 설계 메모 — "흡이 접근하기 전에 처치"를 어떻게 구현했는지

기획서 문구를 곧이곧대로 "흡이 구역에 도달하면 그 즉시 실패(계단이 영영 안 열림)"로 구현하면, 플레이어가 실수로 늦으면 **그 방에서 못 빠져나가는 소프트락**이 생길 위험이 있습니다([[17 게임오버 & 리트라이]]는 "게임 전체 사망 시 처음부터"만 정의하고 있고, 방 단위 실패-재시도 루프는 없음).

그래서 이 조건은 **하드 게이트가 아니라 "도전 과제/체감 연출"로 해석**했습니다 — 1/3층과 동일하게 `RoomClearGate`+`Stairs`(전투 클리어 시 계단)를 그대로 쓰고, 흡이 회복 구역에 늦게라도 도달하면 그냥 "더 오래 걸리는 전투"가 될 뿐 진행 자체는 항상 가능합니다. 플레이어가 빠르게 처치하면 자연스럽게 "회복 못하고 죽었다"는 성취감을 느끼고, 늦으면 조금 더 고생하는 정도 — 별도 실패 판정 코드는 만들지 않았습니다. (나중에 진짜 "실패 시 페널티"를 원하면 별도로 상의해서 추가하면 됩니다.)

## 0단계 — EnemyHeup 프리팹 만들기 (아직 없음)

`EnemyWon` 때와 동일한 절차:

1. `SC_Face_0`(또는 `SC_Face_1`)을 열고 Hierarchy에서 `EnemyHeup` 찾기
2. **Project 창으로 드래그**해서 프리팹 생성 (⚠️ Hierarchy가 아니라 Project 창에 놓을 것 — [[changelog/2026-08-19_인카운터스포너-1층콘텐츠]] 버그 반복 방지)
3. 저장(`Ctrl+S`)

## 1단계 — SC_Face_3 새 씬 만들기

[[logic/3층 콘텐츠 - 전봇대 거리 씬 설정]] 1단계와 동일: `Assets/Scenes`에 `SC_Face_3` 씬 생성 → `Ground`(Plane) + `SpawnPoint` 배치 → 저장

## 2단계 — Addressable 등록 + CubeFaceData 생성

[[logic/큐브 좌표계 씬 설정]] 5~6단계 반복:

1. `Groups` 창에서 `SC_Face_3`를 `Default Local Group`으로 드래그, 주소 정리
2. `Assets/Data`에 `CubeFaceData_3` 생성 → `Face Index`=`3`, `Scene Reference`=`SC_Face_3`
3. `SC_Game`의 `GameSystems` → `GameState` → `Face Data` 배열의 **어느 Element**에 넣을지는 회전 테이블을 참고해야 합니다 — 지금 채워진 면(0=1층, 4=2층, 2=3층)에서 한 번 더 회전했을 때 도달하는 면 번호를 코드(`CubeMapManager.RotationTableCW`)에서 확인하거나, 테스트하면서 뜨는 "몇 면 → 몇 면" 로그를 보고 그 번호에 맞는 Element에 `CubeFaceData_3`을 넣으면 됩니다 (꼭 Element 3일 필요 없음 — `Face Index` 값만 씬 파일과 일치하면 어디 넣어도 상관없음)

## 3단계 — 적 배치 (평×2, 흡×1) + 상점 간판(PaintableObject)

1. `EnemyPyeong` 프리팹 2번, 0단계에서 만든 `EnemyHeup` 프리팹 1번 드래그해서 배치
2. Hierarchy 빈 곳에서 `3D Object` → `Cube`(간판 역할) → 이름 `ShopSign` → 적당한 위치·크기로 배치 (예: 벽에 붙은 얇은 판)
3. `Add Component` → `Paintable Object` 부착, `True Color` 원하는 색 지정, `Start Gray` 켜기

> 이 `ShopSign`이 색 복원 파동에 닿아 칠해지는 순간, `RestoredAreaRegistry`에 자동 등록되고, `EnemyHeup`이 HP가 낮아지면 이 위치로 찾아갑니다 — 별도 연결 작업 필요 없음.

## 4단계 — 계단 & 방 클리어 게이트

[[logic/계단 & 방 클리어 게이트 씬 설정]] 1~2단계 그대로: `Stairs` + `RoomClearGate`(적 3마리 다 덮도록 `Bounds Size` 조정, `Stairs` 연결).

## 5단계 — 저장 + 테스트

1. `Ctrl+S`로 `SC_Face_3` 저장
2. `SC_Game`에서 Play → 1~3층 거쳐 4층까지 도달
3. 평 2마리 처치로 색 복원 파동이 발생해서 `ShopSign`이 칠해지는지, 그 뒤 `EnemyHeup`의 HP를 절반 밑으로 깎았을 때 `ShopSign` 쪽으로 도망가서 회복을 시도하는지 확인 (콘솔에 흡수 중 HP가 올라가는 게 안 보이면 — 회복 로그 자체는 없앤 상태라 육안/HP 수치로 확인해야 함, 필요하면 일시적으로 `Heal()` 로그를 다시 켜서 확인 가능)
4. 결국 흡까지 처치 → `RoomClearGate` 클리어 → 계단 → 회전 확인
