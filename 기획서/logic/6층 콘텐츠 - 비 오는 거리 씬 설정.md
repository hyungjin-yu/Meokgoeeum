# 6층 콘텐츠 — 비 오는 거리 씬 설정

> [[19 층별 상세 설계]] 6층 스펙: "평×2, 분×1, 계단 조건 = 분 처치 후 소형 2마리 추가 처치,
> 특이사항 = 분열형 첫 등장(소형 먹괴음 처치 필요)".
>
> **코드 변경 없음** — [[RoomClearGate]]는 애초에 "범위 안에 `EnemyHealth`가 남아있는가"를
> 주기적으로 재검사하는 방식으로 설계했는데, 그 이유가 정확히 이 케이스(`EnemyBun`이 죽을 때
> 미니언 2마리를 새로 스폰하는 것)를 감안한 것이었습니다(`RoomClearGate.cs` 코드 주석에 이미
> 명시돼 있음). 미니언도 `EnemyBun`을 그대로 `Instantiate()`한 클론이라 `EnemyHealth`를 그대로
> 갖고 있어서, 손대는 것 없이 자동으로 "분 + 미니언 2마리 다 죽어야 계단 열림"이 성립합니다.

## 이번 면은 마지막 남은 면 — 6면 전부 완성됨

지금까지 설정된 면: 0(1층), 4(2층), 2(3층), 5(4층), 1(5층). **면 3만 남아있고, 회전 테이블상 면3은 면0 또는 면5에서만 도달 가능**합니다. 이번에 면3까지 채우면 **큐브 6면이 전부 콘텐츠를 갖추게 되는 첫 완성**이 됩니다(7층부터는 어떤 면이든 반드시 재방문이 섞이기 시작 — [[19 층별 상세 설계]] "7층 이후는 면+방문횟수 조합"이 본격적으로 시작되는 시점).

## 0단계 — EnemyBun 프리팹 만들기 (아직 없음)

`EnemyHeup`/`EnemyWon` 때와 동일한 절차:

1. `SC_Face_0`(또는 `SC_Face_1`)을 열고 Hierarchy에서 `EnemyBun` 찾기
2. **Project 창으로 드래그**해서 프리팹 생성 (⚠️ Hierarchy가 아니라 Project 창에 놓을 것)
3. 저장(`Ctrl+S`)

## 1단계 — SC_Face_5 새 씬 만들기

[[logic/3층 콘텐츠 - 전봇대 거리 씬 설정]] 1단계와 동일: `Ground`(Plane) + `SpawnPoint` 배치 → 저장

## 2단계 — Addressable 등록 + CubeFaceData 생성

1. `Groups` 창에서 `SC_Face_5`를 `Default Local Group`으로 드래그, 주소 정리
2. `Assets/Data`에 `CubeFaceData_5` 생성 → `Face Index`=`3`, `Scene Reference`=`SC_Face_5`
3. `SC_Game`의 `GameSystems` → `GameState` → `Face Data` 배열의 **Element 3**에 연결

## 3단계 — 적 배치 (평×2, 분×1)

`EnemyPyeong` 프리팹 2번, 0단계에서 만든 `EnemyBun` 프리팹 1번 드래그해서 배치

## 4단계 — 계단 & 방 클리어 게이트

[[logic/계단 & 방 클리어 게이트 씬 설정]] 1~2단계 그대로: `Stairs` + `RoomClearGate`(적들 다 덮도록 `Bounds Size` 조정 — 분이 분열하면서 미니언이 흩어질 수 있으니 넉넉하게, `Stairs` 연결)

## 5단계 — 저장 + 테스트

1. `Ctrl+S`로 저장
2. `SC_Game`에서 Play → 6층(면3)까지 도달
3. 평 2마리 처치 후 분을 처치 → 콘솔에 `[EnemyBun] 분열! ... 생성 (미니언, HP ...)`이 2번 뜨는지 확인
4. 미니언 2마리까지 마저 처치해야 `RoomClearGate` 클리어! 계단 활성화가 뜨는지 확인 (분만 죽이고 미니언을 안 잡으면 계단이 안 열려야 정상)
5. 계단 → 회전 확인
