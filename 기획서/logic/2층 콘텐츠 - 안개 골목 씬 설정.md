# 2층 콘텐츠 — 안개 골목 씬 설정

> [[19 층별 상세 설계]] 2층 스펙: "평×3, 바닥 타일에 패턴 복원 시 숨겨진 구슬 1개 등장,
> 계단 조건 = 그 구슬 획득 시 자동". 1층(방A 전투)과 달리 **계단이 전투 클리어가 아니라
> 구슬 획득으로 열린다**는 점이 핵심 차이입니다 — `RoomClearGate` 대신 새로 만든
> [[HiddenOrbSpawner]]를 씁니다.

## 무엇을 만드는지 (미리 보기)

- **평 × 3** — 그냥 배치. 이 층은 웨이브 구조가 아니라서 `EncounterSpawner` 없이 3마리를 씬에 바로 놓습니다 (전투 자체는 계단 조건과 무관 — 아래 "설계 메모" 참고)
- **바닥 타일** (`PaintableObject` 부착) — 색 복원되는 순간이 구슬 등장 트리거
- **숨겨진 구슬 스포너** (`HiddenOrbSpawner.cs`) — 바닥 타일이 칠해지면 구슬 하나를 등장시키고, 그 구슬을 먹으면 계단을 엽니다
- **계단** — 1층 때와 똑같이 `Stairs.cs`, 단 `RoomClearGate` 연결 없이 `HiddenOrbSpawner`가 직접 `Activate()`를 호출합니다

---

## 1단계 — 적 배치

1. `SC_Face_1`을 엽니다 (2층 콘텐츠는 이 씬에 넣습니다 — 두 번째로 방문하게 될 면)
2. 1층에서 만든 `EnemyPyeong` 프리팹을 Project 창에서 Hierarchy로 3번 드래그해서 배치 (적당히 흩어진 위치로)
3. ⚠️ **[[changelog/2026-08-19_인카운터스포너-1층콘텐츠]]에서 겪은 버그를 반복하지 않으려면**: 여기서 놓는 3마리는 그냥 씬에 상주하는 일반 배치이지 프리팹 참조 필드가 아니므로 이번엔 해당 버그 걱정은 없습니다.

## 2단계 — 바닥 타일 (색 복원 트리거) 만들기

1. Hierarchy 빈 곳에서 우클릭 → `3D Object` → `Plane` (또는 `Cube`를 납작하게) → 이름을 `FloorTile_Hidden`으로 변경
2. 적당한 위치(방 안쪽, 눈에 띄지 않는 구석 등)에 배치
3. `Add Component` → `Paintable Object` 부착
   - `True Color`: 원하는 색(예: 밝은 회색이나 패턴 느낌 색) 지정
   - `Start Gray`: 켜둔 채로 (회색에서 시작해야 "복원"이 느껴짐)

> 이 타일이 이미 씬에 있는 다른 `PaintableObject`(색 복원 파동이 닿는 벽/바닥 등)와 똑같이 동작합니다 — 플레이어가 색 복원 파동 범위 안에 들어가면 자동으로 칠해집니다.

## 3단계 — 숨겨진 구슬 스포너 연결

1. Hierarchy 빈 곳에서 `Create Empty` → 이름을 `HiddenOrbSpawner`로 변경
2. `Add Component` → `Hidden Orb Spawner` 검색해서 부착
3. Inspector에서:
   - `Trigger`: 2단계에서 만든 `FloorTile_Hidden`을 드래그해서 연결
   - `Spawn Point`: 구슬이 나타날 위치의 빈 오브젝트를 만들어 연결 (비워두면 이 스포너 자신의 위치를 씀)
   - `Orb Color`: 원하는 색 선택 (예: `Blue`)
   - `Stairs To Activate`: 4단계에서 만들 `Stairs`를 나중에 연결 (지금은 비워둬도 됨, 순서 상관없음)

## 4단계 — 계단 배치

[[logic/계단 & 방 클리어 게이트 씬 설정]] 1단계와 동일하게 `Stairs` 오브젝트를 만들되, **`RoomClearGate`는 만들지 않습니다.** 대신:

1. `Stairs` 오브젝트를 만들고 `Stairs.cs` 부착, `Box Collider`의 `Is Trigger` 체크, `Start Active`는 끄기
2. 3단계에서 만든 `HiddenOrbSpawner`의 `Stairs To Activate` 필드에 이 `Stairs`를 드래그해서 연결

## 5단계 — 저장 + 테스트

1. `Ctrl+S`로 `SC_Face_1` 저장
2. `SC_Game`을 열고 Play (1층을 클리어해서 2층/`SC_Face_1`로 넘어오거나, 테스트 편의상 `CubeMapManager`에서 직접 확인)
3. `FloorTile_Hidden` 근처에서 색 복원 파동이 닿게 만들기(붓으로 처치 후 근처에서 구슬 사용 등) → 콘솔에 `[HiddenOrbSpawner] 숨겨진 구슬 등장!` 로그와 함께 구슬이 나타나는지 확인
4. 구슬을 주우면 `[HiddenOrbSpawner] 숨겨진 구슬 획득!` → `[Stairs] Stairs 활성화!` 순서로 로그가 뜨고 계단이 나타나는지 확인

## 설계 메모 — 왜 전투가 계단 조건이 아닌지

기획서 2층 스펙엔 "계단 조건: 색 구슬 획득 후 자동 등장"만 적혀있고 "전투 클리어"가 없습니다. 1층(튜토리얼, 전투 클리어가 곧 계단 조건)과 의도적으로 다른 패턴입니다 — 매 층이 "적 다 잡아야 진행"이면 반복적으로 느껴질 수 있어서, 2층은 "탐색해서 숨겨진 걸 찾는" 감각으로 설계된 것으로 해석했습니다. 평 3마리는 그대로 두되(플레이어가 이동하려면 자연히 마주침) 계단 게이트로 강제하지 않았습니다.
