# 5층 콘텐츠 — 익숙한 골목 씬 설정

> [[19 층별 상세 설계]] 5층 스펙: "평×3, 원×1, 계단 조건 = 전투 클리어, 특이사항 = 반복 층
> 힌트 시작(나레이션 '이 골목... 전에 본 것 같은데.')".
>
> **코드 변경 없음** — 3층과 완전히 같은 패턴(전투 클리어 → `RoomClearGate`+`Stairs`)이고,
> "반복 층 힌트" 나레이션도 이미 `CubeMapManager.MarkVisited()` + `NarrationManager`가 자동으로
> 처리합니다(3층 테스트에서 이미 검증됨 — 어떤 면이든 2번째 방문하면 Hint 문구가 자동으로 뜸).
> 새로 만들 시스템이 없습니다.

## 어느 면에 넣을지 — 이번엔 두 후보가 있음

지금까지 설정된 면: 0(1층), 4(2층), 2(3층), 5(4층). 회전 테이블(`CubeMapManager.RotationTableCW`)로 계산해보면 아직 안 가본 면(1, 3) 둘 다 남아있고, **플레이어가 계단을 밟는 시점에 어느 면에 있었는지에 따라 다음 목적지가 1이 될 수도 3이 될 수도 있습니다.** 그래서 이번엔 우선 **면 1**에 넣는 걸 추천합니다(4층/면5에서 계단 밟으면 자연스럽게 도달 가능한 경로 중 하나 — 정확히는 면4에서 Y축 회전 시 면1). 남은 면 3은 나중에 같은 절차로 채우면 됩니다 — 두 면 다 채워두면 순서 상관없이 항상 새 콘텐츠로 이어집니다.

## 0단계 — SC_Face_4 새 씬 만들기

[[logic/3층 콘텐츠 - 전봇대 거리 씬 설정]] 1단계와 동일: `Assets/Scenes`에 새 씬 생성(`SC_Face_4`) → `Ground`(Plane) + `SpawnPoint` 배치 → 저장

## 1단계 — Addressable 등록 + CubeFaceData 생성

1. `Groups` 창에서 `SC_Face_4`를 `Default Local Group`으로 드래그, 주소 정리
2. `Assets/Data`에 `CubeFaceData_4` 생성 → `Face Index`=`1`(⚠️ 파일 이름 번호랑 다름 — 씬이 실제로 대응하는 면 번호가 중요), `Scene Reference`=`SC_Face_4`
3. `SC_Game`의 `GameSystems` → `GameState` → `Face Data` 배열의 **Element 1**에 `CubeFaceData_4` 연결

## 2단계 — 적 배치 (평×3, 원×1)

`EnemyPyeong` 프리팹 3번, `EnemyWon` 프리팹 1번 드래그해서 적당히 배치

## 3단계 — 계단 & 방 클리어 게이트

[[logic/계단 & 방 클리어 게이트 씬 설정]] 1~2단계 그대로: `Stairs` + `RoomClearGate`(적 4마리 다 덮도록 `Bounds Size` 조정, `Stairs` 연결)

## 4단계 — 저장 + 테스트

1. `Ctrl+S`로 저장
2. `SC_Game`에서 Play → 4층까지 거쳐서 면1(또는 그 경로가 안 나오면 아직 면3이 비어있어서 다른 곳으로 갈 수 있음 — 그때는 0단계~3단계를 면3에도 반복)
3. 평×3 + 원×1 전부 처치 → `RoomClearGate` 클리어 → 계단 → 회전 확인
4. 이 면을 2번째 방문했을 때 "이 골목... 전에 본 것 같은데." 나레이션이 자동으로 뜨는지 확인 (이미 검증된 기능이라 특별히 새로 확인할 건 없지만, 5층 스펙의 핵심 포인트라 한 번 체감해보면 좋음)
