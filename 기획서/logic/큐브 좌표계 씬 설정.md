# 큐브 좌표계 씬 설정 (Addressables 면 전환)

> [[CubeMapManager]] + [[GameState]] + [[CubeFaceData]] + [[FadeManager]] 코드는 완성되어 있습니다.
> 이 문서는 그걸 실제로 동작시키기 위한 **Unity 에디터 설정 절차**입니다. Cinemachine/NavMesh 설정보다
> 훨씬 손이 많이 갑니다 — Addressables를 이 프로젝트에서 처음 실제로 쓰는 거라 그렇습니다. 천천히 순서대로.

## 왜 이렇게 복잡한가 (배경)

지금까지 `SampleScene` 하나에 Player, GameSystems(매니저들), Ground, 적들이 전부 같이 들어있습니다.
큐브 좌표계는 "면(Face)마다 별도 씬"이 전제라서, **Player/매니저는 계속 남아있고 면 콘텐츠만 통째로
갈아끼울 수 있게** 씬을 분리해야 합니다. 그래서:

- **SC_Game** (새로 만듦): Player, GameSystems(매니저 전부)가 사는 "영구 씬" — 절대 언로드 안 됨
- **SC_Face_0 ~ SC_Face_5** (SampleScene을 씨앗으로 6개 준비): Ground, 적, 장식물 등 "면 콘텐츠" — 회전할 때마다 하나만 로드되고 나머진 언로드됨

## 0단계 — 지금 상태 기준 v0.2 첫 테스트 범위 (읽고 시작할 것)

**전체 6개 면에 각각 다른 레벨 디자인을 채우는 건 이 단계의 목표가 아닙니다.** 지금 목표는 "회전하면
진짜로 다른 씬으로 전환되고, 플레이어가 SpawnPoint로 순간이동하는 핵심 메커니즘이 동작하는가"만
검증하는 것. 그래서 **SC_Face_1~5는 일단 SC_Face_0를 복제한 것으로 채워도 충분**합니다 (내용은 나중에
따로 다듬으면 됨). 6개를 전부 만드는 게 부담되면 **처음엔 2개(Face 0, Face 1)만 만들어서 전환 자체가
되는지부터 확인**해도 좋습니다 — 나머지는 GameState의 Face Data 슬롯을 비워두면 그냥 회전 후보에서
자동으로 제외됩니다 (코드가 null 체크를 하도록 짜여 있음).

---

## 1단계 — Addressables 최초 설정 (한 번만)

1. 상단 메뉴 `Window` → `Asset Management` → `Addressables` → `Groups`
2. 처음 여는 거라면 "Create Addressables Settings" 버튼이 보일 겁니다 → 클릭 (프로젝트에 Addressables 설정 파일들이 자동 생성됨)
3. `Addressables Groups` 창이 뜨면 준비 완료. 이 창은 이후 계속 씁니다.

## 2단계 — 영구 씬(SC_Game) 만들고 Player/매니저 옮기기

1. `Assets/Scenes` 폴더에서 우클릭 → `Create` → `Scene` → 이름 `SC_Game`
2. `SC_Game`을 더블클릭해서 열기 (지금은 빈 씬)
3. `File` → `Open Scene Additive`(또는 Project 창에서 `SampleScene`을 Hierarchy로 드래그)로 `SampleScene`도 같이 열기 — 이제 Hierarchy에 두 씬이 동시에 보입니다
4. `SampleScene`에서 **Player, GameSystems(그 아래 모든 매니저 컴포넌트가 붙은 오브젝트), Main Camera(Cinemachine 관련 오브젝트 포함), EventSystem(있다면)** 을 Hierarchy에서 선택해서 **`SC_Game` 쪽으로 드래그** — 이렇게 하면 그 오브젝트들의 소속 씬이 SC_Game으로 바뀝니다
5. `SC_Game`을 저장 (`Ctrl+S` 또는 `File > Save`)

> ⚠️ 이동 후 `SampleScene`에는 Ground, 적, 장식물 등 **레벨 콘텐츠만** 남아있어야 합니다. Player/매니저가 실수로 남아있으면 나중에 면 전환할 때 같이 사라집니다.

## 3단계 — SampleScene을 SC_Face_0로 정리

1. `SampleScene`에 **SpawnPoint 빈 오브젝트 추가**: Hierarchy 우클릭 → `Create Empty` → 이름을 정확히 `SpawnPoint`로 (대소문자까지 정확히 — `CubeMapManager`가 이름으로 찾습니다) → 플레이어가 이 면에 도착했을 때 서 있을 위치/방향으로 옮기기
2. `SampleScene`을 저장
3. Project 창에서 `SampleScene`을 복사(`Ctrl+D` 또는 우클릭 `Duplicate`) → 이름을 `SC_Face_0`로 변경 (원본 `SampleScene`은 이제 안 씀 — 지워도 되고 그냥 둬도 무방)

## 4단계 — 나머지 면 씬 준비 (최소 2개, 권장 6개)

1. `SC_Face_0`을 Project 창에서 복사해서 `SC_Face_1` 생성 (테스트용이면 내용 그대로 둬도 됨)
2. 나중에 시간 될 때 `SC_Face_2` ~ `SC_Face_5`도 같은 방식으로 준비 (지금 당장 안 해도 회전 시스템 자체는 잘 동작함 — 0단계 참고)

## 5단계 — 면 씬들을 Addressable로 등록

1. `Addressables Groups` 창에서, Project 창의 `SC_Face_0`(, `SC_Face_1`, …)을 **Groups 창 안으로 드래그** → `Default Local Group`에 등록됨
2. 각 항목의 주소(Address) 이름을 **정확히** `SC_Face_0`, `SC_Face_1`… 로 바꾸기 (더블클릭해서 수정) — 파일명과 달라도 상관없지만, 뒤에서 CubeFaceData가 이 주소가 아니라 **AssetReference로 직접 연결**하니 이름 자체는 편의상 맞춰두는 정도면 충분합니다

## 6단계 — CubeFaceData 에셋 만들기

1. `Assets/Data`(없으면 새로 만들기) 폴더에서 우클릭 → `Create` → `MG` → `Cube Face Data` → 6번(또는 준비한 면 개수만큼) 반복해서 `CubeFaceData_0` ~ `CubeFaceData_5` 생성
2. 각 에셋을 선택해서 Inspector에서:
   - `Face Index`: 0, 1, 2… 순서대로
   - `Scene Reference`: 대응하는 `SC_Face_N` 씬을 끌어다 놓기 (Addressable로 등록된 씬만 드롭 가능)

## 7단계 — GameSystems에 매니저 부착 + 연결

`SC_Game`을 열고 `GameSystems` 오브젝트(2단계에서 옮긴 것)에:

1. **`GameState.cs` 부착** → Inspector의 `Face Data` 배열 크기를 6으로 맞추고, 6단계에서 만든 `CubeFaceData_0~5`를 순서대로(인덱스 맞춰서) 끌어다 놓기. 준비 안 한 면은 슬롯을 비워둬도 됩니다(자동으로 회전 후보에서 제외됨)
2. **`CubeMapManager.cs` 부착** → `Starting Face Index`는 기본값 0이면 됩니다
3. **`FadeManager.cs` 부착** → 별도 설정 필요 없음 (Awake에서 알아서 화면 페이드용 Canvas를 만듦)
4. **`DebugOrbCheat.cs`가 이미 부착돼 있다면 그대로 둠** (F4로 회전 테스트 가능)

## 8단계 — 재생 테스트

1. **반드시 `SC_Game` 씬을 연 상태에서 Play** (`SampleScene`이나 `SC_Face_0`을 직접 열고 Play하면 Player/매니저가 없어서 안 됩니다)
2. Play 시작하면 콘솔에 `[CubeMapManager] 플레이어를 (...)로 이동.` 로그가 뜨면서 Face 0가 로드된 것 — Game 뷰에 Ground/적이 보이는지 확인
3. **F4**를 눌러 회전 테스트 → 콘솔에 `회전 시작!` → 화면이 검게 페이드 → `Addressables.UnloadSceneAsync` → 다음 면 로드 → 페이드 인 → `n층 도착` 로그까지 순서대로 뜨는지 확인
4. Face 1을 준비했다면 화면 내용이 바뀌는 게 보여야 함 (지금은 Face 0 복제본이라 겉보기엔 똑같을 수 있음 — 그래도 콘솔 로그의 "현재 면" 숫자가 바뀌는지로 실제 전환 여부를 확인할 수 있습니다)

## 자주 나올 수 있는 문제

| 증상 | 원인 |
|------|------|
| Play 해도 아무것도 안 보임 | `SC_Game`이 아니라 다른 씬을 열고 Play했을 가능성 — Player/매니저가 없는 씬 |
| "면 데이터 또는 씬 참조가 비어있습니다" 로그 | `CubeFaceData` 에셋의 `Scene Reference`를 연결 안 했거나, `GameState`의 `Face Data` 배열에 안 넣었음 |
| "GameState가 씬에 없습니다" 로그 | `GameSystems`에 `GameState.cs`를 안 붙였음 |
| F4 눌러도 반응 없음 | `DebugOrbCheat.cs`가 씬에 없거나, Game 뷰에 입력 포커스가 없음(Game 뷰를 한 번 클릭) |
| Addressable로 드래그해도 등록 안 됨 | 1단계(Addressables 최초 설정)를 안 했을 가능성 |
