# 3층 콘텐츠 — 전봇대 거리 씬 설정

> [[19 층별 상세 설계]] 3층 스펙: "평×2, 원×1, 첫 원거리 적 등장, 계단 조건 = 전투 클리어".
> 2층과 달리 계단 조건이 다시 "전투 클리어"라서 [[logic/계단 & 방 클리어 게이트 씬 설정]]의
> `RoomClearGate`+`Stairs` 패턴을 그대로 씁니다. 웨이브 구조가 아니라서(1층처럼 순차 스폰이 아님)
> `EncounterSpawner`는 안 씁니다 — 그냥 3마리를 씬에 바로 배치.
>
> ⚠️ 이번엔 **`SC_Face_2`가 아예 새 씬**이라서, [[logic/큐브 좌표계 씬 설정]]의 면 추가 절차(4~7단계)부터
> 다시 거쳐야 합니다. 1~3단계(Addressables 최초 설정, SC_Game, SC_Face_0)는 이미 끝나있으니 건너뜁니다.

## 0단계 — EnemyWon 프리팹 만들기 (아직 없음)

지금까지는 `EnemyPyeong` 프리팹만 있고 `EnemyWon`(원거리 먹괴음) 프리팹은 없습니다. `SC_Face_0`나 `SC_Face_1`을 열어보면 예전 테스트용 `EnemyWon`이 Hierarchy에 남아있을 겁니다:

1. `SC_Face_0`(또는 `SC_Face_1`)을 열고, Hierarchy에서 `EnemyWon`을 찾기
2. **Project 창의 `Assets/Scenes`(또는 원하는 폴더)로 드래그** — `EnemyPyeong` 만들 때와 똑같이. ⚠️ **꼭 Project 창으로 드래그할 것** — [[changelog/2026-08-19_인카운터스포너-1층콘텐츠]]에서 겪었던 "Hierarchy 오브젝트를 잘못 참조" 버그를 반복하지 않기 위함
3. 프리팹이 만들어지면, 원래 씬에 남은 `EnemyWon` 인스턴스는 그대로 두거나 지워도 무방(지금 이 씬에서 쓸 게 아니면 지워도 됨)
4. 이 씬을 건드렸다면 `Ctrl+S`로 저장

## 1단계 — SC_Face_2 새 씬 만들기

1. Project 창 `Assets/Scenes`에서 우클릭 → `Create` → `Scene` → 이름 `SC_Face_2`
2. 더블클릭해서 열기 (빈 Hierarchy)
3. Hierarchy 빈 곳에서 `Create Empty` → 이름을 정확히 **`SpawnPoint`**로 → Ground가 없는 빈 씬이니, 우선 바닥 역할 오브젝트도 하나 만들어두기: `3D Object` → `Plane`, 이름 `Ground`, 적당한 크기로 스케일 조정. `SpawnPoint`는 이 `Ground` 위, 막힌 곳 없는 자리로 Position 배치
4. `Ctrl+S`로 저장

## 2단계 — Addressable 등록 + CubeFaceData 생성

[[logic/큐브 좌표계 씬 설정]] 5~6단계와 동일한 절차를 `SC_Face_2` 하나에 대해서만 반복:

1. `Window > Asset Management > Addressables > Groups` 열기
2. Project 창에서 `SC_Face_2` 선택 → `Groups` 창의 `Default Local Group` 안으로 드래그 → 주소를 `SC_Face_2`로 정리
3. `Assets/Data` 폴더에서 우클릭 → `Create` → `MG` → `Cube Face Data` → 이름 `CubeFaceData_2`
4. `CubeFaceData_2` Inspector: `Face Index` = `2`, `Scene Reference` = `SC_Face_2` 씬 파일 드래그
5. `SC_Game`의 `GameSystems` → `GameState` 컴포넌트 → `Face Data` 배열의 **Element 2**에 `CubeFaceData_2`를 드래그해서 연결

## 3단계 — 적 배치 (평×2, 원×1)

1. `SC_Face_2`에서 `EnemyPyeong` 프리팹을 Project 창에서 Hierarchy로 **2번** 드래그
2. 0단계에서 만든 `EnemyWon` 프리팹을 Project 창에서 Hierarchy로 **1번** 드래그
3. 세 마리 모두 `Ground` 위 적당히 흩어진 위치로 배치. `EnemyWon`은 원거리 공격이니 좀 더 트인 공간에 두면 좋음

## 4단계 — 계단 & 방 클리어 게이트

[[logic/계단 & 방 클리어 게이트 씬 설정]] 1~2단계를 `SC_Face_2`에 그대로 적용:

1. `Stairs` 오브젝트 생성 + `Stairs.cs` 부착 + `Box Collider` `Is Trigger` 체크 + `Start Active` 끄기
2. `RoomClearGate` 오브젝트 생성 + `Room Clear Gate` 부착 + `Bounds Size`를 3단계에서 배치한 적들을 전부 덮도록 조정 + `Stairs` 필드에 위 `Stairs` 연결

## 5단계 — 저장 + 테스트

1. `Ctrl+S`로 `SC_Face_2` 저장
2. `SC_Game`을 열고 Play → 2층까지 진행해서 3층(면 2)으로 회전해 들어가거나, 테스트 편의상 `CubeMapManager`가 면 2를 후보로 잡는지 먼저 확인
3. 평 2마리 + 원 1마리 전부 처치 → `[RoomClearGate] ... 계단 활성화.` → 계단 밟기 → 정상 흐름 확인
