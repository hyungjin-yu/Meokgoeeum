> 2026-08-16 신규 작성

## 왜 필요한가

[[09 개발 마일스톤]]은 "무엇을 만들지"는 정의하지만 "무엇이 잘못될 수 있고, 잘못됐을 때 뭘 먼저 버릴지"는 정의하지 않는다. 1인 개발에서 가장 흔한 실패 패턴은 리스크를 몰라서가 아니라, **일정이 밀렸을 때 뭘 잘라야 할지 미리 정해두지 않아서** 전체가 완성 못 된 채로 멈추는 것이다. 이 문서는 필러 4("혼자서 끝까지 만들 수 있는 범위")를 실행 계획으로 구체화한다.

## MoSCoW 스코프 우선순위

일정이 밀렸을 때 항상 이 순서로 자른다. **WON'T부터 자르고, MUST는 절대 건드리지 않는다.**

### MUST (있어야 "먹괴음"이라 부를 수 있는 것)
- 이동 + 3타 콤보 전투
- 색 복원 파동 연출 (필러 1의 핵심)
- 먹괴음 최소 2종 (평, 원)
- 층 8개 이상 + 보스 1체
- 반복 층 연출 최소 1회 (필러 2 성립 조건)
- 색맹 "패턴 강조 모드" (→ 필수, 접근성은 협상 대상 아님)

### SHOULD (있으면 완성도가 확 오르는 것)
- 6색 전부 + 스킬 전부
- 12층 전체 + 강화 버전 적
- 뉴게임+
- 색맹 LUT 보정 모드

### COULD (여유 있으면)
- 색 도감 UI
- Steam Cloud 저장
- 컷씬 풀 연출 (Timeline 다단계)
- 게임패드 지원

### WON'T (이번 버전에서 절대 안 함)
- 멀티플레이/협동
- 모바일 포팅
- 음성 더빙
- 2번째 무기 시스템 (필러 3 위반이기도 함)

## 최소 출시 가능 버전 (MVR — Minimum Viable Release)

v1.0 풀 비전 완성이 어려워질 경우, 아래 기준으로도 "완성된 게임"으로 출시 가능하다고 미리 합의해둔다.

```
MUST 항목 전체 + SHOULD 중 "6색 전부"만 추가
= 8개 층 + 보스 1체 + 6색 스킬 + 반복 층 연출 1회 + 색맹 대응
플레이타임: 3~4시간 (12층 풀 버전의 절반)
가격: ₩6,500 내외로 하향 조정
```

> 이 기준을 넘는 모든 것은 "출시 후 무료 업데이트"로 전환 가능하다는 점을 스팀 페이지에 미리 암시해두면, 축소 출시가 "미완성"이 아니라 "확장 예정"으로 읽힌다.
