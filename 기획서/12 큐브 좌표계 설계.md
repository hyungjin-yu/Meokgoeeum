# 큐브 좌표계 설계

> 2026-03-23 초안 | 2026-05-29 Unity 6.3 LTS C# + Addressables로 전환

## 개요

게임의 전체 맵은 정육면체(큐브) 1개다.
각 면이 하나의 3D 구역이며, 색 구슬 획득 시 큐브가 회전하여 보이는 면이 달라진다.
Unity에서는 각 면을 **Addressable Scene**으로 관리하고, 회전 시 LoadSceneAsync / UnloadSceneAsync로 처리한다.

## 면 인덱스 정의

```
면 인덱스:
  0 = Front  (앞)
  1 = Back   (뒤)
  2 = Top    (위)
  3 = Bottom (아래)
  4 = Left   (왼쪽)
  5 = Right  (오른쪽)
```

## Unity 구현 구조

```
Addressable Groups:
  SC_Game          ← Persistent Scene (플레이어, 매니저 오브젝트 상주)
  SC_Face_0        ← Front 면 (Additive 로드)
  SC_Face_1        ← Back 면
  SC_Face_2        ← Top 면
  SC_Face_3        ← Bottom 면
  SC_Face_4        ← Left 면
  SC_Face_5        ← Right 면

한 번에 1개 면만 Additive 로드 상태.
회전 시: 현재 면 UnloadScene → 다음 면 LoadSceneAsync(Additive) + 페이드 트랜지션.
```

## 회전 로직 (C#)

```csharp
// CubeMapManager.cs (Singleton MonoBehaviour)

public class CubeMapManager : MonoBehaviour
{
    public static CubeMapManager Instance { get; private set; }

    private int currentFaceIndex = 0;
    private AsyncOperationHandle<SceneInstance> currentSceneHandle;

    // 각 축 90도 CW 회전 시 면 인덱스 재배치 테이블
    // X축 CW: Front→Bottom→Back→Top→Front
    // Y축 CW: Front→Right→Back→Left→Front
    // Z축 CW: Top→Right→Bottom→Left→Top
    private static readonly int[][] RotationTable =
    {
        new[] { 3, 2, 0, 1, 4, 5 },  // X축 CW
        new[] { 4, 5, 2, 3, 1, 0 },  // Y축 CW
        new[] { 0, 1, 5, 4, 2, 3 },  // Z축 CW
    };

    // 2026-08-16: "층수"는 면 개수(6)와 별개인 진행 카운터.
    // 6면을 모두 최초 방문하기 전까지는 재방문이 발생하지 않도록 가중치를 준다
    // (→ [[05 맵 시스템 - 큐브 구조]] "층과 면의 관계" 절, QA LVL-1 대응)
    private int floorNumber = 0; // UI에 표시되는 "B{floorNumber}F" — 면과 1:1 대응 아님

    public async UniTask RotateRandomAxis()
    {
        int axis = SelectWeightedAxis(); // 미방문 면이 남아있으면 그쪽으로 가중, 다 방문했으면 완전 랜덤
        int nextFaceIndex = RotationTable[axis][currentFaceIndex];

        await FadeManager.Instance.FadeOut();

        // 현재 면 언로드
        if (currentSceneHandle.IsValid())
            await Addressables.UnloadSceneAsync(currentSceneHandle);

        // 다음 면 로드
        currentSceneHandle = Addressables.LoadSceneAsync(
            $"SC_Face_{nextFaceIndex}", LoadSceneMode.Additive);
        await currentSceneHandle;

        // 플레이어 위치 재배치
        PlayerController.Instance.TeleportToFaceSpawnPoint();

        floorNumber++;
        HUDManager.Instance.SetFloorDisplay(floorNumber); // "B{n}F" 표시만 갱신, 면 로직과 무관

        // 방문 횟수 갱신 + 재방문 판정
        UpdateVisitCount(nextFaceIndex);

        await FadeManager.Instance.FadeIn();

        currentFaceIndex = nextFaceIndex;
    }

    // 6개 면을 전부 최소 1번 방문하기 전까지는, 아직 안 가본 면으로만 이어지는 축을 우선 선택.
    // 다 가봤으면(7번째 회전부터) 완전 무작위 — 그때부터 재방문이 나올 수 있음.
    private int SelectWeightedAxis()
    {
        var unvisitedAxes = new List<int>();
        for (int axis = 0; axis < 3; axis++)
        {
            int candidate = RotationTable[axis][currentFaceIndex];
            if (!GameState.Instance.GetFaceData(candidate).isVisited)
                unvisitedAxes.Add(axis);
        }
        var pool = unvisitedAxes.Count > 0 ? unvisitedAxes : new List<int> { 0, 1, 2 };
        return pool[Random.Range(0, pool.Count)];
    }

    private void UpdateVisitCount(int faceIndex)
    {
        var faceData = GameState.Instance.GetFaceData(faceIndex);
        faceData.visitCount++;
        faceData.isVisited = true;

        // 2번째 방문 = 첫 재방문(약한 데자뷰), 3번째 이상 = 확신 단계(강한 내레이션)
        if (faceData.visitCount == 2)
            NarrationManager.Instance.TriggerRevisitNarration(NarrationTier.Hint);
        else if (faceData.visitCount >= 3)
            NarrationManager.Instance.TriggerRevisitNarration(NarrationTier.Confirmed);
    }
}
```

## 면별 데이터 구조 (ScriptableObject)

```csharp
// CubeFaceData.cs
[CreateAssetMenu(menuName = "MG/CubeFaceData")]
public class CubeFaceData : ScriptableObject
{
    public int faceIndex;
    public AssetReference sceneReference;     // Addressable Scene 참조 (1차 방문용 레이어)
    public AssetReference revisitOverrideData; // 재방문 시 적용할 오브젝트 배치 차이 (선택적, 필러 2: 완전 동일 금지)
    public bool isColorRestored;
    public Color faceColor;
    public bool isVisited;
    public int visitCount;                    // 0=미방문, 1=최초 방문, 2 이상=재방문 (구 isRevisited 대체)
}
```

## 반복 층 연출 처리

- `visitCount`가 2 이상이 되는 순간마다 판정 (bool 플래그가 아니라 카운터로 관리 — 3번째 이상 재방문 시 내레이션 강도를 더 높이기 위함)
- 트리거 시 → 나레이션 텍스트 글리치 UI + AudioMixer로 BGM 피치/에코 변형
- **12층(큐브 구조 노출)과 최종층(보스 방)은 이 순환에 포함되지 않는다** — 별도 씬(`SC_CubeReveal`, `SC_Boss`)이며 `floorNumber`가 특정 값(예: 12)에 도달하면 6면 순환을 벗어나 이 특수 씬으로 전환 (→ [[10 씬 구조 & 기술 스펙]])

## 확정 사항

- **회전 방향:** CW/CCW 랜덤 (RotationTable을 역방향 적용으로 CCW 처리)
- **회전 시 플레이어 위치:** 각 면의 지정된 SpawnPoint Transform으로 이동
- **면별 맵 생성:** 프로시저럴 생성 또는 미리 제작된 씬 풀에서 선택
- **UniTask 사용:** 비동기 씬 로딩을 위해 UniTask 패키지 도입 (Addressables 연동)
- **층(floorNumber) vs 면(faceIndex) 분리:** 1~6층은 미방문 면 우선 가중치로 항상 신규 콘텐츠 보장, 7층부터 완전 랜덤(재방문 가능) — 2026-08-16 확정 (→ [[05 맵 시스템 - 큐브 구조]])
