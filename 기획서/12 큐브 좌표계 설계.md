# 큐브 좌표계 설계

> 2026-03-23 초안 | 2026-05-29 Unity 6.3 LTS C# + Addressables로 전환

## 개요

게임의 전체 맵은 정육면체(큐브) 1개다.
각 면이 하나의 3D 구역이며, 색 구슬 획득 시 큐브가 회전하여 보이는 면이 달라진다.
Unity에서는 각 면을 **Addressable Scene**으로 관리하고, 회전 시 LoadSceneAsync / UnloadSceneAsync로 처리한다.

## 면 인덱스 정의

```
면 인덱스:
  0 = Front  (앞)
  1 = Back   (뒤)
  2 = Top    (위)
  3 = Bottom (아래)
  4 = Left   (왼쪽)
  5 = Right  (오른쪽)
```

## Unity 구현 구조

```
Addressable Groups:
  SC_Game          ← Persistent Scene (플레이어, 매니저 오브젝트 상주)
  SC_Face_0        ← Front 면 (Additive 로드)
  SC_Face_1        ← Back 면
  SC_Face_2        ← Top 면
  SC_Face_3        ← Bottom 면
  SC_Face_4        ← Left 면
  SC_Face_5        ← Right 면

한 번에 1개 면만 Additive 로드 상태.
회전 시: 현재 면 UnloadScene → 다음 면 LoadSceneAsync(Additive) + 페이드 트랜지션.
```

## 회전 로직 (C#)

```csharp
// CubeMapManager.cs (Singleton MonoBehaviour)

public class CubeMapManager : MonoBehaviour
{
    public static CubeMapManager Instance { get; private set; }

    private int currentFaceIndex = 0;
    private AsyncOperationHandle<SceneInstance> currentSceneHandle;

    // 각 축 90도 CW 회전 시 면 인덱스 재배치 테이블
    // X축 CW: Front→Bottom→Back→Top→Front
    // Y축 CW: Front→Right→Back→Left→Front
    // Z축 CW: Top→Right→Bottom→Left→Top
    private static readonly int[][] RotationTable =
    {
        new[] { 3, 2, 0, 1, 4, 5 },  // X축 CW
        new[] { 4, 5, 2, 3, 1, 0 },  // Y축 CW
        new[] { 0, 1, 5, 4, 2, 3 },  // Z축 CW
    };

    public async UniTask RotateRandomAxis()
    {
        int axis = Random.Range(0, 3);
        int nextFaceIndex = RotationTable[axis][currentFaceIndex];

        await FadeManager.Instance.FadeOut();

        // 현재 면 언로드
        if (currentSceneHandle.IsValid())
            await Addressables.UnloadSceneAsync(currentSceneHandle);

        // 다음 면 로드
        currentSceneHandle = Addressables.LoadSceneAsync(
            $"SC_Face_{nextFaceIndex}", LoadSceneMode.Additive);
        await currentSceneHandle;

        // 플레이어 위치 재배치
        PlayerController.Instance.TeleportToFaceSpawnPoint();

        // 반복 층 판정
        UpdateRevisitFlag(nextFaceIndex);

        await FadeManager.Instance.FadeIn();

        currentFaceIndex = nextFaceIndex;
    }

    private void UpdateRevisitFlag(int faceIndex)
    {
        var faceData = GameState.Instance.GetFaceData(faceIndex);
        if (faceData.isVisited)
        {
            faceData.isRevisited = true;
            NarrationManager.Instance.TriggerRevisitNarration();
        }
        faceData.isVisited = true;
    }
}
```

## 면별 데이터 구조 (ScriptableObject)

```csharp
// CubeFaceData.cs
[CreateAssetMenu(menuName = "MG/CubeFaceData")]
public class CubeFaceData : ScriptableObject
{
    public int faceIndex;
    public AssetReference sceneReference;     // Addressable Scene 참조
    public bool isColorRestored;
    public Color faceColor;
    public bool isVisited;
    public bool isRevisited;                  // 반복 층 연출 플래그
}
```

## 반복 층 연출 처리

- 같은 faceIndex의 면이 다시 등장할 때 `isRevisited = true`
- 플래그 감지 시 → 나레이션 텍스트 글리치 UI 트리거 + AudioMixer로 BGM 피치/에코 변형

## 확정 사항

- **회전 방향:** CW/CCW 랜덤 (RotationTable을 역방향 적용으로 CCW 처리)
- **회전 시 플레이어 위치:** 각 면의 지정된 SpawnPoint Transform으로 이동
- **면별 맵 생성:** 프로시저럴 생성 또는 미리 제작된 씬 풀에서 선택
- **UniTask 사용:** 비동기 씬 로딩을 위해 UniTask 패키지 도입 (Addressables 연동)
