#기획 #먹괴음 #튜토리얼

# 튜토리얼 설계

> 2026-05-29 재작성 (실시간 3D 액션 기준)

## 튜토리얼 방식

**환경으로 자연스럽게 유도** — NPC 대화 없음. 텍스트 팝업 힌트 최소화.
좁은 구역에서 하나씩 경험하게 배치.

## 튜토리얼 스킵

- ESC → 스킵 팝업 노출
- 확인 시 스킵 + 1층 시작 지점으로 이동
- 취소 시 튜토리얼 계속

## 단계별 설계

### 1단계 — 이동

- 구역: 긴 복도 (출구가 막혀 있음)
- 바닥에 발자국 이펙트로 WASD 이동 유도
- 달성 조건: 복도 끝 도달

### 2단계 — 구르기

- 구역: 좁은 통로 + 느리게 움직이는 장애물
- 장애물을 피해야 통과 가능 → Space 구르기 자연스럽게 학습
- 팝업: "Space — 구르기"

### 3단계 — 첫 전투

- 구역: **1층(회색 골목)과 같은 공간** — 별도의 튜토리얼 전용 방이 아니라 1층 전투 공간의 1웨이브째 (2026-08-16 확정, QA [[32 QA 리뷰 - 기획자 3인]] LVL-2 대응)
- 1웨이브: 먹괴음 - 평 1마리 (HP 절반 고정) — 마우스 좌클릭 3타 콤보를 안전하게 학습
- 1웨이브 처치 후 짧은 인터벌(약 2초) → **2웨이브: 정상 HP 평 1마리 추가 등장** → 이게 곧 [[19 층별 상세 설계]] 1층의 "평×2" 그 자체
- 2웨이브까지 처치 시 색 구슬 드랍 → 자동으로 다음 단계 (튜토리얼과 1층 클리어가 동시에 완료됨, 중복 전투 없음)

### 4단계 — 색 구슬 획득 & 파동 연출

- 드랍된 구슬 위로 이동 시 자동 획득 (F키 불필요)
- 색 복원 파동 연출 재생 → 맵에 색이 돌아오는 경험
- 팝업: "색이 돌아왔다"

### 5단계 — 색 스킬

- HUD 하단 구슬 슬롯 글로우 효과로 클릭 유도
- 스킬 팝업 열림 → 스킬 1개 선택 → 사용
- 팝업: "1~6 단축키로도 사용 가능"

### 6단계 — 맵 회전 인지

- 구슬 획득 후 맵 회전 연출 재생
- 회전 후 새로운 구역 등장
- 이후 자유 탐색

## 키 안내 팝업 타이밍

| 팝업 | 등장 시점 |
|------|----------|
| WASD — 이동 | 게임 시작 직후 |
| Space — 구르기 | 장애물 구역 진입 시 |
| 마우스 좌클릭 — 공격 | 첫 먹괴음 감지 시 |
| Tab — Lock-On | 첫 전투 후 |
| 1~6 — 스킬 | 첫 구슬 획득 후 |
| ESC — 메뉴 | 튜토리얼 종료 시 |
