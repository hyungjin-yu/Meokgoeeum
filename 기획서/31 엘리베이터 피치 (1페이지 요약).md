# 엘리베이터 피치 (1페이지 요약)

> 2026-08-16 신규 작성 — 25개 이상의 기획 문서를 다 읽을 시간이 없는 사람을 위한 1페이지

## 로그라인

> 색을 잃은 도시에서, 붓을 든 자가 먹물 괴물들을 쓰러뜨리며 세계의 색을 되찾는다.
> — 하지만 이 탑은, 탑이 아니었다.

| 항목 | 내용 |
|------|------|
| 장르 | 3D 실시간 액션 RPG |
| 플랫폼 | PC (Steam) |
| 엔진 | Unity 6.3 LTS (URP) |
| 개발 규모 | 1인 개발 (+ 디자이너 합류 협의 중) |
| 플레이타임 | 6~8시간 (1회차) |
| 가격 | ₩9,500~12,000 |

## 디자인 필러 (한 줄 요약)

1. **색은 감정의 증거다** — 색 복원은 점수가 아니라 기억을 되찾는 사건
2. **반복은 단서다, 배신이 아니다** — 데자뷰는 항상 정직한 힌트
3. **붓 하나로 싸우고, 되살리고, 나아간다** — 하나의 동작이 전투와 세계 복원을 겸함
4. **혼자서 끝까지 만들 수 있는 범위** — 완성이 화려함보다 우선

*(상세 → [[24 디자인 필러]])*

## 핵심 루프

```
탐색 → 먹괴음 조우 → 실시간 붓 전투 → 색 구슬 드랍
  → 획득(파동 연출 + 맵 회전) → 새 구역 개방 → 반복되는 층에 의문
    → 진실 발각(이 세계는 큐브 1개) → 최종 보스 → 색이 완전히 돌아온 세계
```

## 핵심 반전

이 세계는 탑이 아니라 **정육면체(큐브) 1개**다. 색 구슬을 얻을 때마다 큐브가 무작위 축으로 90도 회전하며, 이미 지나온 면이 다시 나타난다 — 플레이어가 "같은 층을 반복해서 오르고 있다"고 느끼는 것은 착각이 아니라 진짜 공간적 사실이다.

## 한눈에 보는 비주얼 훅

회색조로 탈색된 도시 → 색 구슬 획득 시 원형 파동이 퍼지며 벽·간판·바닥에 색이 스며들듯 복원 — 이 순간이 게임의 감정적 정점이자 마케팅 스크린샷의 핵심.

## 이 게임이 다른 이유 (경쟁작 대비)

*(상세 → [[26 경쟁작 비교 & 포지셔닝]])*

> "색을 그리는 게임이 아니다. 색을 위해 싸우는 게임이다 — 그리고 이 세계는, 당신이 생각하는 그 모습이 아니다."

- *Concrete Genie*처럼 붓으로 색을 되돌리지만, 전투와 구조적 반전이 있다
- *Kena*처럼 세계를 정화하지만, 폐쇄적인 큐브 구조가 주는 탈출 불가능한 긴장감이 있다
- *Gris*처럼 색이 감정을 대변하지만, 실시간 액션 콤보와 보스전이 있다

## 타겟 오디언스

- Steam 인디 액션 RPG 태그 소비층
- 서사적 반전/미스터리 구조를 즐기는 플레이어 (Tunic, Outer Wilds류 팬)
- 6~8시간 분량의 완결된 싱글 플레이 경험을 찾는 플레이어
